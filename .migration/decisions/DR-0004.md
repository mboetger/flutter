# DR-0004: Adjusted Seam for T-0.15 Task Split

**Date:** 2026-09-15
**Task:** T-0.15
**Supersedes:** DR-0003

## Context
During plan review, it was identified that assigning `--check-artifact-sha` to the T-0.15b subtask left T-0.15a unable to pass its own verification block. The pipeline integrity relies on this check being available on the branch that introduces the auditing mechanism.

## Decision
The seam for the T-0.15 split is redrawn to ensure independent verifiability:
- **T-0.15a**: Core verification gate commands, JSON artifact schema, dirty tree guard, `--update-goldens` prevention, AND the `--check-artifact-sha` pipeline completeness validator.
- **T-0.15b**: The `--audit-stack` (history walking) and `--device-lock` functionalities (including fetching `adb get-serialno`).
