# DR-0024: Non-Linear Font Scaling Callback Architecture in Embedder API

- **Status:** Accepted
- **Task:** T-1.16
- **Date:** 2026-09-16
- **Context:** Providing embedder support for non-linear font scaling (`_getScaledFontSize` in `dart:ui`) via `FlutterProjectArgs` without breaking existing embedders or crashing when unhandled.

---

## 1. Problem Statement
Android 14 (API 34) introduced non-linear font scaling to ensure that while small text scales up to 200% for accessibility, already large text scales at a lower rate to avoid clipping.
In the Flutter engine, `dart:ui`'s `PlatformDispatcher._getScaledFontSize(fontSize, configurationId)` invokes `PlatformConfigurationNativeApi::GetScaledFontSize`, which routes to `PlatformView::GetScaledFontSize`.

In `PlatformView.cc`:
```cpp
double PlatformView::GetScaledFontSize(double unscaled_font_size,
                                       int configuration_id) const {
  FML_UNREACHABLE();
  return -1;
}
```
Currently, `PlatformViewEmbedder` does not override `GetScaledFontSize`, and `embedder.h` lacks a callback for embedders to calculate or query scaled font sizes.
If any Dart application running on an embedder invokes `_getScaledFontSize`, it hits `FML_UNREACHABLE()` and terminates the process. Furthermore, when Android migrates to the Embedder API, it requires this callback to connect to `FlutterView.getScaledFontSize`.

---

## 2. Considered Alternatives

### Alternative 1: Pass Scaled Font Size Table via Window Metrics
- Embedder computes a lookup table for various font sizes and passes it in `FlutterWindowMetricsEvent`.
- **Drawbacks:**
  - Android computes non-linear font scale dynamically using piecewise linear interpolation across any arbitrary floating point font size. A static lookup table cannot cover continuous font sizes.
  - Bloats `FlutterWindowMetricsEvent` with complex table serialization.

### Alternative 2 (Chosen): Direct Synchronous Callback in `FlutterProjectArgs`
- Add `FlutterGetScaledFontSizeCallback` to `embedder.h`:
  ```c
  typedef double (*FlutterGetScaledFontSizeCallback)(
      double unscaled_font_size,
      int configuration_id,
      void* user_data);
  ```
- Append `get_scaled_font_size_callback` to `FlutterProjectArgs`.
- In `PlatformViewEmbedder::GetScaledFontSize`:
  - If `get_scaled_font_size_callback` is provided by the embedder, invoke it synchronously on the calling UI thread and return the result.
  - If `get_scaled_font_size_callback` is `nullptr` (or omitted by legacy embedders), return `unscaled_font_size` (1:1 linear scale) rather than crashing via `FML_UNREACHABLE()`.
- **Benefits:**
  - Full parity with Android's dynamic `TypedValue.applyDimension` non-linear font scaling.
  - Zero performance cost for embedders that do not enable or implement non-linear font scaling.
  - Graceful fallback: legacy or desktop embedders do not crash if Dart code queries font scaling; they receive the unscaled size.
  - Follows established `FlutterProjectArgs` extension pattern with `SAFE_ACCESS`.

---

## 3. Decision
Adopt Alternative 2. Append `get_scaled_font_size_callback` to `FlutterProjectArgs`, implement fallback-safe dispatch in `PlatformViewEmbedder`, and maintain `FLUTTER_ENGINE_VERSION = 1`.
