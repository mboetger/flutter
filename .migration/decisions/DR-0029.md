# DR-0029: Delegate Forwarding for Semantics, Locale, and Font Scaling Overrides on PlatformViewAndroid

- **Status:** Accepted
- **Task:** T-2.2a
- **Date:** 2026-09-16
- **Context:** Advancing Stage 2 (Refactoring & Decoupling) per `MIGRATION_LEDGER.md` §Stage 2 by migrating 5 `PlatformViewAndroid` overrides to delegate forwarding: `UpdateSemantics`, `SetSemanticsTreeEnabled`, `SetApplicationLocale`, `ComputePlatformResolvedLocales`, and `GetScaledFontSize`.

---

## 1. Problem Statement
In `PlatformViewAndroid`, methods overridden from `PlatformView` directly invoke Android JNI facade methods or internal delegate instances.
To prepare for breaking the `PlatformViewAndroid : PlatformView` inheritance in T-2.4 and delegating to `PlatformViewEmbedder` in T-2.3, each override must be routed through the `platform_view_` delegate seam established in T-2.1 when a delegate is registered, while falling back to the existing implementation when `platform_view_ == nullptr`.

Per `MIGRATION_LEDGER.md` §Stage 2:
- T-2.2 migrates overrides to delegate forwarding in batches of ~3–5 methods per PR.
- T-2.2a covers the first batch: semantics, locale, and font scaling overrides.

Governing invariant: Stage 2 changes NO behavior. All Stage 0 characterization tests must pass unmodified.

---

## 2. Technical Solution
1. **Migrated Methods:**
   - `UpdateSemantics(int64_t view_id, flutter::SemanticsNodeUpdates update, flutter::CustomAccessibilityActionUpdates actions)`
     - When `platform_view_ != nullptr`: delegates to `platform_view_->UpdateSemantics(view_id, std::move(update), std::move(actions))`.
     - Fallback: delegates to `platform_view_android_delegate_.UpdateSemantics(update, actions)`.
   - `SetSemanticsTreeEnabled(bool enabled)`
     - When `platform_view_ != nullptr`: delegates to `platform_view_->SetSemanticsTreeEnabled(enabled)`.
     - Fallback: invokes `jni_facade_->FlutterViewSetSemanticsTreeEnabled(enabled)`.
   - `SetApplicationLocale(std::string locale)`
     - When `platform_view_ != nullptr`: delegates to `platform_view_->SetApplicationLocale(locale)`.
     - Fallback: invokes `jni_facade_->FlutterViewSetApplicationLocale(std::move(locale))`.
   - `ComputePlatformResolvedLocales(const std::vector<std::string>& supported_locale_data)`
     - When `platform_view_ != nullptr`: returns `platform_view_->ComputePlatformResolvedLocales(supported_locale_data)`.
     - Fallback: returns `jni_facade_->FlutterViewComputePlatformResolvedLocale(supported_locale_data)`.
   - `GetScaledFontSize(double unscaled_font_size, int configuration_id) const`
     - When `platform_view_ != nullptr`: returns `platform_view_->GetScaledFontSize(unscaled_font_size, configuration_id)`.
     - Fallback: returns `jni_facade_->FlutterViewGetScaledFontSize(unscaled_font_size, configuration_id)`.

2. **Seam Verification:**
   - Extend `MockPlatformViewDelegate` in `platform_view_android_unittests.cc` to track invocations and arguments for these 5 methods.
   - Add unit tests verifying:
     - When `platform_view_` is set, calls to these 5 methods forward to the delegate.
     - When `platform_view_` is null, calls fall back to their default implementations.
