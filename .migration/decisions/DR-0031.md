# DR-0031: Delegate Forwarding for Surface, Context, and VSync Overrides on PlatformViewAndroid

- **Status:** Accepted
- **Task:** T-2.2c
- **Date:** 2026-09-16
- **Context:** Advancing Stage 2 (Refactoring & Decoupling) per `MIGRATION_LEDGER.md` §Stage 2 by migrating the remaining 9 `PlatformViewAndroid` overrides of `PlatformView` to delegate forwarding across the `platform_view_` seam:
  1. `GetPlatformMessageHandler`
  2. `SetupImpellerContext`
  3. `CreateVSyncWaiter`
  4. `CreateRenderingSurface`
  5. `CreateExternalViewEmbedder`
  6. `CreateSnapshotSurfaceProducer`
  7. `CreateResourceContext`
  8. `ReleaseResourceContext`
  9. `GetImpellerContext`

---

## 1. Problem Statement
In `PlatformViewAndroid`, all remaining overrides from `PlatformView` relate to platform message handler access, surface creation, external view embedder creation, Impeller context access, resource context management, and vsync waiter creation.
To complete T-2.2 and prepare for constructing `PlatformViewEmbedder` in T-2.3 and severing `PlatformViewAndroid : PlatformView` inheritance in T-2.4, these remaining overrides must forward to `platform_view_` when set, while preserving 100% fidelity with existing fallbacks when `platform_view_ == nullptr`.

Per `MIGRATION_LEDGER.md` §Stage 2:
- T-2.2 completes across batches T-2.2a, T-2.2b, and T-2.2c.
- T-2.2c covers all remaining overrides, completing the entire set of virtual overrides in `PlatformViewAndroid`.

Governing invariant: Stage 2 changes NO behavior. All Stage 0 characterization tests must pass unmodified.

---

## 2. Technical Solution
1. **Migrated Methods:**
   - `GetPlatformMessageHandler() const`:
     - When `platform_view_ != nullptr`: delegates to `platform_view_->GetPlatformMessageHandler()`.
     - Fallback: returns `platform_message_handler_`.
   - `SetupImpellerContext()`:
     - When `platform_view_ != nullptr`: delegates to `platform_view_->SetupImpellerContext()`.
     - Fallback: invokes `android_context_->SetupImpellerContext()` and `android_surface_->SetupImpellerSurface()`.
   - `CreateVSyncWaiter()`:
     - When `platform_view_ != nullptr`: delegates to `platform_view_->CreateVSyncWaiter()`.
     - Fallback: returns `std::make_unique<VsyncWaiterAndroid>(task_runners_)`.
   - `CreateRenderingSurface()`:
     - When `platform_view_ != nullptr`: delegates to `platform_view_->CreateRenderingSurface()`.
     - Fallback: delegates to `android_surface_->CreateGPUSurface(...)`.
   - `CreateExternalViewEmbedder()`:
     - When `platform_view_ != nullptr`: delegates to `platform_view_->CreateExternalViewEmbedder()`.
     - Fallback: returns `std::make_shared<AndroidExternalViewEmbedderWrapper>(...)`.
   - `CreateSnapshotSurfaceProducer()`:
     - When `platform_view_ != nullptr`: delegates to `platform_view_->CreateSnapshotSurfaceProducer()`.
     - Fallback: returns `std::make_unique<AndroidSnapshotSurfaceProducer>(*android_surface_)`.
   - `CreateResourceContext() const`:
     - When `platform_view_ != nullptr`: delegates to `platform_view_->CreateResourceContext()`.
     - Fallback: creates resource loading context or returns nullptr.
   - `ReleaseResourceContext() const`:
     - When `platform_view_ != nullptr`: delegates to `platform_view_->ReleaseResourceContext()`.
     - Fallback: calls `android_surface_->ResourceContextClearCurrent()`.
   - `GetImpellerContext() const`:
     - When `platform_view_ != nullptr`: delegates to `platform_view_->GetImpellerContext()`.
     - Fallback: returns Impeller context from surface or `android_context_`.

2. **Seam Verification:**
   - Extend `MockPlatformViewDelegate` in `platform_view_android_unittests.cc` with overrides and tracking flags for all 9 methods.
   - Add unit tests verifying both delegation (when `platform_view_` is non-null) and safe default fallback (when `platform_view_` is null).
