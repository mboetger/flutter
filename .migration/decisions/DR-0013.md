# DR-0013: Smart Workspace

**Status:** superseded by DR-0014 Telemetry Integrity overriding Dirty-Tree Rejections

**Date:** 2026-09-15
**Task:** T-0.15a
**Status:** Active

## Context
During Dogfooding, the pipeline inherently creates untracked `.migration/` artifacts mid-run. This systematically triggered the aggressive dirty-tree abort guard (B3 omission cascading failure), locking the tool out of ever running during routine pipeline operations.

## Decision
1. **Provenance Over Prevention**: The tool must never silently tolerate repository dirt, but must actively support operational workflow metadata.
2. **Smart Filtering**: Utilizing `git status --porcelain`, if ALL discovered untracked/modified files are strictly enclosed within the `.migration/` directory, execution securely proceeds. The tool explicitly captures `"dirty": true` and lists the modified path arrays directly into the verification JSON preventing silent acceptance masking.
3. **Hard Abort Limits**: If ANY evaluated path falls outside `.migration/` (e.g., `dev/tools/`, `engine/src/`), execution terminates aggressively with an explicit failure exit code.
