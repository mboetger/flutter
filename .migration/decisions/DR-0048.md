## Context
Per `MIGRATION_LEDGER.md` §Stage 3:
Stage 3 incrementally replaces internal engine calls with their Embedder API equivalents behind `--android-embedder-api`.
Task T-3.8 addresses:
```
shell_->Spawn(...) -> FlutterEngineSpawn
```

Requirements for Stage 3 tasks:
1. Flagged: Legacy path remains 100% intact and reachable when `--android-embedder-api` is off.
2. The branch point carries `TRACE_EVENT` with the resolved path (`embedder_api` vs `legacy`).
3. Once migrated behind the flag, `platform_view_` usage is not dual-routed on the flag-on path.
4. Parity tests verify both flag states.

## Decision
1. Declare in `AndroidShellHolder`:
   ```cpp
   FlutterEngineResult SpawnEngine(
       const FlutterEngineSpawnConfig* config,
       std::shared_ptr<PlatformViewAndroidJNI> jni_facade,
       std::unique_ptr<AndroidShellHolder>* spawned_holder_out) const;
   ```
   matching the C-ABI `FlutterEngineSpawn` shape.
2. In `AndroidShellHolder::Spawn(...)`:
   - If `settings_.android_embedder_api` is true:
     Emit `TRACE_EVENT1("flutter", "AndroidShellHolder::Spawn", "path", "embedder_api")`, construct `FlutterEngineSpawnConfig`, and route through `SpawnEngine(...)`.
   - If `settings_.android_embedder_api` is false:
     Emit `TRACE_EVENT1("flutter", "AndroidShellHolder::Spawn", "path", "legacy")` and execute the legacy `shell_->Spawn(...)` path.
3. In `SpawnEngine(...)`:
   - Validate `config` (`struct_size`, `argc`, `argv`).
   - Construct child `PlatformViewAndroid` and `PlatformViewEmbedder`.
   - Build run configuration and spawn child shell.
   - Return `kSuccess` on success and population of `spawned_holder_out`.
4. Add unit tests in `android_shell_holder_unittests.cc`:
   - `AndroidShellHolder.SpawnLegacyPath`: verify spawn legacy path with flag off.
   - `AndroidShellHolder.SpawnEmbedderApiPath`: verify spawn embedder path with flag on.
   - `AndroidShellHolder.SpawnEngineDirect`: verify direct `SpawnEngine` invocation.
   - `AndroidShellHolder.SpawnEngineInvalidArguments`: verify argument validation (null config, invalid struct size, negative argc).

## Consequences
- Engine spawning conforms to the `FlutterEngineSpawn` Embedder API shape.
- Strict isolation between flag states; zero regression risk with flag off.
- Dependency ratchet remains <= baseline (63 deps, 121 includes, 0 nogncheck).
