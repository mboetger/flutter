# DR-0043 — Replace DispatchSemanticsAction with FlutterEngineDispatchSemanticsAction Seam behind Flag

- **Task:** T-3.3
- **Branch:** android-embedder-v8/t-3.3-semantics-action-embedder-api
- **Author role:** planner
- **Date:** 2026-09-16
- **Status:** accepted
- **Confidence:** firm

## Context
Per `MIGRATION_LEDGER.md` §Stage 3:
Stage 3 incrementally replaces internal engine calls with their Embedder API equivalents behind `--android-embedder-api`.
Task T-3.3 addresses:
```
platform_view_->DispatchSemanticsAction(...) -> FlutterEngineDispatchSemanticsAction
```

Requirements for Stage 3 tasks:
1. Flagged: Legacy path remains 100% intact and reachable when `--android-embedder-api` is off.
2. The branch point carries `TRACE_EVENT` with the resolved path (`embedder_api` vs `legacy`).
3. Once migrated behind the flag, `platform_view_` usage is not dual-routed on the flag-on path.
4. Parity tests verify both flag states and input validation.

## Decision
1. Declare `FlutterEngineResult DispatchSemanticsAction(uint64_t node_id, FlutterSemanticsAction action, const uint8_t* data, size_t data_length)` in `PlatformViewAndroid`, matching the C-ABI `FlutterEngineDispatchSemanticsAction` signature and returning `FlutterEngineResult`.
2. In `PlatformViewAndroid::DispatchSemanticsAction(JNIEnv* env, jint node_id, jint action, jobject args, jint args_position)`:
   - If `android_embedder_api_` is true:
     Extract buffer address/position if non-null, emit `TRACE_EVENT1("flutter", "PlatformViewAndroid::DispatchSemanticsAction", "path", "embedder_api")`, and dispatch through `DispatchSemanticsAction(node_id, static_cast<FlutterSemanticsAction>(action), data, data_length)`.
   - If `android_embedder_api_` is false:
     Emit `TRACE_EVENT1("flutter", "PlatformViewAndroid::DispatchSemanticsAction", "path", "legacy")` and forward directly to `platform_view_->DispatchSemanticsAction(...)`.
3. In `PlatformViewAndroid::DispatchSemanticsAction(uint64_t node_id, FlutterSemanticsAction action, const uint8_t* data, size_t data_length)`:
   - Validate input parameters (`data == nullptr && data_length > 0` returns `kInvalidArguments`).
   - Reconstruct `fml::MallocMapping` from byte buffer and forward to `platform_view_->DispatchSemanticsAction(kImplicitViewId, node_id, static_cast<flutter::SemanticsAction>(action), std::move(args_vector))`, returning `kSuccess`.
4. Add unit tests in `platform_view_android_unittests.cc`:
   - `SemanticsActionDispatchValidation`: Assert `kInvalidArguments` on null data with positive length, and `kSuccess` on null data with 0 length.
   - `SemanticsActionDispatchWithPayload`: Assert `kSuccess` and proper forwarding of node_id, action, and payload data to delegate.

## Consequences
- Semantics action dispatching conforms to the `FlutterEngineDispatchSemanticsAction` C-ABI shape.
- Strict isolation between flag states; zero regression risk with flag off.
- Dependency ratchet remains <= baseline (63 deps, 121 includes, 0 nogncheck).
