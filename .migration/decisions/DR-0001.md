# DR-0001: Correct branch creation responsibility in five-agent pipeline

**Date:** 2026-09-15
**Task:** T-0.15

## Context
The ledger contained a process inconsistency. §D.4.3 (Implementer contract) and §A.2 stated that the Implementer agent creates the task branch cut from the previous task's branch. Wait, no. The orchestrator must cut the branch BEFORE spawning the Planner, because the Planner writes its Phase 0 and Phase 1 outputs (`.migration/plans/...`) onto that branch.

## Decision
Modified §A.2 and §D.4.3 to explicitly state that the **Orchestrator** creates the branch (since the Planner must write onto it) and that the Implementer only makes local `WIP:` commits. This brings the documentation into lockstep with the actual state machine executing the migration.
