## Context
Per `MIGRATION_LEDGER.md` §Stage 3 Composition Mode Migration:
Modes converge independently behind `--android-embedder-api`. Task T-3.T6 addresses:
```
HC composition mode migration
```

Hybrid Composition (HC) is Flutter's composition mode where native Android platform views are embedded directly into the native view hierarchy, requiring dynamic merging of the raster thread onto the platform thread during platform view rendering and managing overlay surfaces for Flutter UI rendered above or below native views.
Gated on T-1.18 (dynamic thread merging C-ABI extension), which implemented `supports_dynamic_thread_merging`, `post_preroll_callback`, `begin_frame_callback`, and `end_frame_callback` on `FlutterCompositor`.

Requirements for mode tasks:
1. Flagged: Legacy path remains 100% intact and reachable when `--android-embedder-api` is off.
2. The mode dispatch points carry `TRACE_EVENT` with the mode (`HC`) and the resolved path (`embedder_api` vs `legacy`).
3. Once migrated behind the flag, no dual routing on the flag-on path.
4. The B.1 composition mode convergence tracker is updated on the same branch to advance HC status from `legacy` to `embedder-behind-flag`.
5. Parity tests verify both flag states, direct seam dispatch, and argument validation.
6. Ratchet counts must remain <= baseline (deps <= 63, includes <= 121, nogncheck == 0).

## Decision
1. Declare in `PlatformViewAndroid`:
   ```cpp
   void BeginFrameHC();

   FlutterEngineResult BeginFrameHCEmbedder();

   void EndFrameHC();

   FlutterEngineResult EndFrameHCEmbedder();

   std::unique_ptr<PlatformViewAndroidJNI::OverlayMetadata>
   CreateOverlaySurfaceHC();

   FlutterEngineResult CreateOverlaySurfaceHCEmbedder(
       std::unique_ptr<PlatformViewAndroidJNI::OverlayMetadata>* out_metadata);

   void DestroyOverlaySurfacesHC();

   FlutterEngineResult DestroyOverlaySurfacesHCEmbedder();
   ```
2. In `PlatformViewAndroid::BeginFrameHC()`:
   - If `android_embedder_api_` is true:
     Emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::BeginFrameHC", "mode", "HC", "path", "embedder_api")`.
     Route to `BeginFrameHCEmbedder()`.
   - If `android_embedder_api_` is false:
     Emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::BeginFrameHC", "mode", "HC", "path", "legacy")`.
     Dispatch to `jni_facade_->FlutterViewBeginFrame()`.
3. In `PlatformViewAndroid::BeginFrameHCEmbedder()`:
   - If `!jni_facade_`, return `kInternalInconsistency`.
   - Dispatch to `jni_facade_->FlutterViewBeginFrame()`.
   - Return `kSuccess`.
4. In `PlatformViewAndroid::EndFrameHC()` and `EndFrameHCEmbedder()`:
   - Emit `TRACE_EVENT2` with mode `HC` and resolved path.
   - Dispatch to `jni_facade_->FlutterViewEndFrame()`.
   - Return `kSuccess` (or `kInternalInconsistency` if null).
5. In `PlatformViewAndroid::CreateOverlaySurfaceHC()` and `CreateOverlaySurfaceHCEmbedder(...)`:
   - Emit `TRACE_EVENT2` with mode `HC` and resolved path.
   - Validate `out_metadata != nullptr`, returning `kInvalidArguments` if null.
   - Dispatch to `jni_facade_->FlutterViewCreateOverlaySurface()`.
   - Return `kSuccess` (or `kInternalInconsistency` if null).
6. In `PlatformViewAndroid::DestroyOverlaySurfacesHC()` and `DestroyOverlaySurfacesHCEmbedder()`:
   - Emit `TRACE_EVENT2` with mode `HC` and resolved path.
   - Dispatch to `jni_facade_->FlutterViewDestroyOverlaySurfaces()`.
   - Return `kSuccess` (or `kInternalInconsistency` if null).
7. Update `MIGRATION_LEDGER.md` §B.1:
   Advance `HC — Hybrid Composition` status to `embedder-behind-flag` with last verified task `T-3.T6`.
8. Add unit tests in `platform_view_android_unittests.cc`:
   - `BeginFrameHCLegacyPath`: verifies legacy dispatch with flag off.
   - `BeginFrameHCEmbedderApiPath`: verifies embedder dispatch with flag on.
   - `BeginFrameHCDirectSeam`: verifies direct seam invocation.
   - `EndFrameHCLegacyPath`: verifies legacy dispatch with flag off.
   - `EndFrameHCEmbedderApiPath`: verifies embedder dispatch with flag on.
   - `EndFrameHCDirectSeam`: verifies direct seam invocation.
   - `CreateOverlaySurfaceHC`: verifies legacy, embedder, and direct seam dispatch, plus invalid argument check.
   - `DestroyOverlaySurfacesHC`: verifies legacy, embedder, and direct seam dispatch.

## Consequences
- Hybrid Composition mode migration is isolated behind `--android-embedder-api`.
- All six composition modes in §B.1 are now converged behind the flag (`embedder-behind-flag`).
- Zero behavioral impact when the flag is disabled.
- Trace events enable Perfetto inspection of mode resolution without code changes.
- Dependency ratchet remains <= baseline (63 deps, 121 includes, 0 nogncheck).
