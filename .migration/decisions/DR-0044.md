# DR-0044 — Replace SetSemanticsEnabled with FlutterEngineUpdateSemanticsEnabled Seam behind Flag

- **Task:** T-3.4
- **Branch:** android-embedder-v8/t-3.4-semantics-enabled-embedder-api
- **Author role:** planner
- **Date:** 2026-09-16
- **Status:** accepted
- **Confidence:** firm

## Context
Per `MIGRATION_LEDGER.md` §Stage 3:
Stage 3 incrementally replaces internal engine calls with their Embedder API equivalents behind `--android-embedder-api`.
Task T-3.4 addresses:
```
platform_view_->SetSemanticsEnabled(enabled) -> FlutterEngineUpdateSemanticsEnabled
```

Requirements for Stage 3 tasks:
1. Flagged: Legacy path remains 100% intact and reachable when `--android-embedder-api` is off.
2. The branch point carries `TRACE_EVENT` with the resolved path (`embedder_api` vs `legacy`).
3. Once migrated behind the flag, `platform_view_` usage is not dual-routed on the flag-on path.
4. Parity tests verify both flag states.

## Decision
1. Declare `FlutterEngineResult UpdateSemanticsEnabled(bool enabled)` in `PlatformViewAndroid`, matching the C-ABI `FlutterEngineUpdateSemanticsEnabled` signature and returning `FlutterEngineResult`.
2. In `PlatformViewAndroid::SetSemanticsEnabled(bool enabled)`:
   - If `android_embedder_api_` is true:
     Emit `TRACE_EVENT1("flutter", "PlatformViewAndroid::SetSemanticsEnabled", "path", "embedder_api")` and route through `UpdateSemanticsEnabled(enabled)`.
   - If `android_embedder_api_` is false:
     Emit `TRACE_EVENT1("flutter", "PlatformViewAndroid::SetSemanticsEnabled", "path", "legacy")` and forward directly to `platform_view_->SetSemanticsEnabled(enabled)`.
3. In `PlatformViewAndroid::UpdateSemanticsEnabled(bool enabled)`:
   - Forward to `platform_view_->SetSemanticsEnabled(enabled)` and return `kSuccess`.
4. Add unit tests in `platform_view_android_unittests.cc`:
   - `SemanticsEnabledDispatchLegacyPath`: Assert that with flag off, delegate `OnPlatformViewSetSemanticsEnabled` is invoked directly.
   - `SemanticsEnabledDispatchEmbedderApiPath`: Assert that with flag on, delegate `OnPlatformViewSetSemanticsEnabled` is invoked via `UpdateSemanticsEnabled` without dual-routing.
   - `UpdateSemanticsEnabledDirect`: Assert direct invocation of `UpdateSemanticsEnabled` updates the delegate and returns `kSuccess`.

## Consequences
- Semantics enabled state management conforms to the `FlutterEngineUpdateSemanticsEnabled` C-ABI shape.
- Strict isolation between flag states; zero regression risk with flag off.
- Dependency ratchet remains <= baseline (63 deps, 121 includes, 0 nogncheck).
