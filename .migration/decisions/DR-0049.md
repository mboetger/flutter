# DR-0049 — SurfaceProducer / ImageReader External Texture Mode Migration behind Flag

- **Task:** T-3.T1
- **Branch:** android-embedder-v8/t-3.t1-surface-producer-embedder-api
- **Author role:** planner
- **Date:** 2026-09-16
- **Status:** accepted
- **Confidence:** firm

## Context
Per `MIGRATION_LEDGER.md` §Stage 3 Composition Mode Migration:
Modes converge independently behind `--android-embedder-api`. Task T-3.T1 is the first composition mode task:
```
SurfaceProducer / ImageReader external texture mode migration
```

Requirements for mode tasks:
1. Flagged: Legacy path remains 100% intact and reachable when `--android-embedder-api` is off.
2. The mode dispatch point carries `TRACE_EVENT` with the mode (`SurfaceProducer`) and the resolved path (`embedder_api` vs `legacy`).
3. Once migrated behind the flag, no dual routing on the flag-on path.
4. The B.1 composition mode convergence tracker is updated on the same branch to advance the mode status from `legacy` to `embedder-behind-flag`.
5. Parity tests verify both flag states and argument validation.
6. Ratchet counts must remain <= baseline (deps <= 63, includes <= 121, nogncheck == 0).

## Decision
1. Declare in `PlatformViewAndroid`:
   ```cpp
   FlutterEngineResult RegisterImageExternalTexture(
       int64_t texture_id,
       const fml::jni::ScopedJavaGlobalRef<jobject>& image_texture_entry,
       ImageExternalTexture::ImageLifecycle lifecycle);
   ```
2. In `PlatformViewAndroid::RegisterImageTexture(...)`:
   - If `android_embedder_api_` is true:
     Emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::RegisterImageTexture", "mode", "SurfaceProducer", "path", "embedder_api")`.
     Route to `RegisterImageExternalTexture(texture_id, image_texture_entry, lifecycle)`.
   - If `android_embedder_api_` is false:
     Emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::RegisterImageTexture", "mode", "SurfaceProducer", "path", "legacy")`.
     Execute legacy path via `external_texture_adapter_->RegisterImageTexture(...)`.
3. In `PlatformViewAndroid::RegisterImageExternalTexture(...)`:
   - Validate `texture_id <= 0` or `image_texture_entry.is_null()`, returning `kInvalidArguments`.
   - Dispatch to `external_texture_adapter_->RegisterImageTexture(...)`.
   - Return `kSuccess` on success, `kInternalInconsistency` otherwise.
4. Update `MIGRATION_LEDGER.md` §B.1:
   Advance `SurfaceProducer/ImageReader ext. texture` status to `embedder-behind-flag` with last verified task `T-3.T1`.
5. Add unit tests in `platform_view_android_unittests.cc`:
   - `RegisterImageTextureLegacyPath`: verifies legacy dispatch with flag off.
   - `RegisterImageTextureEmbedderApiPath`: verifies embedder dispatch with flag on.
   - `RegisterImageExternalTextureDirect`: verifies direct seam invocation.
   - `RegisterImageExternalTextureInvalidArguments`: verifies argument validation.

## Consequences
- SurfaceProducer / ImageReader mode migration is isolated behind `--android-embedder-api`.
- Zero behavioral impact when the flag is disabled.
- Trace events enable Perfetto inspection of mode resolution without code changes.
- B.1 tracker reflects mode progression to `embedder-behind-flag`.
- Dependency ratchet remains <= baseline (63 deps, 121 includes, 0 nogncheck).
