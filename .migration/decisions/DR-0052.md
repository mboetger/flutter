# DR-0052 — Virtual Display (VD) Composition Mode Migration behind Flag

- **Task:** T-3.T4
- **Branch:** android-embedder-v8/t-3.t4-vd-embedder-api
- **Author role:** planner
- **Date:** 2026-09-16
- **Status:** accepted
- **Confidence:** firm

## Context
Per `MIGRATION_LEDGER.md` §Stage 3 Composition Mode Migration:
Modes converge independently behind `--android-embedder-api`. Task T-3.T4 addresses:
```
Virtual Display (VD) composition mode migration
```

Virtual Display (VD) is an Android platform view composition mode where the native view is hosted in an Android `VirtualDisplay` and rendered into a texture entry (`SurfaceTexture` / `SurfaceProducer`). It depends on T-3.T2 (`SurfaceTexture` external texture mode migration) and resolves blocker B-5.

Requirements for mode tasks:
1. Flagged: Legacy path remains 100% intact and reachable when `--android-embedder-api` is off.
2. The mode dispatch point carries `TRACE_EVENT` with the mode (`VD`) and the resolved path (`embedder_api` vs `legacy`).
3. Once migrated behind the flag, no dual routing on the flag-on path.
4. The B.1 composition mode convergence tracker is updated on the same branch to advance the mode status from `legacy` to `embedder-behind-flag`.
5. Parity tests verify both flag states, direct seam dispatch, and argument validation.
6. Ratchet counts must remain <= baseline (deps <= 63, includes <= 121, nogncheck == 0).

## Decision
1. Declare in `PlatformViewAndroid`:
   ```cpp
   void OnDisplayVirtualDisplayPlatformView(int32_t view_id,
                                           int32_t x,
                                           int32_t y,
                                           int32_t width,
                                           int32_t height);

   FlutterEngineResult DisplayVirtualDisplayPlatformView(int32_t view_id,
                                                         int32_t x,
                                                         int32_t y,
                                                         int32_t width,
                                                         int32_t height);

   FlutterEngineResult DisplayVirtualDisplayPlatformViewEmbedder(
       int32_t view_id,
       int32_t x,
       int32_t y,
       int32_t width,
       int32_t height);
   ```
2. In `PlatformViewAndroid::OnDisplayVirtualDisplayPlatformView(...)`:
   - If `android_embedder_api_` is true:
     Emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::OnDisplayVirtualDisplayPlatformView", "mode", "VD", "path", "embedder_api")`.
     Route to `DisplayVirtualDisplayPlatformView(view_id, x, y, width, height)`.
   - If `android_embedder_api_` is false:
     Emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::OnDisplayVirtualDisplayPlatformView", "mode", "VD", "path", "legacy")`.
3. In `PlatformViewAndroid::DisplayVirtualDisplayPlatformView(...)`:
   - Validate `view_id < 0 || width < 0 || height < 0`, returning `kInvalidArguments`.
   - Return `kSuccess`.
4. In `PlatformViewAndroid::DisplayVirtualDisplayPlatformViewEmbedder(...)`:
   - Forward directly to `DisplayVirtualDisplayPlatformView(view_id, x, y, width, height)`.
5. Update `MIGRATION_LEDGER.md` §B.1:
   Advance `VD — Virtual Display` status to `embedder-behind-flag` with last verified task `T-3.T4`.
6. Add unit tests in `platform_view_android_unittests.cc`:
   - `DisplayVirtualDisplayPlatformViewLegacyPath`: verifies legacy dispatch with flag off.
   - `DisplayVirtualDisplayPlatformViewEmbedderApiPath`: verifies embedder dispatch with flag on.
   - `DisplayVirtualDisplayPlatformViewDirectSeam`: verifies direct seam invocation.
   - `DisplayVirtualDisplayPlatformViewInvalidArguments`: verifies argument validation.

## Consequences
- VD composition mode migration is isolated behind `--android-embedder-api`.
- Zero behavioral impact when the flag is disabled.
- Trace events enable Perfetto inspection of mode resolution without code changes.
- B.1 tracker reflects mode progression to `embedder-behind-flag`.
- Dependency ratchet remains <= baseline (63 deps, 121 includes, 0 nogncheck).
