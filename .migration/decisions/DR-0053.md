## Context
Per `MIGRATION_LEDGER.md` §Stage 3 Composition Mode Migration:
Modes converge independently behind `--android-embedder-api`. Task T-3.T5 addresses:
```
HCPP composition mode migration
```

HCPP (Hybrid Composition Plus Plus) is an advanced platform view composition mode for Android (Impeller Vulkan + API 34+), utilizing `ASurfaceTransaction` and `AndroidExternalViewEmbedder2` to synchronize platform view display and transaction commit with Flutter frame rasterization.

Requirements for mode tasks:
1. Flagged: Legacy path remains 100% intact and reachable when `--android-embedder-api` is off.
2. The mode dispatch point carries `TRACE_EVENT` with the mode (`HCPP`) and the resolved path (`embedder_api` vs `legacy`).
3. Once migrated behind the flag, no dual routing on the flag-on path.
4. The B.1 composition mode convergence tracker is updated on the same branch to advance the mode status from `legacy` to `embedder-behind-flag`.
5. Parity tests verify both flag states, direct seam dispatch, and argument validation.
6. Ratchet counts must remain <= baseline (deps <= 63, includes <= 121, nogncheck == 0).

## Decision
1. Declare in `PlatformViewAndroid`:
   ```cpp
   void OnDisplayPlatformView2(int32_t view_id,
                               int32_t x,
                               int32_t y,
                               int32_t width,
                               int32_t height,
                               int32_t view_width,
                               int32_t view_height,
                               MutatorsStack mutators_stack);

   FlutterEngineResult DisplayPlatformView2(int32_t view_id,
                                            int32_t x,
                                            int32_t y,
                                            int32_t width,
                                            int32_t height,
                                            int32_t view_width,
                                            int32_t view_height,
                                            MutatorsStack mutators_stack);

   FlutterEngineResult DisplayPlatformView2Embedder(
       int32_t view_id,
       int32_t x,
       int32_t y,
       int32_t width,
       int32_t height,
       int32_t view_width,
       int32_t view_height,
       MutatorsStack mutators_stack);

   void OnHidePlatformView2(int32_t view_id);

   FlutterEngineResult HidePlatformView2(int32_t view_id);
   ```
2. In `PlatformViewAndroid::OnDisplayPlatformView2(...)`:
   - If `android_embedder_api_` is true:
     Emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::OnDisplayPlatformView2", "mode", "HCPP", "path", "embedder_api")`.
     Route to `DisplayPlatformView2(view_id, x, y, width, height, view_width, view_height, std::move(mutators_stack))`.
   - If `android_embedder_api_` is false:
     Emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::OnDisplayPlatformView2", "mode", "HCPP", "path", "legacy")`.
     Execute legacy path via `jni_facade_->onDisplayPlatformView2(...)`.
3. In `PlatformViewAndroid::DisplayPlatformView2(...)`:
   - Validate `view_id < 0 || width < 0 || height < 0 || view_width < 0 || view_height < 0`, returning `kInvalidArguments`.
   - If `!jni_facade_`, return `kInternalInconsistency`.
   - Dispatch to `jni_facade_->onDisplayPlatformView2(...)`.
   - Return `kSuccess`.
4. In `PlatformViewAndroid::OnHidePlatformView2(...)` and `HidePlatformView2(...)`:
   - Emit `TRACE_EVENT2` with mode `HCPP` and resolved path.
   - Validate `view_id < 0`, returning `kInvalidArguments`.
   - Dispatch to `jni_facade_->hidePlatformView2(...)`.
   - Return `kSuccess`.
5. Update `MIGRATION_LEDGER.md` §B.1:
   Advance `HCPP (Impeller Vulkan + API 34 only)` status to `embedder-behind-flag` with last verified task `T-3.T5`.
6. Add unit tests in `platform_view_android_unittests.cc`:
   - `DisplayPlatformView2LegacyPath`: verifies legacy dispatch with flag off.
   - `DisplayPlatformView2EmbedderApiPath`: verifies embedder dispatch with flag on.
   - `DisplayPlatformView2DirectSeam`: verifies direct seam invocation.
   - `DisplayPlatformView2InvalidArguments`: verifies argument validation.
   - `HidePlatformView2LegacyPath`: verifies legacy hide dispatch with flag off.
   - `HidePlatformView2EmbedderApiPath`: verifies embedder hide dispatch with flag on.
   - `HidePlatformView2DirectSeam`: verifies direct hide seam invocation.
   - `HidePlatformView2InvalidArguments`: verifies hide argument validation.

## Consequences
- HCPP composition mode migration is isolated behind `--android-embedder-api`.
- Zero behavioral impact when the flag is disabled.
- Trace events enable Perfetto inspection of mode resolution without code changes.
- B.1 tracker reflects mode progression to `embedder-behind-flag`.
- Dependency ratchet remains <= baseline (63 deps, 121 includes, 0 nogncheck).
