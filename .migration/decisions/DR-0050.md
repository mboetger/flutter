# DR-0050 — SurfaceTexture External Texture Mode Migration behind Flag

- **Task:** T-3.T2
- **Branch:** android-embedder-v8/t-3.t2-surface-texture-embedder-api
- **Author role:** planner
- **Date:** 2026-09-16
- **Status:** accepted

## Context
Per `MIGRATION_LEDGER.md` §Stage 3 Composition Mode Migration:
Modes converge independently behind `--android-embedder-api`. Task T-3.T2 addresses:
```
SurfaceTexture external texture mode migration
```

Requirements for mode tasks:
1. Flagged: Legacy path remains 100% intact and reachable when `--android-embedder-api` is off.
2. The mode dispatch point carries `TRACE_EVENT` with the mode (`SurfaceTexture`) and the resolved path (`embedder_api` vs `legacy`).
3. Once migrated behind the flag, no dual routing on the flag-on path.
4. The B.1 composition mode convergence tracker is updated on the same branch to advance the mode status from `legacy` to `embedder-behind-flag`.
5. Parity tests verify both flag states and argument validation.
6. Ratchet counts must remain <= baseline (deps <= 63, includes <= 121, nogncheck == 0).

## Decision
1. Declare in `PlatformViewAndroid`:
   ```cpp
   FlutterEngineResult RegisterSurfaceExternalTexture(
       int64_t texture_id,
       const fml::jni::ScopedJavaGlobalRef<jobject>& surface_texture);
   ```
2. In `PlatformViewAndroid::RegisterExternalTexture(...)`:
   - If `android_embedder_api_` is true:
     Emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::RegisterExternalTexture", "mode", "SurfaceTexture", "path", "embedder_api")`.
     Route to `RegisterSurfaceExternalTexture(texture_id, surface_texture)`.
   - If `android_embedder_api_` is false:
     Emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::RegisterExternalTexture", "mode", "SurfaceTexture", "path", "legacy")`.
     Execute legacy path via `external_texture_adapter_->RegisterSurfaceTexture(...)`.
3. In `PlatformViewAndroid::RegisterSurfaceExternalTexture(...)`:
   - Validate `texture_id <= 0` or `surface_texture.is_null()`, returning `kInvalidArguments`.
   - Dispatch to `external_texture_adapter_->RegisterSurfaceTexture(...)`.
   - Return `kSuccess` on success, `kInternalInconsistency` otherwise.
4. Update `MIGRATION_LEDGER.md` §B.1:
   Advance `SurfaceTexture ext. texture` status to `embedder-behind-flag` with last verified task `T-3.T2`.
5. Add unit tests in `platform_view_android_unittests.cc`:
   - `RegisterSurfaceTextureLegacyPath`: verifies legacy dispatch with flag off.
   - `RegisterSurfaceTextureEmbedderApiPath`: verifies embedder dispatch with flag on.
   - `RegisterSurfaceExternalTextureDirect`: verifies direct seam invocation.
   - `RegisterSurfaceExternalTextureInvalidArguments`: verifies argument validation.

## Consequences
- SurfaceTexture mode migration is isolated behind `--android-embedder-api`.
- Zero behavioral impact when the flag is disabled.
- Trace events enable Perfetto inspection of mode resolution without code changes.
- B.1 tracker reflects mode progression to `embedder-behind-flag`.
- Dependency ratchet remains <= baseline (63 deps, 121 includes, 0 nogncheck).
