# DR-0025: Dynamic Thread Merging C-ABI and Proc Table Extension

- **Status:** Accepted
- **Task:** T-1.18a
- **Date:** 2026-09-16
- **Context:** Delivering the public C-ABI definitions and engine proc-table entries for dynamic raster thread merging required to unblock Hybrid Composition (HC) on Android, following the specifications from T-0.13 (`docs/android/embedder_migration_b4_thread_merging.md`) and Decision DR-0021.

---

## 1. Problem Statement
Hybrid Composition (HC) on Android requires synchronous interleaving of Flutter-rendered textures with platform `View` hierarchies. To prevent deadlocks, touch lag, and visual tearing, Flutter's engine merges the raster task runner onto the platform task runner while platform views are displayed.
Currently, `embedder.h` provides no C-ABI representation for `RasterThreadMerger`, preventing embedders from querying or requesting dynamic thread merging through the public API.

---

## 2. Decision & C-ABI Specification
In Task T-1.18a, we introduce the public C-ABI types, callback signatures, struct extensions in `FlutterCompositor`, and proc-table accessors specified in `docs/android/embedder_migration_b4_thread_merging.md`:

1. **Opaque Merger Handle & Lifecycle Types:**
   - `FlutterRasterThreadMergerRef`: Opaque handle to the engine-owned raster thread merger.
   - `FlutterPostPrerollResult`: Enum (`kFlutterPostPrerollResultSuccess`, `kFlutterPostPrerollResultResubmitFrame`, `kFlutterPostPrerollResultSkipAndRetryFrame`).
   - `FlutterFrameThreadingInfo`: Context structure passed to compositor lifecycle callbacks, containing `struct_size`, `thread_merger`, `is_on_platform_thread`, and `user_data`.
   - `FlutterPostPrerollCallback`: Function pointer taking `const FlutterFrameThreadingInfo*` and returning `FlutterPostPrerollResult`.
   - `FlutterCompositorFrameCallback`: Function pointer taking `const FlutterFrameThreadingInfo*`.

2. **`FlutterCompositor` Extension:**
   Appended after `present_view_callback`:
   - `bool supports_dynamic_thread_merging;`
   - `FlutterPostPrerollCallback post_preroll_callback;`
   - `FlutterCompositorFrameCallback begin_frame_callback;`
   - `FlutterCompositorFrameCallback end_frame_callback;`

3. **C-API Function Declarations & Engine Proc Table:**
   - `FlutterRasterThreadMergerIsMerged`
   - `FlutterRasterThreadMergerIsOnPlatformThread`
   - `FlutterRasterThreadMergerMergeWithLease`
   - `FlutterRasterThreadMergerExtendLeaseTo`
   - Corresponding function pointer typedefs and members in `FlutterEngineProcTable`.

4. **Invariants Maintained:**
   - `FLUTTER_ENGINE_VERSION = 1` preserved (per §G.5/G.9).
   - Zero-initialization of `FlutterCompositor` ensures `supports_dynamic_thread_merging = false`, guaranteeing 100% inertness for iOS, macOS, Windows, and Linux.
   - Strict `SAFE_ACCESS` and struct size checks for backward and forward compatibility.
