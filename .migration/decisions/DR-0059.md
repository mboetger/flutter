- **Task:** T-4.5
- **Branch:** android-embedder-v8/t-4.5-delete-flag-legacy-paths
- **Author role:** planner
- **Date:** 2026-09-16
- **Status:** accepted
- **Confidence:** firm

## Context
Per `MIGRATION_LEDGER.md` §Stage 4 — Flip & Emancipation:
Task T-4.5 is the culmination of the Android Embedder API Migration adherence and flip phases:
```
T-4.5: Delete the flag and all legacy paths
Prototype gate: The gating conditions below, all of them.
T-4.4 clean, plus the conditions below:
- T-0.9 ratchet reports only allowed dependencies (and counts <= baseline)
- Zero overrides remaining in google3
- No open P0/P1 attributed to migration
- Every Stage 0 characterization test still passing unmodified
- nogncheck count is zero (or documented with bug)
- Every row of B.1 tracker reads embedder-default
- HC is embedder-default
- Full matrix and devicelab green after deletion
```
With the successful completion and verification of T-4.1 through T-4.4, all six composition modes are verified on `embedder-default`, opt-out parity has been verified against baseline, and no blocking defects remain.
Retaining legacy branches and switches incurs maintenance debt, dual-path complexity, and risk of divergence. Removing them emancipates the Android platform view architecture to rely exclusively on standard embedder API entry points.

## Decision
1. Remove switches `kAndroidEmbedderApi` and `kNoAndroidEmbedderApi` from `switch_defs.h` and `switches.cc`.
2. Remove `android_embedder_api` member from `Settings` in `common/settings.h`.
3. In `AndroidShellHolder`:
   - Make `InitializeEngine()` the sole initialization path in the constructor.
   - Make `SpawnEngine()` the sole path in `Spawn()`.
   - Make `RunEngine()` the sole path in `Launch()`.
   - Delete `IsAndroidEmbedderApiEnabled()`.
4. In `PlatformViewAndroid`:
   - Remove `android_embedder_api_` member variable and `IsAndroidEmbedderApiEnabled()`.
   - Remove legacy fallback branches across all 15 seams:
     - `DispatchPointerDataPacket`
     - `SetViewportMetrics`
     - `DispatchSemanticsAction`
     - `SetSemanticsEnabled`
     - `SetAccessibilityFeatures`
     - `DispatchEmptyPlatformMessage`
     - `DispatchPlatformMessage`
     - `RegisterExternalTexture` (SurfaceTexture)
     - `RegisterImageTexture` (SurfaceProducer)
     - `OnDisplayPlatformView` (TLHC)
     - `OnHidePlatformView2` (HCPP)
     - `BeginFrameHC` (HC)
     - `EndFrameHC` (HC)
     - `CreateOverlaySurfaceHC` (HC)
     - `DestroyOverlaySurfacesHC` (HC)
5. In unit tests:
   - Remove `SwitchesTest.AndroidEmbedderApiFlag`.
   - Remove `PlatformViewAndroidTest.AndroidEmbedderApiFlagState`.
   - Remove legacy path tests (`*LegacyPath`) in `platform_view_android_unittests.cc` and `android_shell_holder_unittests.cc`.
6. Update `MIGRATION_LEDGER.md` marking T-4.5 gating conditions and task progress.
7. Maintain dependency ratchet (deps <= 63, includes <= 121, nogncheck == 0).

## Consequences
- The legacy engine paths in `shell/platform/android` are permanently removed.
- Dual-path branching is eliminated across all seams.
- The codebase is primed for T-4.6 (renaming `AndroidShellHolder` -> `AndroidEngine` and dissolving `PlatformViewAndroid`).
