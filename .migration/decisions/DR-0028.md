# DR-0028: PlatformView Delegate Pointer Seam on PlatformViewAndroid

- **Status:** Accepted
- **Task:** T-2.1
- **Date:** 2026-09-16
- **Context:** Establishing the `platform_view_` delegate seam on `PlatformViewAndroid` as the first step of Stage 2 (Decoupling & Refactoring), breaking the direct inheritance in preparation for `PlatformViewEmbedder`.

---

## 1. Problem Statement
In the legacy Flutter engine architecture, `PlatformViewAndroid` inherits directly from `PlatformView` (`class PlatformViewAndroid final : public PlatformView`).
As specified in `MIGRATION_LEDGER.md` §Stage 2:
- T-2.1 introduces a `platform_view_` delegate pointer on `PlatformViewAndroid` and forwards one method to prove the seam.
- T-2.2 migrates remaining `PlatformViewAndroid` overrides to delegate forwarding.
- T-2.3 constructs `PlatformViewEmbedder` in `AndroidShellHolder::on_create_platform_view` and wires `SetPlatformView`.
- T-2.4 breaks the `PlatformViewAndroid : PlatformView` inheritance.

Stage 2 governing invariant: Stage 2 changes no behavior. All Stage 0 characterization tests must pass unmodified.

---

## 2. Technical Solution
1. **Delegate Member & Accessors on `PlatformViewAndroid`:**
   - Add `PlatformView* platform_view_ = nullptr;` member variable.
   - Add `void SetPlatformView(PlatformView* platform_view)` setter.
   - Add `PlatformView* GetPlatformViewDelegate() const` getter.
   - `platform_view_` defaults to `nullptr`. It MUST NOT default to `this`, as virtual dispatch on derived methods during forwarding would cause infinite recursion.

2. **Seam Forwarding on `NotifyDestroyed`:**
   - In `PlatformViewAndroid::NotifyDestroyed()`:
     ```cpp
     if (platform_view_) {
       platform_view_->NotifyDestroyed();
     } else {
       PlatformView::NotifyDestroyed();
     }
     ```
   - When `platform_view_` is set, `NotifyDestroyed()` delegates to `platform_view_->NotifyDestroyed()`.
   - When `platform_view_` is `nullptr` (the default state until T-2.3 wires `SetPlatformView`), it calls base class `PlatformView::NotifyDestroyed()`, ensuring 100% backward compatibility with all Stage 0 characterization tests and existing production callers.
   - Surface context teardown (`android_surface_->TeardownOnScreenContext()`) continues to execute on the raster thread as before.

3. **Seam Verification:**
   - Add unit tests in `platform_view_android_unittests.cc`:
     - Verify `GetPlatformViewDelegate()` defaults to `nullptr`.
     - Verify `SetPlatformView` sets and clears the delegate pointer.
     - Verify `NotifyDestroyed()` invokes `platform_view_->NotifyDestroyed()` when a delegate is registered.
     - Verify `NotifyDestroyed()` operates normally and without error when delegate is `nullptr`.
