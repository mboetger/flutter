# DR-0046 — Replace UnregisterTexture and MarkTextureFrameAvailable with FlutterEngine External Texture Seams behind Flag

- **Task:** T-3.6
- **Branch:** android-embedder-v8/t-3.6-external-texture-embedder-api
- **Author role:** planner
- **Date:** 2026-09-16
- **Status:** accepted
- **Confidence:** firm

## Context
Per `MIGRATION_LEDGER.md` §Stage 3:
Stage 3 incrementally replaces internal engine calls with their Embedder API equivalents behind `--android-embedder-api`.
Task T-3.6 addresses:
```
platform_view_->UnregisterTexture(id) -> FlutterEngineUnregisterExternalTexture
platform_view_->MarkTextureFrameAvailable(id) -> FlutterEngineMarkExternalTextureFrameAvailable
```

Requirements for Stage 3 tasks:
1. Flagged: Legacy path remains 100% intact and reachable when `--android-embedder-api` is off.
2. The branch point carries `TRACE_EVENT` with the resolved path (`embedder_api` vs `legacy`).
3. Once migrated behind the flag, `platform_view_` usage is not dual-routed on the flag-on path.
4. Parity tests verify both flag states.

## Decision
1. Declare in `PlatformViewAndroid`:
   - `FlutterEngineResult UnregisterExternalTexture(int64_t texture_id);`
   - `FlutterEngineResult MarkExternalTextureFrameAvailable(int64_t texture_id);`
   matching the C-ABI `FlutterEngineUnregisterExternalTexture` and `FlutterEngineMarkExternalTextureFrameAvailable` signatures.
2. In `PlatformViewAndroid::UnregisterTexture(int64_t texture_id)`:
   - If `android_embedder_api_` is true:
     Emit `TRACE_EVENT1("flutter", "PlatformViewAndroid::UnregisterTexture", "path", "embedder_api")` and route through `UnregisterExternalTexture(texture_id)`.
   - If `android_embedder_api_` is false:
     Emit `TRACE_EVENT1("flutter", "PlatformViewAndroid::UnregisterTexture", "path", "legacy")` and forward to `external_texture_adapter_` / `platform_view_`.
3. In `PlatformViewAndroid::MarkTextureFrameAvailable(int64_t texture_id)`:
   - If `android_embedder_api_` is true:
     Emit `TRACE_EVENT1("flutter", "PlatformViewAndroid::MarkTextureFrameAvailable", "path", "embedder_api")` and route through `MarkExternalTextureFrameAvailable(texture_id)`.
   - If `android_embedder_api_` is false:
     Emit `TRACE_EVENT1("flutter", "PlatformViewAndroid::MarkTextureFrameAvailable", "path", "legacy")` and forward to `external_texture_adapter_` / `platform_view_`.
4. In `PlatformViewAndroid::UnregisterExternalTexture(int64_t texture_id)`:
   - Check `texture_id <= 0` and return `kInvalidArguments`.
   - If `external_texture_adapter_` is present, forward to `external_texture_adapter_->UnregisterExternalTexture(texture_id)`.
   - Otherwise if `platform_view_` is present, forward to `platform_view_->UnregisterTexture(texture_id)` and return `kSuccess`.
5. In `PlatformViewAndroid::MarkExternalTextureFrameAvailable(int64_t texture_id)`:
   - Check `texture_id <= 0` and return `kInvalidArguments`.
   - If `external_texture_adapter_` is present, forward to `external_texture_adapter_->MarkExternalTextureFrameAvailable(texture_id)`.
   - Otherwise if `platform_view_` is present, forward to `platform_view_->MarkTextureFrameAvailable(texture_id)` and return `kSuccess`.
6. Add unit tests in `platform_view_android_unittests.cc`:
   - Legacy path tests for both unregister and mark frame available.
   - Embedder path tests for both unregister and mark frame available.
   - Direct seam invocation tests.
   - Argument validation test for `texture_id <= 0`.

## Consequences
- External texture unregistration and frame availability notifications conform to Embedder API C-ABI shape.
- Strict isolation between flag states; zero regression risk with flag off.
- Dependency ratchet remains <= baseline (63 deps, 121 includes, 0 nogncheck).
