# DR-0030: Delegate Forwarding for Messaging, Engine Restart, Deferred Library, and Asset Resolver Overrides on PlatformViewAndroid

- **Status:** Accepted
- **Task:** T-2.2b
- **Date:** 2026-09-16
- **Context:** Advancing Stage 2 (Refactoring & Decoupling) per `MIGRATION_LEDGER.md` §Stage 2 by migrating 6 `PlatformViewAndroid` overrides to delegate forwarding: `HandlePlatformMessage`, `OnPreEngineRestart`, `RequestDartDeferredLibrary`, `LoadDartDeferredLibrary`, `LoadDartDeferredLibraryError`, and `UpdateAssetResolverByType`.

---

## 1. Problem Statement
In `PlatformViewAndroid`, methods overridden from `PlatformView` directly invoke Android JNI facade methods, message handlers, or the delegate object.
To prepare for breaking the `PlatformViewAndroid : PlatformView` inheritance in T-2.4 and delegating to `PlatformViewEmbedder` in T-2.3, each override must be routed through the `platform_view_` delegate seam established in T-2.1 when a delegate is registered, while falling back to the existing implementation when `platform_view_ == nullptr`.

Per `MIGRATION_LEDGER.md` §Stage 2:
- T-2.2 migrates overrides to delegate forwarding in batches of ~3–5 methods per PR.
- T-2.2a covered the first batch (semantics, locale, and font scaling overrides).
- T-2.2b covers the second batch: messaging, restart, deferred library, and asset resolver overrides.

Governing invariant: Stage 2 changes NO behavior. All Stage 0 characterization tests must pass unmodified.

---

## 2. Technical Solution
1. **Migrated Methods:**
   - `HandlePlatformMessage(std::unique_ptr<flutter::PlatformMessage> message)`
     - When `platform_view_ != nullptr`: delegates to `platform_view_->HandlePlatformMessage(std::move(message))`.
     - Fallback: delegates to `platform_message_handler_->HandlePlatformMessage(std::move(message))`.
   - `OnPreEngineRestart() const`
     - When `platform_view_ != nullptr`: delegates to `platform_view_->OnPreEngineRestart()`.
     - Fallback: invokes `jni_facade_->FlutterViewOnPreEngineRestart()`.
   - `RequestDartDeferredLibrary(intptr_t loading_unit_id)`
     - When `platform_view_ != nullptr`: delegates to `platform_view_->RequestDartDeferredLibrary(loading_unit_id)`.
     - Fallback: invokes `jni_facade_->RequestDartDeferredLibrary(loading_unit_id)`.
   - `LoadDartDeferredLibrary(intptr_t loading_unit_id, std::unique_ptr<const fml::Mapping> snapshot_data, std::unique_ptr<const fml::Mapping> snapshot_instructions)`
     - When `platform_view_ != nullptr`: delegates to `platform_view_->LoadDartDeferredLibrary(loading_unit_id, std::move(snapshot_data), std::move(snapshot_instructions))`.
     - Fallback: invokes `delegate_.LoadDartDeferredLibrary(loading_unit_id, std::move(snapshot_data), std::move(snapshot_instructions))`.
   - `LoadDartDeferredLibraryError(intptr_t loading_unit_id, const std::string error_message, bool transient)`
     - When `platform_view_ != nullptr`: delegates to `platform_view_->LoadDartDeferredLibraryError(loading_unit_id, error_message, transient)`.
     - Fallback: invokes `delegate_.LoadDartDeferredLibraryError(loading_unit_id, error_message, transient)`.
   - `UpdateAssetResolverByType(std::unique_ptr<AssetResolver> updated_asset_resolver, AssetResolver::AssetResolverType type)`
     - When `platform_view_ != nullptr`: delegates to `platform_view_->UpdateAssetResolverByType(std::move(updated_asset_resolver), type)`.
     - Fallback: invokes `delegate_.UpdateAssetResolverByType(std::move(updated_asset_resolver), type)`.

2. **Visibility Adjustment:**
   - `HandlePlatformMessage` and `OnPreEngineRestart` moved from `private` to `public` in `PlatformViewAndroid`, matching their visibility on base class `PlatformView`.

3. **Seam Verification:**
   - Extend `MockPlatformViewDelegate` in `platform_view_android_unittests.cc` to track invocations and arguments for these 6 methods.
   - Add unit tests verifying:
     - When `platform_view_` is set, calls to these 6 methods forward to the delegate.
     - When `platform_view_` is null, calls fall back to their default implementations.
