# DR-0042 — Replace SetViewportMetrics with FlutterEngineSendWindowMetricsEvent Seam behind Flag

- **Task:** T-3.2
- **Branch:** android-embedder-v8/t-3.2-window-metrics-embedder-api
- **Author role:** planner
- **Date:** 2026-09-16
- **Status:** accepted
- **Confidence:** firm

## Context
Per `MIGRATION_LEDGER.md` §Stage 3:
Stage 3 incrementally replaces internal engine calls with their Embedder API equivalents behind `--android-embedder-api`.
Task T-3.2 addresses:
```
platform_view_->SetViewportMetrics(view_id, metrics) -> FlutterEngineSendWindowMetricsEvent
```

Requirements for Stage 3 tasks:
1. Flagged: Legacy path remains 100% intact and reachable when `--android-embedder-api` is off.
2. The branch point carries `TRACE_EVENT` with the resolved path (`embedder_api` vs `legacy`).
3. Once migrated behind the flag, `platform_view_` usage is not dual-routed on the flag-on path.
4. Parity tests verify both flag states.

## Decision
1. Declare `FlutterEngineResult SendWindowMetricsEvent(const FlutterWindowMetricsEvent* event)` in `PlatformViewAndroid`, matching the C-ABI `FlutterEngineSendWindowMetricsEvent` signature and returning `FlutterEngineResult`.
2. In `PlatformViewAndroid::SetViewportMetrics`:
   - If `android_embedder_api_` is true:
     Convert `ViewportMetrics` to `FlutterWindowMetricsEvent` and dispatch through `SendWindowMetricsEvent`, emitting `TRACE_EVENT1("flutter", "PlatformViewAndroid::SetViewportMetrics", "path", "embedder_api")`.
   - If `android_embedder_api_` is false:
     Forward directly to `platform_view_->SetViewportMetrics(view_id, metrics)`, emitting `TRACE_EVENT1("flutter", "PlatformViewAndroid::SetViewportMetrics", "path", "legacy")`.
3. In `PlatformViewAndroid::SendWindowMetricsEvent`:
   - Validate input parameters (`event != nullptr`, `event->struct_size == sizeof(FlutterWindowMetricsEvent)`, dimension bounds, padding/inset bounds, etc.), returning `kInvalidArguments` on error.
   - Reconstruct `ViewportMetrics` from `FlutterWindowMetricsEvent` and forward to `platform_view_->SetViewportMetrics(view_id, metrics)`, returning `kSuccess`.
4. Add unit tests in `platform_view_android_unittests.cc`:
   - `WindowMetricsDispatchLegacyPath`: Assert that with flag off, legacy delegate `OnPlatformViewSetViewportMetrics` is invoked directly.
   - `WindowMetricsDispatchEmbedderApiPath`: Assert that with flag on, dispatch routes through `SendWindowMetricsEvent` to update delegate metrics without dual-routing.
   - `SendWindowMetricsEventValidation`: Assert `kInvalidArguments` on null/invalid inputs and `kSuccess` on valid inputs.

## Consequences
- Viewport metrics handling conforms to the `FlutterEngineSendWindowMetricsEvent` C-ABI shape.
- Strict isolation between flag states; zero regression risk with flag off.
- Dependency ratchet remains <= baseline (63 deps, 121 includes, 0 nogncheck).
