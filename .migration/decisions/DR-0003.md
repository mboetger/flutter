# DR-0003: Task Size constraint enforces splitting T-0.15

**Status:** superseded by DR-0004

**Date:** 2026-09-15
**Task:** T-0.15

## Context
Task T-0.15 calls for constructing a robust Dart-based testing gate execution script, including pipeline validations (`--check-artifact-sha`), `--audit-stack` history walking, verification artifact schemas, device lock interactions (`--device-lock`), and `--summary` creation. Invariant I-7 strictly enforces a 400-line diff cap.

## Decision
Evaluating this complexity against I-7, it is impossible to securely implement and provide testing coverage within a single 400-line budget. We decide to split the task into:
- **T-0.15a**: Core verification gate commands, artifact writing, summary logic, and dirty tree check.
- **T-0.15b**: Advanced pipeline checks, `origin` tree stack auditing, and device block/flock.
