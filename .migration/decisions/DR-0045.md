# DR-0045 — Replace SetAccessibilityFeatures with FlutterEngineUpdateAccessibilityFeatures Seam behind Flag

- **Task:** T-3.5
- **Branch:** android-embedder-v8/t-3.5-accessibility-features-embedder-api
- **Author role:** planner
- **Date:** 2026-09-16
- **Status:** accepted
- **Confidence:** firm

## Context
Per `MIGRATION_LEDGER.md` §Stage 3:
Stage 3 incrementally replaces internal engine calls with their Embedder API equivalents behind `--android-embedder-api`.
Task T-3.5 addresses:
```
platform_view_->SetAccessibilityFeatures(flags) -> FlutterEngineUpdateAccessibilityFeatures
```

Requirements for Stage 3 tasks:
1. Flagged: Legacy path remains 100% intact and reachable when `--android-embedder-api` is off.
2. The branch point carries `TRACE_EVENT` with the resolved path (`embedder_api` vs `legacy`).
3. Once migrated behind the flag, `platform_view_` usage is not dual-routed on the flag-on path.
4. Parity tests verify both flag states.

## Decision
1. Declare `FlutterEngineResult UpdateAccessibilityFeatures(FlutterAccessibilityFeature features)` in `PlatformViewAndroid`, matching the C-ABI `FlutterEngineUpdateAccessibilityFeatures` signature and returning `FlutterEngineResult`.
2. In `PlatformViewAndroid::SetAccessibilityFeatures(int32_t flags)`:
   - If `android_embedder_api_` is true:
     Emit `TRACE_EVENT1("flutter", "PlatformViewAndroid::SetAccessibilityFeatures", "path", "embedder_api")` and route through `UpdateAccessibilityFeatures(static_cast<FlutterAccessibilityFeature>(flags))`.
   - If `android_embedder_api_` is false:
     Emit `TRACE_EVENT1("flutter", "PlatformViewAndroid::SetAccessibilityFeatures", "path", "legacy")` and forward directly to `platform_view_->SetAccessibilityFeatures(flags)`.
3. In `PlatformViewAndroid::UpdateAccessibilityFeatures(FlutterAccessibilityFeature features)`:
   - Forward to `platform_view_->SetAccessibilityFeatures(static_cast<int32_t>(features))` and return `kSuccess`.
4. Add unit tests in `platform_view_android_unittests.cc`:
   - `AccessibilityFeaturesDispatchLegacyPath`: Assert that with flag off, delegate `OnPlatformViewSetAccessibilityFeatures` is invoked directly.
   - `AccessibilityFeaturesDispatchEmbedderApiPath`: Assert that with flag on, delegate `OnPlatformViewSetAccessibilityFeatures` is invoked via `UpdateAccessibilityFeatures` without dual-routing.
   - `UpdateAccessibilityFeaturesDirect`: Assert direct invocation of `UpdateAccessibilityFeatures` updates the delegate and returns `kSuccess`.

## Consequences
- Accessibility feature flags management conforms to the `FlutterEngineUpdateAccessibilityFeatures` C-ABI shape.
- Strict isolation between flag states; zero regression risk with flag off.
- Dependency ratchet remains <= baseline (63 deps, 121 includes, 0 nogncheck).
