# DR-0014: Secure Workspace Telemetry & Directory Traversal Prevention

**Date:** 2026-09-15
**Task:** T-0.15a
**Status:** Active (Supersedes DR-0013)

## Context
DR-0013 permitted uncommitted `.migration/` artifacts to coexist dynamically without crashing pipeline validation (the Smart Dirty-Tree feature). However, naive string-matching path policies (e.g. `path.contains('.migration/')`) could be trivially bypassed by malicious subagents appending the string in arbitrary file paths or leveraging Git Rename (`R`) indicators to overwrite external directories legally.

## Decision
1. **Absolute Root Enforcements**: Uncommitted file evaluations against `git status --porcelain` MUST assert robust root-bindings. All output paths must strictly start with precisely the string `".migration/"` (or directory equivalent parsing) relative to the repository root.
2. **Rename Vectors Banned**: Any Git porcelain Rename (`R`) or Copy (`C`) lines must evaluate both the origin AND destination path segments securely against the `.migration/` absolute prefix.
3. **Fail Closed**: Any unrecognised status tokens, arbitrary subdirectory manipulations (e.g., `lib/ui/.migration/hack.cc`), or paths navigating backwards via `../` MUST immediately fail closed aggressively terminating execution.
