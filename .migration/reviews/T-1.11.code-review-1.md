# Code Review: T-1.11 — Embedder API: FlutterEngineSpawn

- **Reviewer:** Code Reviewer (Embedder API & Core Engine Architecture)

- **Verdict:** **APPROVE**

## 1. Summary of Changes Under Review
Task T-1.11 implements `FlutterEngineSpawn` in the Embedder API, fulfilling the requirements of Blocker B-6 and DR-0023:
1. `engine/src/flutter/shell/platform/embedder/embedder.h`:
   - Moved `FlutterGpuAvailability` enum definition above `#ifndef FLUTTER_ENGINE_NO_PROTOTYPES` to ensure it is visible when compiling proc-table consumer code.
   - Defined `FlutterEngineSpawnConfig` info-struct adhering to the standard C-API pattern:
     ```c
     typedef struct {
       size_t struct_size;
       const char* entrypoint;
       const char* library_path;
       const char* initial_route;
       int64_t argc;
       const char* const* argv;
       void* user_data;
       const FlutterProjectArgs* custom_args;
       const FlutterRendererConfig* custom_renderer_config;
     } FlutterEngineSpawnConfig;
     ```
   - Declared C-API export `FlutterEngineSpawn`.
   - Defined function pointer type `FlutterEngineSpawnFnPtr` and appended `FlutterEngineSpawnFnPtr Spawn;` to `FlutterEngineProcTable`.
2. `engine/src/flutter/shell/platform/embedder/embedder.cc`:
   - Factored reusable helper functions: `CreatePlatformDispatchTable`, `CreateExternalTextureResolver`, and `ApplyCustomArgsToRunConfiguration` to share setup logic cleanly between `FlutterEngineInitialize` and `FlutterEngineSpawn`.
   - Updated `FlutterEngineInitialize` to pass `*config` and `user_data` into `EmbedderEngine`.
   - Implemented `FlutterEngineSpawn` with comprehensive parameter validation (null checks, engine validity, platform thread affinity, struct_size > 0 via `SAFE_ACCESS`), run configuration population (entrypoint, library path, initial route, command line arguments), and invocation of `parent_engine->Spawn(...)`.
   - Registered `SET_PROC(Spawn, FlutterEngineSpawn)` in `FlutterEngineGetProcAddresses`.
   - Corrected `SetLabel` call on `impeller::Texture*` for Impeller Vulkan backing store.
3. `engine/src/flutter/shell/platform/embedder/embedder_engine.{h,cc}`:
   - Changed `thread_host_` storage from `std::unique_ptr<EmbedderThreadHost>` to `std::shared_ptr<EmbedderThreadHost>` to enable safe thread host sharing between parent and spawned engines.
   - Stored `renderer_config_` and `user_data_` to support context and configuration inheritance.
   - Implemented `EmbedderEngine::Spawn(...)` forwarding to `shell_->Spawn(...)` and dispatching platform view notifications.
   - Implemented out-of-order teardown safety in `CollectThreadHost()`: using `thread_host_teardown_mutex`, if `thread_host_.use_count() > 1`, the engine simply resets its shared pointer without invalidating task runners. Only the last surviving engine invalidates task runners and joins threads.
   - Routed `UpdateAssetResolverByType` and `LoadDartDeferredLibrary` through `static_cast<PlatformView::Delegate&>(*shell_)`.
4. Supporting embedder fixes:
   - `platform_view_embedder.h`: Made `RequestDartDeferredLibrary` and `SetApplicationLocale` public to conform to `PlatformView` interface.
   - `embedder_external_texture_gl.cc`: Fixed `#include "flutter/display_list/dl_paint.h"`.
   - `embedder_external_texture_vk.cc`: Fixed `#include "flutter/fml/closure.h"` and initialized `desc.size = impeller::ISize(texture->width, texture->height)`.
   - `embedder_asset_resolver_unittests.cc`: Defined `kData` and `kDataSize` as `static constexpr` for uncaptured lambda compatibility.
   - `embedder_vk_unittests.cc`: Replaced `CREATE_FFI_LAMBDA` on C callback `SetVulkanExternalTextureFrameCallback` with static state and clean function pointer lambdas.
5. Host unit tests:
   - In `tests/embedder_unittests_proctable.cc`: Added `SpawnEngineProc` asserting `procs.Spawn != nullptr`.
   - In `tests/embedder_unittests.cc`: Added `SpawnEngine`, `SpawnEngineWithArgs`, `SpawnEngineOutOfOrderShutdownParentFirst`, `SpawnMultipleEngines`, `SpawnEngineSafeAccessTruncatedStruct`, and `SpawnEngineInvalidArguments`.

## 2. Invariant & Safety Audit
