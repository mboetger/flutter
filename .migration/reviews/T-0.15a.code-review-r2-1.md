**3. Execution Provenance Spoofable via PATH (`which` Command)**
**What is wrong:** `RealSystemCommandExecutor` correctly utilizes `Process.run` utilizing `includeParentEnvironment: false` on the actual resolved gate execution. However, it resolves the absolute path of implicit binaries using `io.Process.run('which', [executable])` which inherently defaults to `includeParentEnvironment: true`. This allows arbitrary environment inheritance! An implementer can trivially inject a mock script into their `PATH` causing `which` to resolve to the fake bin and blindly execute.
**Evidence:** Running `PATH=/tmp/fakepath2:$PATH dart dev/tools/bin/migration_verify.dart --task T-0.15 --gates my_devicelab` allowed an uncommitted payload script to execute natively and output a clean JSON verification artifact with `"ran": true, "passed": true`.
**Resolution:** Explicitly disable parent environment injection when invoking `which` (e.g., `io.Process.run('which', [...], includeParentEnvironment: false, environment: _getSafeEnvironment())`).
