# Code Review: T-1.10 — OpenGL: UV Transform Matrix & Platform Views on GLES

- **Reviewer:** Code Reviewer (Embedder API & Android Graphics Architecture)
- **Date:** 2026-09-16
- **Verdict:** **APPROVE**

## 1. Summary of Changes Under Review
Task T-1.10 closes the critical external texture UV transformation gap and Impeller GLES platform view backing-store gap identified in Blocker B-5 and DR-0022:
1. `engine/src/flutter/shell/platform/embedder/embedder.h`:
   - Appended `double transformation[16]` to `FlutterOpenGLTexture` representing a 4x4 UV transformation matrix in column-major order.
   - Comprehensive docstring explaining the column-major layout, coordinate conventions, and zero-initialization default behavior.
2. `engine/src/flutter/shell/platform/embedder/embedder_external_texture_gl.{h,cc}`:
   - Added `ExtractTransformation` helper to detect non-zero matrix values and construct a 4x4 `DlMatrix`.
   - Updated `ResolveTextureSkia` and `ResolveTextureImpeller` to capture the matrix into `last_transformation_`.
   - In `ResolveTextureImpeller`, mapped `GL_TEXTURE_EXTERNAL_OES` (0x8D65) target to `impeller::TextureType::kTextureExternalOES`.
   - In `Paint`, when `last_transformation_` is present and non-identity, applied inverted matrix with canvas orientation adjustment (`Translate(bounds.GetX(), bounds.GetY() + bounds.GetHeight())`, `Scale(bounds.GetWidth(), -bounds.GetHeight())`) via `DlColorSource::MakeImage(last_image_, ..., &transform)` and `canvas->DrawRect(DlRect::MakeWH(1, 1), paint)`.
   - Handled non-invertible matrices with error logging and early exit.
   - Reset `last_transformation_` on `MarkNewFrameAvailable`.
3. `engine/src/flutter/shell/platform/embedder/embedder.cc`:
   - Implemented `MakeRenderTargetFromBackingStoreImpeller` overload for `const FlutterOpenGLTexture* texture`.
   - Wrapped texture in `impeller::TextureGLES` with render target and shader read usage, color attachment, placeholder depth/stencil attachments, and destruction callback forwarding.
   - Wired `kFlutterOpenGLTargetTypeTexture` in `CreateEmbedderRenderTarget` to dispatch to `MakeRenderTargetFromBackingStoreImpeller` when `enable_impeller` is true.
4. `engine/src/flutter/shell/platform/embedder/tests/embedder_assertions.h`:
   - Updated `operator==` for `FlutterOpenGLTexture` to compare `width`, `height`, and all 16 `transformation` elements.
5. `engine/src/flutter/shell/platform/embedder/tests/embedder_unittests.cc`:
   - Added `RendererConfigOpenGLTextureTransformationFields` host test asserting default zero-initialization and matrix element assignment.
6. `engine/src/flutter/shell/platform/embedder/tests/embedder_gl_unittests.cc`:
   - Added `RenderTextureWithUVTransformation` asserting external texture rendering with a 90-degree UV rotation matrix.
   - Added `RenderTextureWithOESTargetImpeller` asserting `GL_TEXTURE_EXTERNAL_OES` target handling under Impeller GLES.
   - Added `PlatformViewWithOpenGLTextureBackingStoreImpeller` asserting platform view composition with OpenGL texture backing stores on Impeller GLES.
