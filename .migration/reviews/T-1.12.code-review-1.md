# Code Review: T-1.12 — Embedder API: Custom Task Runners & Thread Priority Setter

- **Reviewer:** Code Reviewer (Embedder API & Core Engine Architecture)
- **Date:** 2026-09-16
- **Verdict:** **APPROVE**

## 1. Summary of Changes Under Review
Task T-1.12 implements custom task runner enhancements and thread priority setter support in the Embedder API, fulfilling the requirements of `MIGRATION_PLAN.md` §1.12 and resolving the IO thread priority discrepancy noted in `MIGRATION_LEDGER.md` §T-0.3:

1. `engine/src/flutter/shell/platform/embedder/embedder.h`:
   - Added `FlutterThreadPrioritySetter` (`void (*)(FlutterThreadPriority)`) and `FlutterThreadPrioritySetterWithUserData` (`void (*)(FlutterThreadPriority, void*)`) callback typedefs.
   - Appended `priority`, `thread_priority_setter`, and `thread_priority_setter_with_user_data` to `FlutterTaskRunnerDescription`.
   - Appended `thread_priority_setter_with_user_data`, `user_data`, `io_task_runner`, and `io_thread_priority` to `FlutterCustomTaskRunners`.
   - All public additions maintain struct backward/forward compatibility. `FLUTTER_ENGINE_VERSION` remains at 1. No preprocessor conditionals in public C-ABI structs.

2. `engine/src/flutter/shell/platform/embedder/embedder_task_runner.{h,cc}`:
   - Added `thread_priority_setter` callback to `EmbedderTaskRunner::DispatchTable`.
   - Stored atomic `FlutterThreadPriority priority_` in `EmbedderTaskRunner`.
   - Implemented `GetThreadPriority()` and `SetThreadPriority(FlutterThreadPriority priority)`, notifying the dispatcher callback directly if on current thread or via `PostTask` if called from another thread.

3. `engine/src/flutter/shell/platform/embedder/embedder_thread_host.cc`:
   - In `CreateEmbedderTaskRunner`: Read `priority`, `thread_priority_setter`, and `thread_priority_setter_with_user_data` via `SAFE_ACCESS`. Configured `EmbedderTaskRunner::DispatchTable` with priority setter. If a priority setter is provided, immediately applied it on initialization (invoking directly if `RunsTasksOnCurrentThread()` or posting if not).
   - In `CreateEmbedderManagedThreadHost`: Validated `SAFE_ACCESS(custom_task_runners, struct_size, 0) > 0`. Supported custom `io_task_runner` embedder pair. Configured engine-managed IO thread config with `io_thread_priority` (`kNormal` vs default `kBackground`). Registered custom `io_task_runner` into `embedder_task_runners` set and identifier deduplication logic.

4. `engine/src/flutter/shell/platform/embedder/embedder.cc`:
   - Updated `thread_config_callback` in `FlutterEngineInitialize` to read `thread_priority_setter_with_user_data` and `thread_priority_setter` via `SAFE_ACCESS`, giving precedence to the user-data variant.

5. Test Harness & Unit Tests:
   - Updated `tests/embedder_config_builder.{h,cc}` with `SetIOTaskRunner`, `SetThreadPrioritySetter`, `SetThreadPrioritySetterWithUserData`, and `SetIOThreadPriority`.
   - Updated `tests/embedder_unittests_util.h` with priority setters on `EmbedderTestTaskRunner`.
   - Added 8 unit tests in `tests/embedder_unittests.cc`:
     - `CanSpecifyCustomIOTaskRunner`: Verifies custom embedder IO task runner execution during engine startup and runtime.
     - `CanSpecifyCustomTaskRunnerThreadPriorities`: Verifies custom task runner thread priority setter invocation.
     - `CanSpecifyCustomTaskRunnerThreadPriorityWithUserData`: Verifies contextual thread priority setter with user data.
     - `CanSetEngineThreadPrioritiesWithGlobalSetter`: Verifies global engine thread priority setter for engine-managed threads.
     - `CanSetEngineThreadPrioritiesWithUserDataSetter`: Verifies user-data engine thread priority setter for engine-managed threads.
     - `EngineManagedIOThreadPriorityConfig`: Verifies custom IO thread priority configuration (`kNormal`) on engine-managed IO thread.
     - `EmbedderTaskRunnerSetThreadPriorityAtRuntime`: Verifies dynamic thread priority changes and callback dispatch.
     - `CustomTaskRunnersSafeAccessTruncatedStruct`: Verifies backward compatibility when embedder passes truncated legacy struct.
