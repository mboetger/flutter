# Code Review: T-1.14 — Engine-Independent Dart Callback Cache

- **Reviewer:** Code Reviewer (Embedder API & Core Engine Architecture)
- **Date:** 2026-09-16
- **Verdict:** **APPROVE**

## 1. Summary of Changes Under Review
Task T-1.14 introduces an engine-independent C-API for resolving Dart callback metadata from callback handles, fulfilling `MIGRATION_PLAN.md` §1.14:

1. `engine/src/flutter/lib/ui/plugins/callback_cache.{h,cc}`:
   - Added `DartCallbackCache::GetCallbackInformationPtr(int64_t handle)`.
   - Returns a `const DartCallbackRepresentation*` pointing directly to the entry in `cache_` under `mutex_` lock (or `nullptr` if not found).
   - Guarantees node pointer stability per C++ standard associative container rules (`std::map`).

2. `engine/src/flutter/shell/platform/embedder/embedder.h`:
   - Defined `FlutterCallbackInformation` struct containing `struct_size`, `callback_name`, `class_name`, and `library_path`.
   - Declared `FlutterEngineGetCallbackInformation` prototype.
   - Declared `FlutterEngineGetCallbackInformationFnPtr` typedef.
   - Appended `GetCallbackInformation` to `FlutterEngineProcTable`.
   - Maintained `FLUTTER_ENGINE_VERSION = 1` invariant.

3. `engine/src/flutter/shell/platform/embedder/embedder.cc`:
   - Implemented `FlutterEngineGetCallbackInformation`:
     - Checks null pointer for `info_out` (returning `kInvalidArguments`).
     - Validates `SAFE_ACCESS(info_out, struct_size, 0) == sizeof(FlutterCallbackInformation)` (returning `kInvalidArguments` on mismatch).
     - Looks up callback handle in `DartCallbackCache`. Returns `kInternalInconsistency` if not found.
     - Sets `info_out->callback_name`, `info_out->class_name`, and `info_out->library_path` using process-lifetime string pointers (per DR-0022).
   - Wired `SET_PROC(GetCallbackInformation, FlutterEngineGetCallbackInformation)` in `FlutterEngineGetProcAddresses`.

4. Test Suite (`tests/embedder_unittests.cc` & `tests/embedder_unittests_proctable.cc`):
   - Added 4 unit tests in `EmbedderTest`:
     - `CallbackInfoArgumentValidation`: verifies error codes on null pointer, truncated struct size, and non-existent handle.
     - `CallbackInfoLookupClassMethod`: verifies lookup of static class method callback representation.
     - `CallbackInfoLookupTopLevelFunction`: verifies lookup of top-level function callback representation.
     - `CallbackInfoProcTable`: verifies resolution via `FlutterEngineGetProcAddresses` and execution through proc table pointer.
   - `EmbedderProcTable.AllPointersProvided` and `NoDuplicatePointers` pass with 100% table coverage.

## 2. Invariant & Safety Audit
- **C-ABI Extensibility & Version Invariant:** `FLUTTER_ENGINE_VERSION` preserved at 1. `FlutterEngineProcTable` safely extended at the end.
- **Lifetime & Zero Leaks (DR-0022):** Returns string pointers with process lifetime directly from the static callback cache; avoids dynamic allocations and does not require a custom deallocation API.
- **Zero Android Contamination (I-10):** Pure C-ABI types only; zero Android types or NDK headers.
- **Thread Safety:** Access to internal `DartCallbackCache::cache_` is serialized with `std::scoped_lock lock(mutex_)`.
- **Formatting & Build:** Passed `ci/format.sh --fix` cleanly. All host unit tests pass.
