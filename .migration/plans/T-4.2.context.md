# Context: T-4.2 — Soak: Full Matrix + Devicelab, Three Consecutive Clean Runs, Flag On

## Problem Statement
With T-4.1 merged, the Android Embedder API path is enabled by default in the Flutter engine.
Before finalizing the public default (T-4.3) and deleting the legacy engine paths (T-4.5), Stage 4 requires a soak gate to verify that:
1. All 21 composition integration test mains continue to pass consistently across 3 consecutive runs under both OpenGLES and Impeller Vulkan backends.
2. All Devicelab correctness tasks pass with zero regressions.
3. Devicelab performance benchmarks (frame build time, 90th percentile rasterizer time, worst frame rasterizer time) remain within the noise bands established at baseline (T-0.12).
Task T-4.2 performs these evaluations and publishes the soak verification report in `engine/src/flutter/docs/android/embedder_migration_soak.md`.

## Scope of Changes
1. `engine/src/flutter/docs/android/embedder_migration_soak.md`:
   - Document the 3 consecutive clean soak runs of the 21 composition integration test mains across OpenGLES and Impeller Vulkan.
   - Document the devicelab correctness tasks results.
   - Document the performance metrics and compare against the T-0.12 baseline noise bands across all 6 targets.
   - Disclose the prototype gate limitations per §Stage 4 note.
2. `docs/platforms/android/embedder-api-migration/MIGRATION_LEDGER.md`:
   - Document T-4.2 status and completion of prototype soak gate.

## Non-goals
- Public default announcement (scheduled for T-4.3).
- Legacy path deletion (scheduled for T-4.5).
