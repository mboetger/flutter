## 1. Ground Truth Verification (§G Re-verification)
- `shell/platform/android/platform_view_android.cc:184-234`:
  - `NotifyCreated(native_window)`:
    - Posts synchronous task to raster runner: `surface->SetNativeWindow(native_window, jni_facade)`.
    - Calls `PlatformView::NotifyCreated()` -> `Shell::OnPlatformViewCreated()`.
  - `NotifySurfaceWindowChanged(native_window)`:
    - Posts synchronous task to raster runner: `surface->TeardownOnScreenContext()` followed by `surface->SetNativeWindow(native_window, jni_facade)`.
    - Calls `PlatformView::ScheduleFrame()`.
  - `NotifyDestroyed()`:
    - Calls `PlatformView::NotifyDestroyed()` -> `Shell::OnPlatformViewDestroyed()`.
    - Synchronously teardowns on-screen context on raster runner.
    - Synchronous completion is mandatory before Android framework `surfaceDestroyed()` returns.

  - `GpuAvailability`: `kAvailable`, `kFlushAndMakeUnavailable`, `kUnavailable`.
  - `Shell::SetGpuAvailability()`: Synchronously drains IO unref queue and toggles `is_gpu_disabled_sync_switch_`.

  - iOS calls `_shell->SetGpuAvailability` on app backgrounding/foregrounding to prevent Jetsam kills (`0x8badf00d`).
- `platform_view_android_surface_lifecycle_unittests.cc` (T-0.2 characterization):
  - Confirmed 6 surface lifecycle behaviors and thread affinities under test.

## 2. Core Blocker (B-2)
The Embedder API treats renderer configuration as an immutable, permanent property bound at `FlutterEngineInitialize`. On Android, `ANativeWindow` instances are destroyed whenever the app enters the background or a `FlutterView` is detached. Accessing a destroyed window crashes the process.
