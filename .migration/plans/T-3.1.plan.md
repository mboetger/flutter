# Implementation Plan: T-3.1 — Replace `DispatchPointerDataPacket` with `FlutterEngineSendPointerEvent` behind Flag

- **Task:** T-3.1
- **Target Files:**
  - `engine/src/flutter/shell/platform/android/platform_view_android.h`
  - `engine/src/flutter/shell/platform/android/platform_view_android.cc`
  - `engine/src/flutter/shell/platform/android/platform_view_android_unittests.cc`
- **Dependencies:** T-3.0
- **Decision Record:** DR-0041

---

## 1. Objectives
1. Implement `SendPointerEvents(const FlutterPointerEvent* events, size_t count)` on `PlatformViewAndroid`, matching the `FlutterEngineSendPointerEvent` Embedder API shape.
2. In `PlatformViewAndroid::DispatchPointerDataPacket`:
   - When `android_embedder_api_` is true: convert the `PointerDataPacket` to `FlutterPointerEvent`s and dispatch via `SendPointerEvents`, emitting `TRACE_EVENT1("flutter", "PlatformViewAndroid::DispatchPointerDataPacket", "path", "embedder_api")`. Do not invoke `platform_view_->DispatchPointerDataPacket` (no dual routing).
   - When `android_embedder_api_` is false: forward to `platform_view_->DispatchPointerDataPacket`, emitting `TRACE_EVENT1("flutter", "PlatformViewAndroid::DispatchPointerDataPacket", "path", "legacy")`.
3. Add unit tests verifying both flag states and input validation.

---

## 2. Implementation Steps

### 2.1 Header (`platform_view_android.h`)
Declare:
```cpp
FlutterEngineResult SendPointerEvents(
    const FlutterPointerEvent* events,
    size_t count);
```

### 2.2 Implementation (`platform_view_android.cc`)
1. Implement `SendPointerEvents`:
   - Validate `events != nullptr && count > 0`; return `kInvalidArguments` on failure.
   - Create `std::unique_ptr<PointerDataPacket> packet = std::make_unique<PointerDataPacket>(count);`.
   - Populate `PointerData` for each event using `SAFE_ACCESS` and standard phase/kind/signal mappings.
   - Dispatch to engine:
     If `platform_view_` exists, dispatch to it; otherwise complete successfully.
   - Return `kSuccess`.
2. Update `DispatchPointerDataPacket`:
   - If `android_embedder_api_`:
     - Trace: `TRACE_EVENT1("flutter", "PlatformViewAndroid::DispatchPointerDataPacket", "path", "embedder_api");`.
     - Convert packet data into `std::vector<FlutterPointerEvent>`.
     - Call `SendPointerEvents(events.data(), events.size());`.
   - Else:
     - Trace: `TRACE_EVENT1("flutter", "PlatformViewAndroid::DispatchPointerDataPacket", "path", "legacy");`.
     - If `platform_view_`: call `platform_view_->DispatchPointerDataPacket(std::move(packet));`.

### 2.3 Unit Tests (`platform_view_android_unittests.cc`)
1. Add `dispatch_pointer_data_packet_called` tracking to `MockPlatformViewDelegate`.
2. Add `TEST_F(PlatformViewAndroidTest, PointerDispatchLegacyPath)`:
   - With `settings.android_embedder_api = false`, calling `DispatchPointerDataPacket` invokes `platform_view_->DispatchPointerDataPacket`.
3. Add `TEST_F(PlatformViewAndroidTest, PointerDispatchEmbedderApiPath)`:
   - With `settings.android_embedder_api = true`, calling `DispatchPointerDataPacket` does NOT invoke `platform_view_->DispatchPointerDataPacket` (zero dual routing).
4. Add `TEST_F(PlatformViewAndroidTest, SendPointerEventsValidation)`:
   - Null pointer or 0 count returns `kInvalidArguments`.
   - Valid pointer event returns `kSuccess`.
