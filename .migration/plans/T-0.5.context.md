## 2. Four Candidates Analysis
1. **`kSoftware`**:
   - *Selection:* `--enable-software-rendering` switch, `FlutterEngineFlags.ENABLE_SOFTWARE_RENDERING`, or `FlutterShellArgs.ARG_ENABLE_SOFTWARE_RENDERING`.
   - *Implementation:* `AndroidSurfaceSoftware` draws into an `ANativeWindow` buffer using Skia's software rasterizer (`SkSurface::MakeRasterDirect`).
   - *Reachability:* Reachable in testing/emulator environments where GPU acceleration is disabled or unavailable (e.g. `FlutterActivityTestRule.java`).
   - *Impact if removed:* Breaks tests and emulators relying on software rasterization. Requires formal deprecation window and breaking-change process if removed.
2. **`kSkiaOpenGLES`**:
   - *Selection:* Active when `!settings.enable_impeller`, or when running on Android API level < 29 (Lollipop API 21 through Pie API 28), or on Vivante GPUs (`IsVivante()`).
   - *Implementation:* `AndroidContextGLSkia` and `AndroidSurfaceGLSkia`.
   - *Reachability:* Highly reachable on real devices. Flutter's supported Android `minSdkVersion` is currently 21. Devices running Android 5.0–9.0 do not enable Impeller and fall back to `kSkiaOpenGLES`.
   - *Impact if removed:* Breaking change: completely breaks Flutter apps on Android API 21–28 and devices with Vivante GPUs. Cannot be removed until Flutter officially drops support for API < 29 and completes the Impeller opt-out deprecation.
3. **`kImpellerAutoselect`**:
   - *Selection:* Default for Android API >= 29 with Impeller enabled.
   - *Implementation:* `AndroidContextDynamicImpeller` and `AndroidSurfaceDynamicImpeller`.
   - *Reachability:* Production default for all modern Android devices.
   - *Impact if removed:* Fatal. Interacts with Blocker B-1. Must survive.
4. **`kMergeAfterLaunch`**:
   - *Selection:* `--merged-platform-ui-thread=mergeAfterLaunch`.
   - *Reachability:* Used by internal clients. Explicitly preserved on the engine-switch route per plan §4.
   - *Impact if removed:* Breaks internal clients. Must not be deleted.
