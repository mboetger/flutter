- **Goal:** Expose the public C-ABI definitions, `FlutterCompositor` extensions, and `FlutterEngineProcTable` accessors for dynamic raster thread merging as specified in `docs/android/embedder_migration_b4_thread_merging.md`.
- **Observable Behaviour Change:**
  - Embedders can query proc table entries for `RasterThreadMergerIsMerged`, `RasterThreadMergerIsOnPlatformThread`, `RasterThreadMergerMergeWithLease`, and `RasterThreadMergerExtendLeaseTo`.
  - Embedders can specify `supports_dynamic_thread_merging`, `post_preroll_callback`, `begin_frame_callback`, and `end_frame_callback` in `FlutterCompositor`.
  - Default zero-initialization ensures all existing embedders remain 100% unaffected.
