## 3. Threat Model
Attempting to force an Implementer agent to run tests requiring hours of setup leads to repository sabotage or faked evidence. The tool fundamentally **cannot** detect if the target devicelab script is actively structurally modified in the repository (e.g. `sleep 3600; exit 0`). The mechanism fully relies on the Code Reviewer to catch modifications to the tool itself, and post-facto metric analysis via verification JSON logs detecting anomalous executions (such typically hour-long tests claiming success natively under a minute's time tracking).
