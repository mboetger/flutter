# T-0.10 Plan: CI Runner and Builder Configuration

## Goal
Implement CI and harness protections to guarantee that all Android embedder test targets run in CI, orphan executables cannot be added unnoticed, the dependency ratchet is strictly enforced, and an ASan test variant exists. Document all builder-to-target relationships in `engine/src/flutter/docs/android/embedder_ci_mapping.md`.

## Files Touched
- `engine/src/flutter/testing/run_tests.py` (add orphan check and ratchet check to test pipeline)
- `engine/src/flutter/ci/builders/linux_android_emulator.json` (add ASan emulator test variant)
- `engine/src/flutter/docs/android/embedder_ci_mapping.md` (new documentation deliverable)

## Implementation Sequence
1. Implement `check_android_embedder_contracts()` in `testing/run_tests.py`:
   - Inspect all `BUILD.gn` files in `shell/platform/android/` and subdirectories.
   - Extract `executable("...")` targets.
   - Assert each executable is referenced in `run_tests.py`.
   - Run `tools/android_embedder_deps.py --check`.
   - Wire into `run_tests.py` main execution when `--type android` or `--type engine` is specified.
2. Update `ci/builders/linux_android_emulator.json`:
   - Add build `ci/android_emulator_debug_x64_asan` with `--asan` flag in GN args.
   - Add test runner entry targeting the ASan variant.
3. Write `engine/src/flutter/docs/android/embedder_ci_mapping.md`:
   - Map each target (`flutter_shell_native_unittests`, `android_external_view_embedder_unittests`, `jni_unittests`, `platform_view_android_delegate_unittests`, Robolectric, integration tests) to its CI builder and runner invocation.
4. Validate:
   - Prove orphan check catches an unregistered executable and fails non-zero.
   - Prove ratchet check executes.
   - Format check with `./ci/format.sh`.
