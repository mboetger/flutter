# T-1.7 Plan: SetApplicationLocale Callback

## Goal
Extend the Embedder API (`embedder.h`), `PlatformViewEmbedder`, and `embedder.cc` so embedders can receive application-requested locale updates triggered from Dart via `PlatformDispatcher.instance.setApplicationLocale`.

## Files Touched
- `engine/src/flutter/shell/platform/embedder/embedder.h`
- `engine/src/flutter/shell/platform/embedder/embedder.cc`
- `engine/src/flutter/shell/platform/embedder/platform_view_embedder.h`
- `engine/src/flutter/shell/platform/embedder/platform_view_embedder.cc`
- `engine/src/flutter/shell/platform/embedder/platform_view_embedder_unittests.cc`
- `engine/src/flutter/shell/platform/embedder/fixtures/main.dart`
- `engine/src/flutter/shell/platform/embedder/tests/embedder_unittests.cc`

## Implementation Sequence
1. In `embedder.h`:
   - Declare callback type:
     ```c
     typedef void (*FlutterSetApplicationLocaleCallback)(const char* locale,
                                                         void* user_data);
     ```
   - Append `set_application_locale_callback` to `FlutterProjectArgs` with clear doc comments regarding thread affinity (platform task runner) and string lifetime (valid for duration of invocation).
   - Note: Do NOT bump `FLUTTER_ENGINE_VERSION` (§G.5, §G.9 Item 2).
2. In `platform_view_embedder.h` & `platform_view_embedder.cc`:
   - Add `using SetApplicationLocaleCallback = std::function<void(const std::string& locale)>;`
   - Add `SetApplicationLocaleCallback set_application_locale_callback;` to `PlatformDispatchTable`.
   - Override `void SetApplicationLocale(std::string locale) override;` in `PlatformViewEmbedder` to forward to the callback if non-null.
3. In `embedder.cc`:
   - Read `set_application_locale_callback` from `args` using `SAFE_ACCESS`.
   - Forward into `PlatformDispatchTable.set_application_locale_callback` capturing `user_data`.
4. In `platform_view_embedder_unittests.cc`:
   - Add `DispatchesSetApplicationLocale` testing that `SetApplicationLocale` calls the provided callback with the expected locale string.
   - Add `SetApplicationLocaleWithoutCallback` testing that `SetApplicationLocale` safely handles a null callback.
5. In `fixtures/main.dart` & `embedder_unittests.cc`:
   - Add `set_application_locale_main` in `fixtures/main.dart` calling `PlatformDispatcher.instance.setApplicationLocale(const Locale.fromSubtags(languageCode: 'pt', countryCode: 'BR'))`.
   - Add `CanReceiveApplicationLocale` test in `embedder_unittests.cc` ensuring end-to-end receipt of `"pt-BR"` on the native callback.
6. Verify & Ratchet:
   - Run `./ci/format.sh --fix`.
   - Run `migration_verify.dart --task T-1.7 --gates analysis,ratchet`.
