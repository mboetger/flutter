# Implementation Plan: T-2.4 — Break PlatformViewAndroid : PlatformView Inheritance

- **Task:** T-2.4
- **Target Files:**
  - `engine/src/flutter/shell/platform/android/platform_view_android.h`
  - `engine/src/flutter/shell/platform/android/platform_view_android.cc`
  - `engine/src/flutter/shell/platform/android/android_shell_holder.h`
  - `engine/src/flutter/shell/platform/android/android_shell_holder.cc`
  - `engine/src/flutter/shell/platform/android/android_shell_holder_unittests.cc`
- **Dependencies:** T-2.3

---

## 1. Objectives
- Remove `: public PlatformView` inheritance from `PlatformViewAndroid`.
- Store `task_runners_` and `weak_factory_` directly on `PlatformViewAndroid` if needed.
- `on_create_platform_view` returns `std::unique_ptr<PlatformView>` which is `platform_view_embedder`.
- `AndroidShellHolder` holds `std::unique_ptr<PlatformViewAndroid> platform_view_android_` (and `platform_view_` weak pointer).
- `PlatformViewAndroid` methods that send messages to the engine forward directly to `platform_view_` (`PlatformView*`).
- Retain exact baseline dependency ratchet counts (deps <= 26/63, includes <= 98/123, nogncheck: 0).
- Pass all unit tests in `flutter_shell_native_unittests`.

---

## 2. Implementation Steps

1. **`platform_view_android.h`**:
   - Change class declaration from `class PlatformViewAndroid final : public PlatformView` to `class PlatformViewAndroid final`.
   - Remove `PlatformView::Delegate& delegate` from constructors.
   - Store `const flutter::TaskRunners task_runners_;`.
   - Add `fml::WeakPtrFactory<PlatformViewAndroid> weak_factory_;` and `fml::WeakPtr<PlatformViewAndroid> GetWeakPtr();`.
   - Implement delegation methods on `PlatformViewAndroid` for:
     - `DispatchPointerDataPacket(std::unique_ptr<PointerDataPacket> packet)`
     - `SetViewportMetrics(int64_t view_id, const ViewportMetrics& metrics)`
     - `SetSemanticsEnabled(bool enabled)`
     - `UnregisterTexture(int64_t texture_id)`
     - `MarkTextureFrameAvailable(int64_t texture_id)`
   - Remove `override` keywords from methods previously inherited from `PlatformView`.

2. **`platform_view_android.cc`**:
   - Update constructors to initialize `task_runners_(task_runners)` and `weak_factory_(this)`.
   - Update methods to remove `PlatformView::...` base class calls and forward to `platform_view_->...`.

3. **`android_shell_holder.h` / `android_shell_holder.cc`**:
   - In `AndroidShellHolder::AndroidShellHolder`, construct `platform_view_android` as `std::make_unique<PlatformViewAndroid>(...)`.
   - Inside `on_create_platform_view`, construct `PlatformViewEmbedder`, wire `platform_view_android->SetPlatformView(platform_view_embedder.get())`, and return `platform_view_embedder` to `Shell`.
   - Store `std::unique_ptr<PlatformViewAndroid> platform_view_android_` in `AndroidShellHolder`.
   - Mirror this in `Spawn`.

4. **Testing (`android_shell_holder_unittests.cc`)**:
   - Verify `holder->GetPlatformView()` is non-null.
   - Verify `holder->GetPlatformView()->GetPlatformViewDelegate() != nullptr`.
   - Verify that all existing unit tests in `flutter_shell_native_unittests` pass.

5. **Build & Verify**:
   - `./ci/format.sh --fix`
   - `ninja -C out/android_debug_unopt_arm64 flutter_shell_native_unittests flutter_shell_native`
   - `python3 tools/android_embedder_deps.py --check`
   - `dart analyze --fatal-infos dev/tools/`
