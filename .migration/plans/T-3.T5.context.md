# Context: T-3.T5 — HCPP Composition Mode Migration behind Flag

## Problem Statement
The Flutter Android embedder supports multiple platform view composition modes: Texture Layer Hybrid Composition (TLHC), Virtual Display (VD), Hybrid Composition (HC), and Hybrid Composition Plus Plus (HCPP).
HCPP is an advanced platform view composition mode for Android (Impeller Vulkan + API 34+), utilizing `ASurfaceTransaction` and `AndroidExternalViewEmbedder2` to synchronize platform view display and transaction commit with Flutter frame rasterization.
In Stage 3 of the Android Embedder API migration, composition modes converge independently behind `--android-embedder-api`.
Task T-3.T5 migrates the HCPP mode to the embedder path while keeping the legacy path intact and reachable when the flag is disabled.
