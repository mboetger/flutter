## 1. Problem Statement & Motivation
In T-1.18a and T-1.18b, the dynamic raster thread merging C-API and engine implementation were added to `embedder.h`, `embedder.cc`, and `EmbedderExternalViewEmbedder`.
Per `MIGRATION_LEDGER.md` §T-1.18c:
- We must add host unit tests in `engine/src/flutter/shell/platform/embedder/tests/embedder_unittests.cc`.
- The tests must:
  1. Prove Invariant I-1 (null `post_preroll_callback` when `supports_dynamic_thread_merging = true` is an initialization error).
  2. Exercise `FlutterRasterThreadMerger*` C-API functions (`MergeWithLease`, `ExtendLeaseTo`, `IsMerged`, `IsOnPlatformThread`).
  3. Exercise all three `FlutterPostPrerollResult` values (`kFlutterPostPrerollResultSkipAndRetryFrame`, `kFlutterPostPrerollResultResubmitFrame`, `kFlutterPostPrerollResultSuccess`).
  4. Verify that `begin_frame_callback` and `end_frame_callback` are executed with valid `FlutterFrameThreadingInfo`.
  5. Prove inertness across existing tests.

---

## 2. Technical Solution
Add two comprehensive unit tests to `embedder_unittests.cc`:
1. `TEST_F(EmbedderTest, DynamicThreadMergingNullCallbackError)`:
   - Configures `supports_dynamic_thread_merging = true` and `post_preroll_callback = nullptr`.
   - Asserts `FlutterEngineInitialize` returns `kInvalidArguments`.
2. `TEST_F(EmbedderTest, DynamicThreadMergingLifecycle)`:
   - Configures `supports_dynamic_thread_merging = true` with callbacks.
   - Pushes frame through `render_implicit_view`.
   - Exercises all 3 post-preroll results and merger operations.
   - Validates invocation counts and threading info structure integrity.
