# T-1.11 Plan: FlutterEngineSpawn in Embedder C-API

## 1. Summary of Changes
1. **Define `FlutterEngineSpawnConfig` Info-Struct & `FlutterEngineSpawn` in `embedder.h`:**
   - Define `FlutterEngineSpawnConfig`:
     ```c
     typedef struct {
       size_t struct_size;
       const char* entrypoint;
       const char* library_path;
       const char* initial_route;
       int64_t argc;
       const char* const* argv;
       void* user_data;
       const FlutterProjectArgs* custom_args;
       const FlutterRendererConfig* custom_renderer_config;
     } FlutterEngineSpawnConfig;
     ```
   - Declare `FlutterEngineSpawn`:
     ```c
     FLUTTER_EXPORT
     FlutterEngineResult FlutterEngineSpawn(
         FLUTTER_API_SYMBOL(FlutterEngine) parent_engine,
         const FlutterEngineSpawnConfig* config,
         FLUTTER_API_SYMBOL(FlutterEngine) * engine_out);
     ```
   - Add `FlutterEngineSpawnFnPtr` and append `FlutterEngineSpawnFnPtr Spawn;` to `FlutterEngineProcTable`.
   - Relocate `FlutterGpuAvailability` enum before `#ifndef FLUTTER_ENGINE_NO_PROTOTYPES` to maintain type visibility for proc-table consumers.

2. **Implement `FlutterEngineSpawn` & Helpers in `embedder.cc`:**
   - Validate `parent_engine != nullptr`, `parent_engine->IsValid()`, platform thread affinity, `engine_out != nullptr`, and `config != nullptr && SAFE_ACCESS(config, struct_size, 0) > 0`.
   - Access all configuration fields strictly via `SAFE_ACCESS(config, ...)`. Never check `config->struct_size < sizeof(...)`.
   - Support inherited or custom renderer config (`custom_renderer_config`).
   - Factor out and reuse `CreatePlatformDispatchTable`, `CreateExternalTextureResolver`, and `ApplyCustomArgsToRunConfiguration` across `FlutterEngineInitialize` and `FlutterEngineSpawn`.
   - Wire `initial_route`, `entrypoint`, `library_path`, `argc`, `argv` to `RunConfiguration`.
   - Call `parent_embedder_engine->Spawn(...)` and export spawned engine handle.
   - Wire `Spawn` proc in `FlutterEngineGetProcAddresses`.
   - Fix `SetLabel` access on `impeller::Texture` for Impeller Vulkan backing store.

3. **Extend `EmbedderEngine` for Multi-Engine Lifecycles (`embedder_engine.{h,cc}`):**
   - Store `thread_host_` as `std::shared_ptr<EmbedderThreadHost>`.
   - Store `renderer_config_` (`std::optional<FlutterRendererConfig>`) and `user_data_` (`void*`) to enable context inheritance in spawned engines.
   - Add spawned engine constructor and `EmbedderEngine::Spawn(...)`.
   - In `CollectThreadHost()`: guard with mutex and check `thread_host_.use_count() > 1` before tearing down; only the final surviving engine invalidates runners and joins thread hosts.
   - Access `UpdateAssetResolverByType` and `LoadDartDeferredLibrary` via `PlatformView::Delegate` interface to respect access control.
   - Correct `#include` directives in `embedder_external_texture_gl.cc` (`dl_paint.h`) and `embedder_external_texture_vk.cc` (`closure.h`).

4. **Add Comprehensive Host Unit Tests (`tests/embedder_unittests.cc`, `tests/embedder_unittests_proctable.cc`):**
   - `SpawnEngine`: Launch parent engine, spawn child engine with custom entrypoint and `initial_route`, verify running state and clean shutdown.
   - `SpawnEngineOutOfOrderShutdown`: Verify parent engine can be shut down before child engine without crashes, deadlocks, or thread invalidation errors.
   - `SpawnEngineSafeAccessTruncatedStruct`: Pass truncated `FlutterEngineSpawnConfig` with reduced `struct_size`, confirming forward/backward compatibility via `SAFE_ACCESS`.
   - `EmbedderProcTable.Spawn`: Verify `procs.Spawn` is non-null and equal to `&FlutterEngineSpawn`.
