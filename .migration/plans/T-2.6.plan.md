## 3. Detailed Steps
1. **Update `APKAssetProvider` (`apk_asset_provider.h` and `apk_asset_provider.cc`):**
   - Add `#include "flutter/shell/platform/embedder/embedder.h"` (allowed header in `tools/android_embedder_deps.py`).
   - Add member `FlutterAssetResolver flutter_asset_resolver_ = {};`.
   - Initialize `flutter_asset_resolver_` in constructor:
     - `struct_size = sizeof(FlutterAssetResolver)`
     - `user_data = impl_.get()`
     - `type = kFlutterAssetResolverTypeAPK`
     - `get_asset_callback` allocates `FlutterMapping` with custom `release_callback` deleting the `fml::Mapping`.
     - `is_valid_after_asset_manager_change = [](void*) { return true; }`
   - Add getter `const FlutterAssetResolver* GetFlutterAssetResolver() const;`.
   - Ensure `Clone()` preserves a valid `FlutterAssetResolver` pointing to the cloned provider's `impl_`.

2. **Update `AndroidShellHolder` (`android_shell_holder.h`):**
   - Expose `const FlutterAssetResolver* GetAssetResolverForTesting() const` returning `apk_asset_provider_->GetFlutterAssetResolver()`.

3. **Unit Tests in `apk_asset_provider_unittests.cc`:**
   - Test `FlutterAssetResolver` structure verification: `struct_size`, `type`, non-null callbacks.
   - Test asset resolution via `get_asset_callback` returning `FlutterMapping`, verifying buffer contents, length, and proper cleanup via `release_callback`.
   - Test failed resolution returns `false`.
   - Test full roundtrip: `APKAssetProvider` -> `FlutterAssetResolver` -> `EmbedderAssetResolver` -> `fml::Mapping`.
   - Test `AndroidShellHolder` integration.

4. **Formatting & Validation:**
   - Run `./ci/format.sh --fix`.
   - Run `python3 tools/android_embedder_deps.py --check`.
   - Compile and verify with `ninja -C out/android_debug_unopt_arm64 flutter_shell_native_unittests flutter_shell_native`.
