# Context Pack: T-2.4 — Break PlatformViewAndroid : PlatformView Inheritance

## Task Metadata
- **Task:** T-2.4
- **Branch:** `android-embedder-v8/t-2.4-break-platform-view-inheritance`
- **Depends On:** T-2.3
- **Primary Goal:** Sever `PlatformViewAndroid : PlatformView` inheritance, making `PlatformViewAndroid` an independent platform class while having `Shell` own `PlatformViewEmbedder` as its `PlatformView`.

## Key Files in Scope
- `engine/src/flutter/shell/platform/android/platform_view_android.h`
- `engine/src/flutter/shell/platform/android/platform_view_android.cc`
- `engine/src/flutter/shell/platform/android/android_shell_holder.h`
- `engine/src/flutter/shell/platform/android/android_shell_holder.cc`
- `engine/src/flutter/shell/platform/android/android_shell_holder_unittests.cc`

## Architectural Context
- In T-2.3, `PlatformViewEmbedder` was constructed and wired into `PlatformViewAndroid::SetPlatformView`.
- In T-2.4, `PlatformViewAndroid` no longer inherits `PlatformView`.
- `Shell::Create`'s `on_create_platform_view` returns `std::unique_ptr<PlatformView>` which is `platform_view_embedder`.
- `AndroidShellHolder` directly owns `std::unique_ptr<PlatformViewAndroid> platform_view_android_` (and exposes `fml::WeakPtr<PlatformViewAndroid> GetPlatformView()`).
- All JNI dispatch methods on `PlatformViewAndroid` invoke the corresponding methods on `platform_view_` (`PlatformViewEmbedder`).
