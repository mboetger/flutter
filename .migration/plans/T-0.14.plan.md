# T-0.14 Plan: External Texture Inventory (Blocker B-5)

## Goal
Audit all 6 native Android external texture implementations against the existing Embedder API (`embedder.h`), resolve the UV transformation matrix and Vulkan external texture gaps, map Java-side public API contracts, and define the Stage 1 implementation tasks.

## Files Touched
- `engine/src/flutter/docs/android/embedder_external_texture_gaps.md` (new)

## Implementation Sequence
1. Audit the six implementations in `shell/platform/android`:
   - `SurfaceTextureExternalTextureGLSkia`
   - `SurfaceTextureExternalTextureGLImpeller`
   - `SurfaceTextureExternalTextureVKImpeller`
   - `ImageExternalTextureGLSkia`
   - `ImageExternalTextureGLImpeller`
   - `ImageExternalTextureVKImpeller`
2. Catalog JNI dependencies and native buffer interactions:
   - `SurfaceTextureAttachToGLContext`, `SurfaceTextureUpdateTexImage`, `SurfaceTextureGetTransformMatrix`, `SurfaceTextureDetachFromGLContext`.
   - `ImageProducerTextureEntryAcquireLatestImage`, `ImageGetHardwareBuffer`, `HardwareBufferClose`.
   - `AHardwareBuffer` EGL/Vulkan imports and fence synchronization.
3. Analyze Embedder API expressiveness:
   - Identify absence of UV transform matrix in `FlutterOpenGLTexture` (required for rotation, crop, flip).
   - Identify absence of Vulkan external texture callback in `FlutterVulkanRendererConfig`.
   - Identify `GL_TEXTURE_EXTERNAL_OES` target handling and sampling.
   - Address `ImageLRU` cache lifecycle and surface recycling.
4. Enumerate public Java `TextureRegistry` APIs:
   - `createSurfaceTexture()`, `createSurfaceProducer()`, `createImageTexture()`, and `SurfaceProducer.Callback`.
5. Specify C-ABI extensions and Stage 1 tasks:
   - Task T-1.19: Add UV transform matrix to external texture C-ABI.
   - Task T-1.20: Add Vulkan external texture frame callback to `FlutterVulkanRendererConfig`.
   - Task T-1.21: Wire Android `TextureRegistry` implementation through Embedder API external texture mechanics.
