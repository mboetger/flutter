# Context Pack: T-2.5 — Extract Thread Configuration into Standalone Unit Matching FlutterCustomTaskRunners Shape

## Task Metadata
- **Task:** T-2.5
- **Branch:** `android-embedder-v8/t-2.5-extract-thread-configuration`
- **Depends On:** T-0.3, T-1.12
- **Primary Goal:** Extract thread configuration from `AndroidShellHolder` into a standalone unit (`AndroidTaskRunners`) that provides `flutter::TaskRunners` to `Shell` and exposes the `FlutterCustomTaskRunners` Embedder API shape with the Android priority setter contract.

## Architectural Context
- In T-0.3, characterization tests established the Stage 3 parity contract for Android thread priorities: UI (-1), Raster (-5 with -2 fallback), IO (0 / kNormal), Platform/Worker (0).
- In T-1.12, the Embedder API was extended with `FlutterThreadPrioritySetter`, `io_thread_priority`, and custom task runners support in `embedder.h`.
- In T-2.5, thread management is decoupled from `AndroidShellHolder` into `AndroidTaskRunners`.
- `AndroidTaskRunners` encapsulates `ThreadHost` creation, priority configuration, and task runner resolution.
- `AndroidTaskRunners` exposes both `flutter::TaskRunners` (used by `Shell` in Stage 2) and `FlutterCustomTaskRunners` (used in T-2.8 / Stage 3).
- All characterization tests in `android_threading_unittests.cc` pass without modification.
