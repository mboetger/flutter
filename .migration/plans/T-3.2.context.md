# Context: T-3.2 — Replace `platform_view_->SetViewportMetrics(view_id, metrics)` with `FlutterEngineSendWindowMetricsEvent` behind Flag

## Problem Statement
In the legacy Android embedding, viewport metrics (screen dimensions, insets, paddings, display cutouts, and corner radii) are delivered from Java via JNI (`nativeSetViewportMetrics`) directly to `PlatformViewAndroid::SetViewportMetrics(int64_t view_id, const ViewportMetrics& metrics)` which calls `platform_view_->SetViewportMetrics(view_id, metrics)`.
In the standard Flutter Embedder API, window metrics updates are delivered via `FlutterEngineSendWindowMetricsEvent(engine, &window_metrics_event)`.

## Scope of Changes
1. `engine/src/flutter/shell/platform/android/platform_view_android.h`:
   - Declare `FlutterEngineResult SendWindowMetricsEvent(const FlutterWindowMetricsEvent* event);`
2. `engine/src/flutter/shell/platform/android/platform_view_android.cc`:
   - Update `SetViewportMetrics` to branch on `android_embedder_api_`.
   - On the flag-on path, emit `TRACE_EVENT1("flutter", "PlatformViewAndroid::SetViewportMetrics", "path", "embedder_api")`, convert `flutter::ViewportMetrics` to `FlutterWindowMetricsEvent`, and call `SendWindowMetricsEvent`.
   - On the legacy path, emit `TRACE_EVENT1("flutter", "PlatformViewAndroid::SetViewportMetrics", "path", "legacy")`, and call `platform_view_->SetViewportMetrics(view_id, metrics)`.
   - Implement `SendWindowMetricsEvent(const FlutterWindowMetricsEvent* event)`.
3. `engine/src/flutter/shell/platform/android/platform_view_android_unittests.cc`:
   - Update `FakePlatformViewDelegate` to capture `set_viewport_metrics_called`, `last_view_id`, and `last_viewport_metrics`.
   - Add unit tests verifying legacy dispatch, embedder dispatch, and parameter validation.

## Non-goals
- Modifying JNI signatures or Java-side `FlutterRenderer` methods in this task.
- Introducing `EmbedderEngine` initialization (scheduled for T-3.7).
