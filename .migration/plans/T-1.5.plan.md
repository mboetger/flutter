# T-1.5 Plan: Semantics Node Field Gaps

## Goal
Extend `FlutterSemanticsNode2` in the Embedder API (`embedder.h`) to bridge the 10 semantic field gaps between `flutter::SemanticsNode` and `FlutterSemanticsNode2`:
1. `max_value_length`: maximum length limit for editable text (-1 if no limit)
2. `current_value_length`: current character count in editable text (-1 if no limit)
3. `traversal_parent`: ID of parent node for accessibility traversal
4. `min_value`: minimum value for range-based semantics
5. `max_value`: maximum value for range-based semantics
6. `hit_test_transform`: 4x4 transform applied during hit testing
7. `link_url`: URL that the node links to
8. `role`: semantic role (`FlutterSemanticsRole`)
9. `validation_result`: input validation status (`FlutterSemanticsValidationResult`)
10. `locale`: BCP 47 locale string of node content

Expose `FlutterSemanticsRole` and `FlutterSemanticsValidationResult` enums. Populate these fields in `EmbedderSemanticsUpdate2::AddNode` in `embedder_semantics_update.cc`. Add thorough unit tests in `embedder_a11y_unittests.cc` asserting that each new field correctly round-trips non-default and default values.
