## 1. Goal & Observable Behaviour Change
- **Goal:** Decouple Android's screenshot mechanism (`FlutterJNI.getBitmap()`) from `flutter::Shell` and `flutter::Rasterizer`. Implement direct surface pixel readback in Android platform code (`AndroidSurface` and `PlatformViewAndroid`), matching the macOS platform pattern without adding screenshot APIs to `embedder.h`.
- **Observable Behaviour Change:** Preserves existing bitmap capture behaviour while breaking the architectural coupling to `Rasterizer`. Existing Java/JNI consumers (`FlutterRenderer.getBitmap()`) continue functioning identically.

## 3. Implementation Sequence
1. **`AndroidSurface` Base Definition:**
   - In `surface/android_surface.h`:
     ```cpp
     #include "third_party/skia/include/core/SkData.h"
     ...
     struct Screenshot {
       sk_sp<SkData> data;
       DlISize frame_size;
     };
     virtual Screenshot Screenshot();
     ```
   - In `surface/android_surface.cc`:
     ```cpp
     AndroidSurface::Screenshot AndroidSurface::Screenshot() {
       return {};
     }
     ```
2. **`AndroidSurfaceSoftware` Implementation:**
   - Query `sk_surface_->imageInfo()`. If dimensions invalid, return empty screenshot.
   - Allocate `SkData::MakeUninitialized(...)` for `kRGBA_8888_SkColorType`, `kPremul_SkAlphaType`.
   - Invoke `sk_surface_->readPixels(...)`.
3. **`AndroidSurfaceGLSkia` & `AndroidSurfaceGLImpeller` Implementation:**
   - Bind onscreen surface with `MakeCurrent()`.
   - Query size (`onscreen_surface_->GetSize()` or `native_window_->GetSize()`).
   - Call `glReadPixels(0, 0, width, height, GL_RGBA, GL_UNSIGNED_BYTE, temp.data())`.
   - Invert rows vertically into destination `SkData` buffer.
4. **`AndroidSurfaceDynamicImpeller` Implementation:**
   - Forward to `vulkan_surface_->Screenshot()` or `gl_surface_->Screenshot()`.
5. **`PlatformViewAndroid` Thread Dispatch:**
   - In `platform_view_android.cc`:
     ```cpp
     AndroidSurface::Screenshot PlatformViewAndroid::Screenshot() {
       if (!android_surface_) {
         return {};
       }
       AndroidSurface::Screenshot screenshot;
       fml::AutoResetWaitableEvent latch;
       fml::TaskRunner::RunNowOrPostTask(
           task_runners_.GetRasterTaskRunner(),
           [&latch, surface = android_surface_.get(), &screenshot]() {
             screenshot = surface->Screenshot();
             latch.Signal();
           });
       latch.Wait();
       return screenshot;
     }
     ```
6. **`AndroidShellHolder` Redirection:**
   - In `android_shell_holder.cc`:
     ```cpp
     Rasterizer::Screenshot AndroidShellHolder::Screenshot(
         Rasterizer::ScreenshotType type,
         bool base64_encode) {
       if (!IsValid() || !platform_view_) {
         return {nullptr, DlISize(), "", Rasterizer::ScreenshotFormat::kUnknown};
       }
       auto surface_screenshot = platform_view_->Screenshot();
       Rasterizer::Screenshot screenshot;
       screenshot.data = surface_screenshot.data;
       screenshot.frame_size = surface_screenshot.frame_size;
       screenshot.format = "ScreenshotType::UncompressedImage";
       return screenshot;
     }
     ```
7. **Unit Tests:**
   - Implement `AndroidSurfaceSoftware.ScreenshotNonBlank` and `AndroidShellHolder.Screenshot` tests.

## 4. Test Plan (Invariant I-4)
- Test in `android_shell_holder_unittests.cc`:
  1. `AndroidSurfaceSoftware.ScreenshotNonBlank`:
     - Creates `AndroidSurfaceSoftware`.
     - Acquires backing store of size `(80, 60)`.
     - Fills with solid color (`SK_ColorRED`).
     - Calls `surface.Screenshot()`.
     - Asserts `screenshot.data != nullptr`.
     - Asserts `screenshot.frame_size == DlISize(80, 60)`.
     - Asserts `screenshot.data->size() == 80 * 60 * 4`.
     - Asserts non-blank: verifies that pixels contain non-zero data (confirming red channel and alpha are present).
  2. `AndroidShellHolder.ScreenshotEmptyWhenNoFrame`:
     - Asserts that invoking screenshot prior to surface attachment / rendering safely returns null data without crashing.
