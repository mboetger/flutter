# T-4.6 Context: Rename AndroidShellHolder to AndroidEngine and Dissolve PlatformViewAndroid

## Background & Historical Architecture
Prior to this migration:
- Android Java `FlutterEngine` interfaced with C++ through JNI pointers pointing to `AndroidShellHolder`.
- `AndroidShellHolder` owned an internal `flutter::Shell` instance along with thread hosts and run configurations.
- `Shell` created a `PlatformView`, which was subclassed on Android as `PlatformViewAndroid`.
- `PlatformViewAndroid` was tightly coupled to both the core `PlatformView` class and Android JNI callbacks, handling surfaces, rendering, texture management, and input.

## Post-T-4.5 State
- In Stage 2 (T-2.4), the inheritance `PlatformViewAndroid : PlatformView` was broken.
- In Stage 3, all input, window metrics, semantics, accessibility, textures, and platform view rendering modes (HC, TLHC, VD, HCPP) were routed through the embedder API seams.
- In Stage 4 (T-4.5), all legacy fallback code paths and `--android-embedder-api` switches were deleted.
- As a result, `PlatformViewAndroid` is no longer a `PlatformView` subclass and has no legacy fallback logic. It serves purely as an intermediary held by `AndroidShellHolder` forwarding calls to the embedder API seams and holding the surface/texture adapters.
- Similarly, `AndroidShellHolder` is no longer merely "holding a shell" for legacy orchestrations; it is the concrete Android C++ embedding engine host.

## Objectives of T-4.6
1. Rename `AndroidShellHolder` to `AndroidEngine` (`android_engine.h`, `android_engine.cc`, `android_engine_unittests.cc`).
2. Dissolve `PlatformViewAndroid` completely by moving its surface lifecycle management, external texture adapter, and embedder API seam dispatchers directly into `AndroidEngine`.
3. Update JNI bridges (`platform_view_android_jni_impl.cc`) and library loader (`library_loader.cc`) to interface directly with `AndroidEngine`.
4. Update GN targets in `shell/platform/android/BUILD.gn`.
5. Maintain dependency ratchet compliance (all counts <= baseline, nogncheck == 0).
