# Context: T-2.6 — Extract Asset Resolver Setup into FlutterAssetResolver Shape

## Context & Architecture
`APKAssetProvider` is the Android embedder's implementation of the engine's `flutter::AssetResolver` interface. It manages reading application assets (including kernel blobs, Dart snapshots, and Flutter assets) from APK archives via Android's NDK `AAssetManager`.

In Stage 3, `FlutterEngineRun` will be used instead of `Shell::Create` + `RunEngine`. The Embedder API communicates asset providers to the engine through `FlutterProjectArgs.asset_resolvers`, an array of pointers to `FlutterAssetResolver` structs (introduced in T-1.3). Furthermore, hot-restart asset updates will occur via `FlutterEngineUpdateAssetResolverByType(engine, resolver)`.

T-2.6 bridges the existing Android asset provider with this Embedder API shape, ensuring `APKAssetProvider` exposes a valid `FlutterAssetResolver` structure while maintaining 100% backward-compatible internal behavior for Stage 2.
