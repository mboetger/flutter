# T-1.2 Context Pack: Surface and Renderer Availability Lifecycle

## Objective
Add `FlutterEngineSetGpuAvailability`, `FlutterEngineNotifySurfaceCreated`, and `FlutterEngineNotifySurfaceDestroyed` to the Flutter Embedder API (`embedder.h`). This exposes cross-platform surface lifecycle and GPU execution availability controls to embedders, enabling synchronous teardown and backgrounding state transitions required by Android (`surfaceDestroyed`) and iOS (Jetsam GPU suspension).

- Ledger block: `### T-1.2 — Surface/renderer availability lifecycle`

- Rules:
  - Append only to `FlutterEngineProcTable`.
  - Expose `FlutterGpuAvailability` enum and exported functions.
  - Wire to `Shell::SetGpuAvailability` and `PlatformView::NotifyCreated` / `NotifyDestroyed`.
  - Enforce synchronous platform-thread execution semantics with waitable event latches.
  - Ship non-Android host unit tests in `embedder_unittests.cc` and `embedder_unittests_proctable.cc`.
  - No Android headers or types in `shell/platform/embedder/`.
