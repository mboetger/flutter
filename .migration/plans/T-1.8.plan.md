# T-1.8 Plan: Window Metrics Gaps (Padding, Gesture Insets, Touch Slop, Display Features, Corner Radii)

## Goal
Extend `FlutterWindowMetricsEvent` in `embedder.h` to include all window metrics parameters from the T-0.4 parity contract (`android_viewport_metrics_unittests.cc`), translate them safely in `embedder.cc::MakeViewportMetricsFromWindowMetrics`, and verify validation and dispatch in `embedder_unittests.cc`.

## Files Touched
- `engine/src/flutter/shell/platform/embedder/embedder.h`
- `engine/src/flutter/shell/platform/embedder/embedder.cc`
- `engine/src/flutter/shell/platform/embedder/tests/embedder_unittests.cc`

## Implementation Sequence
1. In `embedder.h`:
   - Declare enums `FlutterDisplayFeatureType` and `FlutterDisplayFeatureState` before `FlutterWindowMetricsEvent`.
   - Append 17 new fields to `FlutterWindowMetricsEvent`:
     - `display_features_count` (size_t)
     - `display_features_bounds` (const double*)
     - `display_features_type` (const int*)
     - `display_features_state` (const int*)
     - `physical_padding_top` (double)
     - `physical_padding_right` (double)
     - `physical_padding_bottom` (double)
     - `physical_padding_left` (double)
     - `physical_system_gesture_inset_top` (double)
     - `physical_system_gesture_inset_right` (double)
     - `physical_system_gesture_inset_bottom` (double)
     - `physical_system_gesture_inset_left` (double)
     - `physical_touch_slop` (double, -1.0 indicates unset)
     - `physical_display_corner_radius_top_left` (double, -1.0 indicates unset)
     - `physical_display_corner_radius_top_right` (double, -1.0 indicates unset)
     - `physical_display_corner_radius_bottom_right` (double, -1.0 indicates unset)
     - `physical_display_corner_radius_bottom_left` (double, -1.0 indicates unset)
   - Preserve `FLUTTER_ENGINE_VERSION = 1` (§G.5, §G.9 Item 2).
2. In `embedder.cc` (`MakeViewportMetricsFromWindowMetrics`):
   - Extract `physical_padding_*` with `SAFE_ACCESS(flutter_metrics, ..., 0.0)`.
   - Extract `physical_system_gesture_inset_*` with `SAFE_ACCESS(flutter_metrics, ..., 0.0)`.
   - Extract `physical_touch_slop` with `SAFE_ACCESS(flutter_metrics, physical_touch_slop, -1.0)`.
   - Extract `physical_display_corner_radius_*` with `SAFE_ACCESS(flutter_metrics, ..., -1.0)`.
   - Validate `physical_padding_*`: must be non-negative and not exceed physical window dimensions (`height` / `width`).
   - Extract and validate display features:
     - Check for `SIZE_MAX / 4` count overflow.
     - If count > 0, ensure `bounds`, `type`, and `state` buffers are non-null.
     - Copy into `metrics.physical_display_features_{bounds,type,state}` vectors.
3. In `tests/embedder_unittests.cc`:
   - Extend `InvalidFlutterWindowMetricsEvent`: assert negative padding rejected, excessive padding rejected, valid padding accepted.
   - Add `WindowMetricsEventDisplayFeaturesValidation`: assert non-zero count with null buffer rejected, valid display feature buffers accepted.
   - Add `WindowMetricsEventAllParityFields`: send event with all 17 new fields populated with distinct non-default values and verify `kSuccess`.
   - Add `WindowMetricsEventWithLegacyStructSize`: send event with struct size truncated at `max_height_constraint` to prove C-ABI backwards compatibility.
4. Verify & Ratchet:
   - Run `./ci/format.sh --fix`.
   - Run `migration_verify.dart --task T-1.8 --gates analysis,ratchet`.
