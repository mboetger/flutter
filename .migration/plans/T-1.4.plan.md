# T-1.4 Plan: Dart Deferred Components

## Goal
Extend the Embedder API (`embedder.h`) to support Dart deferred component loading. Expose `FlutterRequestDartDeferredLibraryCallback` and append `dart_deferred_library_request_callback` to `FlutterProjectArgs`. Expose versioned info structs `FlutterLoadDeferredLibraryInfo` and `FlutterLoadDeferredLibraryErrorInfo`, and export functions `FlutterEngineLoadDartDeferredLibrary` and `FlutterEngineLoadDartDeferredLibraryError`. Append `LoadDartDeferredLibrary` and `LoadDartDeferredLibraryError` to `FlutterEngineProcTable`. Wire deferred library request dispatching through `PlatformViewEmbedder`, and wire library loading/error notification through `EmbedderEngine` to `Shell`. Add automated host unit tests in `embedder_unittests.cc` and `platform_view_embedder_unittests.cc`.

## Implementation Sequence
1. In `embedder.h`:
   - Declare `FlutterRequestDartDeferredLibraryCallback` typedef (`void (*)(intptr_t loading_unit_id, void* user_data)`).
   - Declare `FlutterLoadDeferredLibraryInfo` struct with `struct_size`, `loading_unit_id`, `isolate_snapshot_data`, `isolate_snapshot_data_size`, `isolate_snapshot_instructions`, `isolate_snapshot_instructions_size`.
   - Declare `FlutterLoadDeferredLibraryErrorInfo` struct with `struct_size`, `loading_unit_id`, `error_message`, `transient`.
   - Append `dart_deferred_library_request_callback` to `FlutterProjectArgs`.
   - Declare `FlutterEngineResult FlutterEngineLoadDartDeferredLibrary(FlutterEngine, const FlutterLoadDeferredLibraryInfo*);`.
   - Declare `FlutterEngineResult FlutterEngineLoadDartDeferredLibraryError(FlutterEngine, const FlutterLoadDeferredLibraryErrorInfo*);`.
   - Add function pointer typedefs (`FlutterEngineLoadDartDeferredLibraryFnPtr`, `FlutterEngineLoadDartDeferredLibraryErrorFnPtr`) and append `LoadDartDeferredLibrary` and `LoadDartDeferredLibraryError` to `FlutterEngineProcTable`.
2. In `platform_view_embedder.h` and `.cc`:
   - Add `using RequestDartDeferredLibraryCallback = std::function<void(intptr_t loading_unit_id)>;` to `PlatformViewEmbedder`.
   - Add `RequestDartDeferredLibraryCallback request_dart_deferred_library_callback;` to `PlatformDispatchTable`.
   - Override `void RequestDartDeferredLibrary(intptr_t loading_unit_id) override;` in `PlatformViewEmbedder` forwarding to the dispatch table callback.
3. In `embedder_engine.h` and `.cc`:
   - Add `bool LoadDartDeferredLibrary(intptr_t loading_unit_id, std::unique_ptr<const fml::Mapping> snapshot_data, std::unique_ptr<const fml::Mapping> snapshot_instructions);` delegating to `shell_->LoadDartDeferredLibrary`.
   - Add `bool LoadDartDeferredLibraryError(intptr_t loading_unit_id, const std::string& error_message, bool transient);` delegating to `shell_->LoadDartDeferredLibraryError`.
4. In `embedder.cc`:
   - In `FlutterEngineInitialize`, read `SAFE_ACCESS(args, dart_deferred_library_request_callback, nullptr)` and wire into `platform_dispatch_table.request_dart_deferred_library_callback`.
   - Implement `FlutterEngineLoadDartDeferredLibrary`: validate engine handle and info struct size, validate non-null snapshot data, wrap buffers in `fml::NonOwnedMapping`, and delegate to `embedder_engine->LoadDartDeferredLibrary`.
   - Implement `FlutterEngineLoadDartDeferredLibraryError`: validate engine handle, info struct size, and non-null error message, and delegate to `embedder_engine->LoadDartDeferredLibraryError`.
   - In `FlutterEngineGetProcAddresses`: add `SET_PROC` mappings for `LoadDartDeferredLibrary` and `LoadDartDeferredLibraryError`.
5. In `platform_view_embedder_unittests.cc`:
   - Add test verifying `PlatformViewEmbedder::RequestDartDeferredLibrary` dispatches to `platform_dispatch_table`.
6. In `tests/embedder_unittests.cc`:
   - Add integration test `DartDeferredLibraryCallbacks` verifying argument validation, request callback invocation via `PlatformView`, `FlutterEngineLoadDartDeferredLibraryError` reporting, and `FlutterEngineLoadDartDeferredLibrary` resolution.
7. Verify:
   - Format with `./ci/format.sh`.
   - `migration_verify.dart --task T-1.4 --gates analysis,ratchet` clean.
