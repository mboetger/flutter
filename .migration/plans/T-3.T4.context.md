# Context: T-3.T4 — Virtual Display (VD) Composition Mode Migration behind Flag

## Problem Statement
The Flutter Android embedder supports multiple platform view composition modes: Texture Layer Hybrid Composition (TLHC), Virtual Display (VD), Hybrid Composition (HC), and Hybrid Composition Plus Plus (HCPP).
Virtual Display (VD) mode hosts the platform view in an Android `VirtualDisplay` object that renders directly into a texture entry (`SurfaceTexture` / `SurfaceProducer`).
In Stage 3 of the Android Embedder API migration, composition modes converge independently behind `--android-embedder-api`.
Task T-3.T4 migrates the VD mode to the embedder path while keeping the legacy path intact and reachable when the flag is disabled.

## Scope of Changes
1. `engine/src/flutter/shell/platform/android/platform_view_android.h`:
   - Declare:
     ```cpp
     void OnDisplayVirtualDisplayPlatformView(int32_t view_id,
                                             int32_t x,
                                             int32_t y,
                                             int32_t width,
                                             int32_t height);

     FlutterEngineResult DisplayVirtualDisplayPlatformView(int32_t view_id,
                                                           int32_t x,
                                                           int32_t y,
                                                           int32_t width,
                                                           int32_t height);

     FlutterEngineResult DisplayVirtualDisplayPlatformViewEmbedder(
         int32_t view_id,
         int32_t x,
         int32_t y,
         int32_t width,
         int32_t height);
     ```
2. `engine/src/flutter/shell/platform/android/platform_view_android.cc`:
   - Implement `PlatformViewAndroid::OnDisplayVirtualDisplayPlatformView(...)`:
     - Flag on: emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::OnDisplayVirtualDisplayPlatformView", "mode", "VD", "path", "embedder_api")` and route to `DisplayVirtualDisplayPlatformView(...)`.
     - Flag off: emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::OnDisplayVirtualDisplayPlatformView", "mode", "VD", "path", "legacy")`.
   - Implement `PlatformViewAndroid::DisplayVirtualDisplayPlatformView(...)` with validation.
   - Implement `PlatformViewAndroid::DisplayVirtualDisplayPlatformViewEmbedder(...)` forwarding to `DisplayVirtualDisplayPlatformView(...)`.
3. `docs/platforms/android/embedder-api-migration/MIGRATION_LEDGER.md`:
   - Update §B.1 Composition Mode Convergence Tracker to advance `VD — Virtual Display` status to `embedder-behind-flag` with last verified `T-3.T4`.
4. `engine/src/flutter/shell/platform/android/platform_view_android_unittests.cc`:
   - Add unit tests verifying legacy path, embedder API path, direct seam invocation, and argument validation for VD platform views.

## Non-goals

- HC composition mode migration (scheduled for T-3.T6).
