# Context: T-3.3 — Replace `platform_view_->DispatchSemanticsAction(...)` with `FlutterEngineDispatchSemanticsAction` behind Flag

## Problem Statement
In the legacy Android embedding, semantics actions from Android accessibility services are delivered via JNI (`nativeDispatchSemanticsAction`) to `PlatformViewAndroid::DispatchSemanticsAction(JNIEnv* env, jint id, jint action, jobject args, jint args_position)` which forwards directly to `platform_view_->DispatchSemanticsAction(...)`.
In the standard Flutter Embedder API, semantics actions are delivered via `FlutterEngineDispatchSemanticsAction(engine, node_id, action, data, data_length)`.

## Scope of Changes
1. `engine/src/flutter/shell/platform/android/platform_view_android.h`:
   - Declare `FlutterEngineResult DispatchSemanticsAction(uint64_t node_id, FlutterSemanticsAction action, const uint8_t* data, size_t data_length);`
2. `engine/src/flutter/shell/platform/android/platform_view_android.cc`:
   - Update `PlatformViewAndroid::DispatchSemanticsAction(JNIEnv* env, ...)` to branch on `android_embedder_api_`.
   - On flag-on path: emit `TRACE_EVENT1("flutter", "PlatformViewAndroid::DispatchSemanticsAction", "path", "embedder_api")`, extract direct buffer data, and call `DispatchSemanticsAction(node_id, action, data, data_length)`.
   - On legacy path: emit `TRACE_EVENT1("flutter", "PlatformViewAndroid::DispatchSemanticsAction", "path", "legacy")` and forward directly to `platform_view_->DispatchSemanticsAction(...)`.
   - Implement `DispatchSemanticsAction(uint64_t node_id, FlutterSemanticsAction action, const uint8_t* data, size_t data_length)`.
3. `engine/src/flutter/shell/platform/android/platform_view_android_unittests.cc`:
   - Update `FakePlatformViewDelegate` to capture `dispatch_semantics_action_called`, `last_semantics_node_id`, `last_semantics_action`, and `last_semantics_args_size`.
   - Add unit tests verifying semantics action validation and payload forwarding.

## Non-goals
- Changing Android Java-side accessibility code in this task.
- Introducing multi-view semantics dispatch (deferred to multi-view tasks).
