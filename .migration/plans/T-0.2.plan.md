# T-0.2 Plan: Surface Lifecycle Characterization Tests

## Goal
Establish characterization unit tests for the Android embedder surface lifecycle (`NotifyCreated`, `NotifySurfaceWindowChanged`, `NotifyDestroyed`) in `PlatformViewAndroid`. These tests pin the current behavior across Activity backgrounding and foregrounding, window resizing/recreation, mid-frame window changes, in-flight frame destruction, and double invocation idempotency, asserting thread affinity and emitting Perfetto trace events.

## Files Touched
- `engine/src/flutter/shell/platform/android/platform_view_android_surface_lifecycle_unittests.cc` (new)
- `engine/src/flutter/shell/platform/android/BUILD.gn` (add test file to `flutter_shell_native_unittests`)

## Implementation Sequence
1. Implement `platform_view_android_surface_lifecycle_unittests.cc` with test suite `PlatformViewAndroidSurfaceLifecycleTest`:
   - Setup `AndroidShellHolder` test fixture with `MockPlatformViewAndroidJNI` and `AndroidNativeWindow` fake window.
   - **Test 1: NotifyCreatedValidSurface**: Verifies that calling `NotifyCreated` initializes the native surface and sets up the rendering surface.
   - **Test 2: NotifyDestroyedReleasesGpuResources**: Verifies that calling `NotifyDestroyed` tears down the on-screen context cleanly without leak or crash.
   - **Test 3: BackgroundAndForegroundCycle**: Verifies `NotifyCreated` -> `NotifyDestroyed` -> `NotifyCreated` cleanly handles activity backgrounding and re-entry.
   - **Test 4: NotifySurfaceWindowChangedMidFrame**: Verifies `NotifySurfaceWindowChanged` replaces the native window and schedules a frame.
   - **Test 5: NotifyDestroyedWithFrameInFlight**: Verifies teardown when tasks are pending on the raster thread.
   - **Test 6: IdempotentDoubleNotifyCreated**: Asserts the observed behavior when `NotifyCreated` is invoked twice.
   - **Test 7: IdempotentDoubleNotifyDestroyed**: Asserts the observed behavior when `NotifyDestroyed` is invoked twice.
2. In all test cases:
   - Verify thread affinity using `task_runners.GetPlatformTaskRunner()->RunsTasksOnCurrentThread()` and `task_runners.GetRasterTaskRunner()->RunsTasksOnCurrentThread()`.
   - Add `TRACE_EVENT0("flutter", ...)` annotations.
3. Update `engine/src/flutter/shell/platform/android/BUILD.gn` to include `platform_view_android_surface_lifecycle_unittests.cc` in `flutter_shell_native_unittests`.
