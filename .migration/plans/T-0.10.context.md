# Context: Task T-0.10 — CI: Make the Android Embedder Test Story Real

## Problem Statement
In the previous migration attempt (v7), the verification story rested on tests that were never wired into CI and executed solely on an individual developer's device. Consequently, critical failures went completely unnoticed.
Task T-0.10 establishes the authoritative CI contract for the Android embedder migration before any functional engine refactoring begins in Stages 1-4:
1. Guarantee that `flutter_shell_native_unittests` (which compiles the T-0.2, T-0.3, and T-0.4 characterization suites) is actively built and executed in CI (`linux_android_emulator.json`).
2. Add an AddressSanitizer (ASan) configuration for Android unit tests to validate surface lifecycle and texture teardown memory safety.
3. Wire the T-0.9 dependency ratchet check as a mandatory gate in `testing/run_tests.py`.
4. Add an orphan target guard in `testing/run_tests.py` that fails the build if any new `executable(...)` target appears in `shell/platform/android/BUILD.gn` (or subdirectories) without a corresponding runner entry in `run_tests.py`.
5. Author a complete documentation mapping at `engine/src/flutter/docs/android/embedder_ci_mapping.md` describing builders, test targets, and coverage.

## Governing Invariants & Principles
- **I-5 (Test targets wired):** Every test target must be wired into test runners and CI builders; orphan targets are strictly forbidden.
- **I-8 (No nogncheck without bug):** Tracked by ratchet.
- **I-12 (Continuous E2E verification):** Tests must be continuously exercised in CI.
- **§A.5 (The evidence rule):** Verified by committed artifacts.

## Scope & Deliverables
1. `engine/src/flutter/testing/run_tests.py`:
   - `check_android_embedder_contracts()`:
     - Scans `shell/platform/android/**/BUILD.gn` for `executable(...)` targets and asserts they are registered in `run_tests.py`.
     - Invokes `tools/android_embedder_deps.py --check`.
2. `engine/src/flutter/ci/builders/linux_android_emulator.json`:
   - Adds ASan build and test configuration for x64 Android emulator.
3. `engine/src/flutter/docs/android/embedder_ci_mapping.md`:
   - Complete builder-to-target mapping documentation.
