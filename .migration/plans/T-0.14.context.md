# T-0.14 Context Pack: External Texture Inventory (Blocker B-5)

## Objective
Deliver a comprehensive technical inventory of all six Android external texture implementations against the Flutter Embedder API (`embedder.h`). Identify C-ABI representation gaps (specifically the 4x4 UV transform matrix, Vulkan external texture callback support, `GL_TEXTURE_EXTERNAL_OES` handling, and Android `HardwareBuffer` lifecycle/LRU caching) and enumerate public Java `TextureRegistry` APIs that must remain fully functional.
