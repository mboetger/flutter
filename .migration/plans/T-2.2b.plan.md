## 1. Objectives
- Route 6 `PlatformViewAndroid` overrides through the `platform_view_` delegate seam when a delegate is registered:
  1. `HandlePlatformMessage`
  2. `OnPreEngineRestart`
  3. `RequestDartDeferredLibrary`
  4. `LoadDartDeferredLibrary`
  5. `LoadDartDeferredLibraryError`
  6. `UpdateAssetResolverByType`
- Preserve existing fallbacks when `platform_view_ == nullptr`.
- Promote `HandlePlatformMessage` and `OnPreEngineRestart` to `public` visibility on `PlatformViewAndroid`.
- Add unit tests in `platform_view_android_unittests.cc` verifying that each method delegates to `platform_view_` when set and falls back when null.
- Verify characterization tests pass unmodified.

---

## 2. Implementation Steps
1. **Header Visibility (`platform_view_android.h`):**
   - Promote `HandlePlatformMessage` and `OnPreEngineRestart` from private to public under the `PlatformView` override section.

2. **Source Delegation (`platform_view_android.cc`):**
   - In `HandlePlatformMessage`:
     ```cpp
     if (platform_view_) {
       platform_view_->HandlePlatformMessage(std::move(message));
       return;
     }
     ```
   - In `OnPreEngineRestart`:
     ```cpp
     if (platform_view_) {
       platform_view_->OnPreEngineRestart();
       return;
     }
     ```
   - In `RequestDartDeferredLibrary`:
     ```cpp
     if (platform_view_) {
       platform_view_->RequestDartDeferredLibrary(loading_unit_id);
       return;
     }
     ```
   - In `LoadDartDeferredLibrary`:
     ```cpp
     if (platform_view_) {
       platform_view_->LoadDartDeferredLibrary(loading_unit_id,
                                               std::move(snapshot_data),
                                               std::move(snapshot_instructions));
       return;
     }
     ```
   - In `LoadDartDeferredLibraryError`:
     ```cpp
     if (platform_view_) {
       platform_view_->LoadDartDeferredLibraryError(loading_unit_id,
                                                    error_message, transient);
       return;
     }
     ```
   - In `UpdateAssetResolverByType`:
     ```cpp
     if (platform_view_) {
       platform_view_->UpdateAssetResolverByType(std::move(updated_asset_resolver),
                                                 type);
       return;
     }
     ```

3. **Unit Tests (`platform_view_android_unittests.cc`):**
   - Extend `MockPlatformViewDelegate`:
     - Track calls to `HandlePlatformMessage`, `OnPreEngineRestart`, `RequestDartDeferredLibrary`, `LoadDartDeferredLibrary`, `LoadDartDeferredLibraryError`, and `UpdateAssetResolverByType`.
   - Add test `PlatformViewDelegateMessagingAndDeferredSeam`:
     - Test each of the 6 methods with a registered delegate: confirm delegate method is called with expected parameters.
   - Add test `PlatformViewDelegateMessagingAndDeferredFallback`:
     - Test each method with `nullptr` delegate: confirm fallback paths execute safely.

4. **Build & Verify:**
   - Compile target `flutter_shell_native_unittests` for `android_debug_unopt_arm64`.
   - Run unit tests and characterization tests.
   - Run dependency ratchet check (`android_embedder_deps.py --check`).
