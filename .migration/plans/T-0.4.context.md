## 4. What v7 Did
- In v7, `FlutterWindowMetricsEvent` was missing fields for padding, gesture insets, touch slop, display features, and corner radii. The parameters were discarded, zeroing `MediaQuery.padding` and `MediaQuery.systemGestureInsets` on all Android devices.
- T-0.4 pins down all 30 parameters individually and verifies platform message thread affinity before Stage 1 API extensions.
