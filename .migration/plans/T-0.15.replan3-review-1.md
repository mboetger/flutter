- **Can it be gamed?** Yes. A loose directory path check (e.g. `path.contains('.migration/')` or `.startsWith('.migration/')` but relying on raw user-input paths) allows source changes to be classified as tolerable. - **Tested both ways?** Yes, the plan maps positive and negative explicit mock testing.

6. **Silently Dropped Tests**: The plan outlines exactly 9 tests, explicitly dropping the test for **Req 1** (mechanically validating `commit_sha` and `parent_sha` derivations from Git processes) and dropping the test validating proper CLI argument parsing. I-4 demands behavioral tests for all changes; dropping them to sustain a 390 line budget is a critical restriction bypass.
7. **Phantom Ledger Updates**: The plan dictates that deferrals (`--allow-dirty`, etc.) implicitly abort with `exit > 0` and are banned from `MIGRATION_LEDGER.md` "until natively explicitly implemented". However, the plan fails to explicitly schedule or budget the necessary markdown deletions to `MIGRATION_LEDGER.md` within T-0.15a to remove these advertisements.
