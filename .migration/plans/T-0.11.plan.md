# T-0.11 Plan: Composition Conformance Harness

## Goal
Refactor `dev/bots/suite_runners/run_android_engine_tests.dart` to establish an explicit mode registry, assert non-empty test execution for all composition modes, encode the HCPP Vulkan-only constraint via self-documenting declarations, add GLES HCPP fallback coverage, plumb the `--android-embedder-api` flag axis, and emit `composition_matrix_results.json`.

## Files Touched
- `dev/bots/suite_runners/run_android_engine_tests.dart`

## Implementation Sequence
1. Introduce `CompositionMode` enum:
   ```dart
   enum CompositionMode {
     virtualDisplay,
     textureLayerHybrid,
     hybrid,
     hcpp,
     surfaceTexture,
     surfaceProducer,
   }
   ```
2. Map each mode to an explicit list of relative test main paths.
3. Define support matrix rules:
   - `virtualDisplay`, `textureLayerHybrid`, `hybrid`, `surfaceTexture`, `surfaceProducer` are supported on all backends.
   - `hcpp` is supported on `ImpellerBackend.vulkan` and declared `unsupported` on `ImpellerBackend.opengles` with reason: `'HCPP structurally requires Impeller Vulkan and Android API 34; on OpenGLES apps fall back to HC/TLHC'`.
4. Empty-mode assertion:
   - For every supported mode, verify that at least one main file exists on disk and executes. If any supported mode resolves to zero tests, call `foundError` naming the missing mode.
5. Add GLES fallback coverage:
   - On OpenGLES, run `upgrade_legacy_pv_types_main.dart` with `useHCPPFlag: true` and `EXPECT_HCPP=false`, asserting that requesting HCPP gracefully resolves to legacy platform views.
6. Plumb `androidEmbedderApi` flag parameter:
   - Add `bool? androidEmbedderApi` to `runAndroidEngineTests`.
   - Forward `--android-embedder-api` / `--no-android-embedder-api` in flutter drive arguments when set.
7. Emit `composition_matrix_results.json`:
   - Serialize execution results for each mode, backend, and flag state to disk.
8. Verify:
   - `dart analyze --fatal-infos dev/bots/`
   - `dart format dev/bots/suite_runners/run_android_engine_tests.dart`
   - Prove guard works by temporarily testing empty mode detection.
