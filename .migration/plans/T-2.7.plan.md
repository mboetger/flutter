## 3. Detailed Steps
1. **Create `AndroidSurfaceLifecycle` (`android_surface_lifecycle.h` and `android_surface_lifecycle.cc`):**
   - Class `AndroidSurfaceLifecycle` with inner `Delegate` interface (`OnSurfaceCreated`, `OnSurfaceDestroyed`, `OnScheduleFrame`, `OnInstallFirstFrameCallback`).
   - Encapsulate raster thread synchronization for `NotifyCreated`, `NotifySurfaceWindowChanged`, `NotifyDestroyed`, and `NotifyChanged`.
   - Expose `SetGpuAvailability(FlutterGpuAvailability availability)`, `GetGpuAvailability()`, and `IsSurfaceAvailable()`.
   - Wire `android_surface_lifecycle.h` and `android_surface_lifecycle.cc` in `shell/platform/android/BUILD.gn` under `flutter_shell_native_src`.

2. **Update `PlatformViewAndroid` (`platform_view_android.h` and `platform_view_android.cc`):**
   - Implement `AndroidSurfaceLifecycle::Delegate`.
   - Hold `std::unique_ptr<AndroidSurfaceLifecycle> surface_lifecycle_`.
   - Forward `NotifyCreated`, `NotifySurfaceWindowChanged`, `NotifyDestroyed`, and `NotifyChanged` to `surface_lifecycle_`.
   - Expose `SetGpuAvailability(FlutterGpuAvailability availability)`.
   - Expose `AndroidSurfaceLifecycle* GetSurfaceLifecycleForTesting() const`.

3. **Extend Tests in `platform_view_android_surface_lifecycle_unittests.cc`:**
   - Keep all 7 Stage 0 characterization tests unmodified.
   - Add new tests directly verifying `AndroidSurfaceLifecycle`:
     - Surface availability tracking across `NotifyCreated` and `NotifyDestroyed`.
     - GPU availability state transitions (`SetGpuAvailability`).
     - Delegate callbacks invocation ordering.
     - Direct idempotency checks on `AndroidSurfaceLifecycle`.

4. **Formatting & Validation:**
   - Run `git add -A` and `./ci/format.sh --fix`.
   - Run `python3 tools/android_embedder_deps.py --check`.
   - Compile and verify with `ninja -C out/android_debug_unopt_arm64 flutter_shell_native_unittests flutter_shell_native`.
