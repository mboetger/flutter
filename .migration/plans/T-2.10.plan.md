# Plan: T-2.10 — Introduce an External Texture Seam Shaped like FlutterEngineRegisterExternalTexture

## 1. Overview
Introduce an external texture seam (`AndroidExternalTextureAdapter`) in front of `SurfaceTextureExternalTexture` and `ImageExternalTexture`. The adapter provides methods matching the shape of `FlutterEngineRegisterExternalTexture`, `FlutterEngineUnregisterExternalTexture`, and `FlutterEngineMarkExternalTextureFrameAvailable`, while keeping both the legacy Android JNI registration paths (`RegisterSurfaceTexture`, `RegisterImageTexture`) and the Embedder API shaped paths active and fully functional. Wire `PlatformViewAndroid` to delegate external texture operations through this adapter, preserving 100% behavioral equivalence across all rendering backends.

## 3. Detailed Steps
1. **Create `AndroidExternalTextureAdapter` (`android_external_texture_adapter.h` and `android_external_texture_adapter.cc`):**
   - Header: `engine/src/flutter/shell/platform/android/android_external_texture_adapter.h`
   - Source: `engine/src/flutter/shell/platform/android/android_external_texture_adapter.cc`
   - Define `Delegate` interface:
     ```cpp
     class Delegate {
      public:
       virtual ~Delegate() = default;
       virtual void OnRegisterTexture(std::shared_ptr<flutter::Texture> texture) = 0;
       virtual void OnUnregisterTexture(int64_t texture_id) = 0;
       virtual void OnMarkTextureFrameAvailable(int64_t texture_id) = 0;
     };
     ```
   - Provide legacy registration methods:
     - `bool RegisterSurfaceTexture(int64_t texture_id, const fml::jni::ScopedJavaGlobalRef<jobject>& surface_texture);`
     - `bool RegisterImageTexture(int64_t texture_id, const fml::jni::ScopedJavaGlobalRef<jobject>& image_texture_entry, ImageExternalTexture::ImageLifecycle lifecycle);`
   - Provide Embedder API shaped methods:
     - `FlutterEngineResult RegisterExternalTexture(int64_t texture_identifier);`
     - `FlutterEngineResult UnregisterExternalTexture(int64_t texture_identifier);`
     - `FlutterEngineResult MarkExternalTextureFrameAvailable(int64_t texture_identifier);`
   - Maintain internal registry of active textures with query methods:
     - `bool HasTexture(int64_t texture_id) const;`
     - `std::shared_ptr<flutter::Texture> GetTexture(int64_t texture_id) const;`
     - `size_t TextureCount() const;`

2. **Integrate into `PlatformViewAndroid`:**
   - In `platform_view_android.h`:
     - Implement `AndroidExternalTextureAdapter::Delegate`.
     - Own `std::unique_ptr<AndroidExternalTextureAdapter> external_texture_adapter_;`.
     - Expose testing accessor: `AndroidExternalTextureAdapter* GetExternalTextureAdapterForTesting() const;`.
   - In `platform_view_android.cc`:
     - In constructor, instantiate `external_texture_adapter_ = std::make_unique<AndroidExternalTextureAdapter>(*android_context_, jni_facade_, this);`.
     - Update `RegisterExternalTexture`, `RegisterImageTexture`, `UnregisterTexture`, and `MarkTextureFrameAvailable` to delegate to `external_texture_adapter_`.
     - Implement `OnRegisterTexture`, `OnUnregisterTexture`, and `OnMarkTextureFrameAvailable`.

3. **Update GN Build Configuration:**
   - In `shell/platform/android/BUILD.gn`:
     - Add `"android_external_texture_adapter.cc"` and `"android_external_texture_adapter.h"` to `flutter_shell_native_src`.
     - Add `"android_external_texture_adapter_unittests.cc"` to `flutter_shell_native_unittests`.

4. **Add Unit Tests in `android_external_texture_adapter_unittests.cc`:**
   - Test `EmbedderApiShapeRegistration`: verifies `RegisterExternalTexture`, `UnregisterExternalTexture`, and `MarkExternalTextureFrameAvailable` handle valid IDs and error cases.
   - Test `SurfaceTextureRegistration`: verifies proper `flutter::Texture` instantiation across rendering APIs.
   - Test `ImageTextureRegistration`: verifies proper `ImageExternalTexture` instantiation and lifecycle tracking.
   - Test `PlatformViewAndroidWiring`: verifies delegate callbacks and testing accessors on `PlatformViewAndroid`.

5. **Format & Verify:**
   - Run `git add -A` and `./ci/format.sh --fix`.
   - Run `python3 tools/android_embedder_deps.py --check`.
   - Build and test with `ninja -C out/android_debug_unopt_arm64 flutter_shell_native_unittests flutter_shell_native`.
