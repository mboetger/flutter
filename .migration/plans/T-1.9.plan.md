# T-1.9 Plan: Vulkan External Textures & Backing-Store Render Targets

## Goal
Implement Vulkan external texture support and backing-store render targets across the Embedder API (`embedder.h`), engine resolver (`embedder_external_texture_resolver.{h,cc}`, `embedder_external_texture_vk.{h,cc}`), and embedder initialization (`embedder.cc`), with unit test coverage in `embedder_vk_unittests.cc`.

## Implementation Sequence
1. In `embedder.h`:
   - Define `FlutterVulkanExternalTexture` struct with `struct_size`, `width`, `height`, `image`, `format`, `user_data`, and `destruction_callback`.
   - Define `FlutterVulkanTextureFrameCallback` function pointer type taking `(void* user_data, int64_t texture_identifier, size_t width, size_t height, FlutterVulkanExternalTexture* texture_out)`.
   - Append `vulkan_external_texture_frame_callback` to `FlutterVulkanRendererConfig`.
   - Maintain `FLUTTER_ENGINE_VERSION = 1` invariant (§G.5, §G.9 Item 2).
2. Create `embedder_external_texture_vk.h` and `embedder_external_texture_vk.cc`:
   - Subclass `flutter::Texture`.
   - Implement `Paint`, `ResolveTexture`, `ResolveTextureSkia`, and `ResolveTextureImpeller`.
   - For Skia (Ganesh): import `VkImage` using `GrBackendTextures::MakeVk` and `SkImages::BorrowTextureFrom` into a `DlImageSkia`.
   - For Impeller: import `VkImage` via `impeller::ContextVK`, wrapping into `impeller::TextureVK` and `impeller::DlImageImpeller`.
   - Ensure `destruction_callback` is invoked on destruction / frame retirement.
3. In `embedder_external_texture_resolver.{h,cc}`:
   - Add `#ifdef SHELL_ENABLE_VULKAN` guards.
   - Add constructor overload for `EmbedderExternalTextureVK::ExternalTextureCallback`.
   - Implement resolution in `ResolveExternalTexture` and check in `SupportsExternalTextures`.
4. In `BUILD.gn`:
   - Add `embedder_external_texture_vk.{h,cc}` to `embedder_source_set` under `if (embedder_enable_vulkan)`.
5. In `embedder.cc`:
   - In `FlutterEngineInitialize`, wire `vulkan_external_texture_frame_callback` via `SAFE_ACCESS(vulkan_config, vulkan_external_texture_frame_callback, nullptr)` into `EmbedderExternalTextureResolver`.
   - In `InferExternalViewEmbedderFromArgs` / `MakeRenderTargetFromBackingStoreImpeller`, support Vulkan backing-store render targets under Impeller Vulkan.
6. In `embedder_test_context_vulkan.{h,cc}` and `embedder_vk_unittests.cc`:
   - Add helper in `EmbedderTestContextVulkan` to set `vulkan_external_texture_frame_callback`.
   - Add unit tests:
     - `CanRegisterAndResolveVulkanExternalTexture`: registers an external texture, provides a valid `FlutterVulkanExternalTexture`, marks frame available, and verifies resolution and destruction callback execution.
     - `VulkanExternalTextureWithLegacyStructSize`: ensures an engine initialized with a legacy `FlutterVulkanRendererConfig` lacking the callback field continues running cleanly.
     - `VulkanExternalTextureCallbackFailure`: ensures graceful failure when callback returns false or invalid image.
7. Verify & Format:
   - Run `./ci/format.sh --fix` with `PATH=/usr/local/google/home/boetger/src/depot_tools/python-bin:$PATH`.
   - Run unit tests and verification gates (`analysis`, `ratchet`).
