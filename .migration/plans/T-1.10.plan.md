# T-1.10 Plan: OpenGL UV Transform Matrix & Platform Views on GLES

## 1. Summary of Changes
1. **Extend `FlutterOpenGLTexture` with 4x4 UV Transformation Matrix (`embedder.h`):**
   - Append `double transformation[16]` to `FlutterOpenGLTexture`.
   - Document column-major ordering matching OpenGL and Android `SurfaceTexture` conventions.
   - All elements zero indicates unpopulated/identity transformation (backwards compatible with zero-initialized allocations).
2. **Handle UV Transformation and OES Target in `EmbedderExternalTextureGL` (`embedder_external_texture_gl.{h,cc}`):**
   - In `ResolveTextureSkia` and `ResolveTextureImpeller`:
     - Extract `transformation[16]` and construct `DlMatrix` if non-zero.
     - For Impeller GLES, inspect `texture->target`: if `texture->target == 0x8D65 /* GL_TEXTURE_EXTERNAL_OES */`, configure `desc.type = impeller::TextureType::kTextureExternalOES`.
   - In `Paint`:
     - If `last_transformation_` is populated and non-identity: invert the matrix, adjust canvas coordinates for OpenGL vertical orientation (`Translate(bounds.GetX(), bounds.GetY() + bounds.GetHeight())`, `Scale(bounds.GetWidth(), -bounds.GetHeight())`), create shader via `DlColorSource::MakeImage(last_image_, DlTileMode::kClamp, DlTileMode::kClamp, sampling, &transform)`, and draw a unit rectangle `DrawRect(DlRect::MakeWH(1, 1), paint)`.
     - Else: fallback to standard `DrawImageRect` / `DrawImage`.
   - In `MarkNewFrameAvailable`: reset `last_image_ = nullptr` and `last_transformation_.reset()`.
3. **Support OpenGL Texture Backing Stores under Impeller GLES (`embedder.cc`):**
   - Implement `MakeRenderTargetFromBackingStoreImpeller` for `const FlutterOpenGLTexture* texture`.
   - Wrap `texture->name` into `impeller::TextureGLES` using `gl_context.GetReactor()->CreateHandle(...)` and `WrapTexture(...)`.
   - Build `impeller::RenderTarget` with color attachment, placeholder depth/stencil attachments, and cleanup closure invoking `texture->destruction_callback`.
   - Wire `kFlutterOpenGLTargetTypeTexture` in `CreateEmbedderRenderTarget` to call `MakeRenderTargetFromBackingStoreImpeller` when `enable_impeller` is active.
4. **Update Test Assertions & Add Host Unit Tests (`embedder_assertions.h`, `embedder_gl_unittests.cc`):**
   - Update `operator==` and `operator<<` for `FlutterOpenGLTexture`.
   - Add unit tests for:
     - External texture with UV transformation matrix roundtripping and rendering.
     - External texture with `GL_TEXTURE_EXTERNAL_OES` target under Impeller GLES.
     - Impeller GLES compositor with `kFlutterOpenGLTargetTypeTexture` backing stores.
     - Platform view composition with OpenGL texture backing stores under Impeller GLES.
