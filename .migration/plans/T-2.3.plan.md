## 1. Objectives
- Construct `PlatformViewEmbedder` inside `AndroidShellHolder`'s `on_create_platform_view` callback.
- Wire `PlatformViewAndroid::SetPlatformView` to point to the constructed `PlatformViewEmbedder`.
- Store ownership of `std::unique_ptr<PlatformViewEmbedder> platform_view_embedder_` in `AndroidShellHolder`.
- Mirror this construction and wiring in `AndroidShellHolder::Spawn`.
- Populate `PlatformViewEmbedder::PlatformDispatchTable` with JNI routing callbacks for:
  - `update_semantics_callback`
  - `platform_message_response_callback`
  - `compute_platform_resolved_locale_callback`
  - `on_pre_engine_restart_callback`
  - `on_channel_update`
  - `view_focus_change_request_callback`
  - `request_dart_deferred_library_callback`
  - `set_application_locale_callback`
  - `get_scaled_font_size_callback`
- Preserve native Android GPU rendering (`android_surface_`), external view embedders (`AndroidExternalViewEmbedderWrapper`), Impeller contexts, and vsync waiters (`VsyncWaiterAndroid`) on `PlatformViewAndroid`.
- Maintain dependency ratchet counts `<= baseline` (Deps: 26/63, Includes: 98/123, nogncheck: 0) by pruning unused `#include "flutter/lib/ui/painting/image_generator_registry.h"` from `android_shell_holder.cc`.
- Add unit tests in `android_shell_holder_unittests.cc` verifying that `GetPlatformView()->GetPlatformViewDelegate()` is non-null for both primary and spawned holders.

## 2. Implementation Steps

1. **Header Updates (`android_shell_holder.h`):**
   - Forward-declare `class PlatformViewEmbedder;`
   - Add member `std::unique_ptr<PlatformViewEmbedder> platform_view_embedder_;`
   - Update `AndroidShellHolder` private spawn constructor to accept `std::unique_ptr<PlatformViewEmbedder> platform_view_embedder`.

2. **Source Updates (`android_shell_holder.cc`):**
   - Prune unused `#include "flutter/lib/ui/painting/image_generator_registry.h"`.
   - Add `#include "flutter/shell/platform/embedder/platform_view_embedder.h"`.
   - In `AndroidShellHolder::AndroidShellHolder`:
     - Inside `on_create_platform_view`, construct `PlatformViewEmbedder` with `PlatformDispatchTable`.
     - Call `platform_view_android->SetPlatformView(platform_view_embedder.get())`.
     - Assign constructed embedder to `platform_view_embedder_`.
   - In `AndroidShellHolder::Spawn`:
     - Inside `on_create_platform_view`, construct `PlatformViewEmbedder` with `PlatformDispatchTable`.
     - Call `platform_view_android->SetPlatformView(spawned_platform_view_embedder.get())`.
     - Move `spawned_platform_view_embedder` into the spawned `AndroidShellHolder`.

3. **Refine PlatformViewAndroid Fallbacks (`platform_view_android.cc`):**
   - Ensure surface, context, and vsync methods (`CreateRenderingSurface`, `CreateExternalViewEmbedder`, `GetImpellerContext`, `CreateVSyncWaiter`, `CreateSnapshotSurfaceProducer`) prioritize the native Android GPU pipeline (`android_surface_`, `android_context_`, `VsyncWaiterAndroid`) so that GPU rendering and platform views remain unaffected.

4. **Unit Tests (`android_shell_holder_unittests.cc`):**
   - Add assertion in `TEST(AndroidShellHolder, Create)` verifying `GetPlatformView()->GetPlatformViewDelegate()` is non-null.
   - Add `TEST(AndroidShellHolder, PlatformViewEmbedderDelegateWired)` verifying that the platform view delegate is wired and active.

5. **Build & Verify:**

   - Build target: `ninja -C out/android_debug_unopt_arm64 flutter_shell_native_unittests`
   - Ratchet check: `python3 tools/android_embedder_deps.py --check`
