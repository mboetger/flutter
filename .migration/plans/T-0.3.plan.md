# T-0.3 Plan: Threading, Priority, and Merging Characterization

## Goal
Implement native C++ characterization unit tests for the Android embedder threading subsystem:
1. Pin down the exact POSIX thread priorities configured by `AndroidPlatformThreadConfigSetter` for UI, raster, IO, platform, and worker threads, establishing the Stage 3 parity contract constants.
2. Assert thread affinity for core callbacks: vsync callback, platform message dispatch, external texture registration, and semantics updates.
3. Test dynamic thread merging capability (`SupportsDynamicThreadMerging`) across `AndroidExternalViewEmbedder`, `AndroidExternalViewEmbedder2`, and `AndroidExternalViewEmbedderWrapper`.
4. Characterize the `kMergeAfterLaunch` thread merging path.
5. Commit a golden reference startup trace under `engine/src/flutter/docs/android/`.

## Implementation Sequence
1. Create `engine/src/flutter/shell/platform/android/android_threading_unittests.cc`:
   - `ThreadPrioritiesParityContract`: Validates `AndroidPlatformThreadConfigSetter` priority mappings against the constants above.
   - `CallbackThreadAffinities`: Asserts platform thread affinity for platform message dispatch, texture registration, and semantics update; asserts UI thread affinity for vsync callbacks.
   - `DynamicThreadMergingCapabilities`: Covers `SupportsDynamicThreadMerging()` for `AndroidExternalViewEmbedder` (true), `AndroidExternalViewEmbedder2` (false), and `AndroidExternalViewEmbedderWrapper` (mode-dependent).
   - `MergeAfterLaunchPath`: Asserts that when `settings.merged_platform_ui_thread == kMergeAfterLaunch`, UI and Platform queues merge.
2. Create `engine/src/flutter/docs/android/startup_perfetto_trace_reference.json`:
   - Golden reference startup trace events captured from standard engine launch with thread tracks and priorities.
3. Add `android_threading_unittests.cc` to `flutter_shell_native_unittests` in `engine/src/flutter/shell/platform/android/BUILD.gn`.
