## 2. Documented Falsification Attempts

### Falsification Attempt 1: Deadlock Risk During SkipAndRetry or Resubmit in Tests
- **Hypothesis:** Returning `kFlutterPostPrerollResultSkipAndRetryFrame` or `kFlutterPostPrerollResultResubmitFrame` in an embedder unit test could cause the pipeline to stall or deadlock if tasks are yielded or awaiting a latch.
- **Investigation:** In `GPURasterizer::Draw`, when `kSkipAndRetry` or `kResubmit` is returned from `PostPrerollAction`, the rasterizer immediately re-enqueues or retries rasterization. As demonstrated in `rasterizer_unittests.cc`, returning `kSkipAndRetry` or `kResubmit` transitions cleanly to the next raster attempt once the state machine transitions to `kSuccess`. The test waitable latch waits on `present_callback` which occurs when the frame finally successfully renders.
- **Result:** Falsified. The raster pipeline handles retry and resubmit without deadlock.

### Falsification Attempt 2: Thread Safety of User Baton in Callbacks
- **Hypothesis:** `begin_frame_callback`, `post_preroll_callback`, and `end_frame_callback` execute on the raster/platform task runner while the test thread waits on a latch, risking data races on user baton fields.
- **Investigation:** The test state baton is only mutated sequentially on the rasterizer execution thread during the frame callback sequence (`begin_frame` -> `post_preroll` -> `end_frame`), and is read on the main test thread only AFTER `latch.Wait()` returns (which synchronizes-with the presentation callback). Atomic counters or latch synchronization ensure memory visibility.
- **Result:** Falsified. Latch synchronization establishes a full happens-before edge between callback mutations and test assertions.

### Falsification Attempt 3: Inadvertent Regressions in Existing Tests
- **Hypothesis:** Adding new tests might perturb existing embedder test fixture state.
- **Investigation:** Each `TEST_F(EmbedderTest, ...)` runs in an isolated fixture with fresh `EmbedderTestContext` and independent engine instances.
- **Result:** Falsified. Zero interference with pre-existing tests.
