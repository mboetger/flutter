# T-1.3 Plan: Custom Asset Resolver and Dynamic Asset Updates

## Goal
Extend the Embedder API (`embedder.h`) with custom asset resolver capabilities and dynamic asset updates. Expose `FlutterAssetResolverType`, `FlutterMapping`, and `FlutterAssetResolver`, add `asset_resolvers` and `asset_resolvers_count` to `FlutterProjectArgs`, and export `FlutterEngineUpdateAssetResolver`. Implement `EmbedderAssetResolver` in `shell/platform/embedder/` to adapt embedder callbacks to `flutter::AssetResolver`, wire `EmbedderEngine::UpdateAssetResolver` to `Shell::UpdateAssetResolverByType`, append `UpdateAssetResolver` to `FlutterEngineProcTable`, and provide automated host unit tests.

## Implementation Sequence
1. In `engine/src/flutter/assets/asset_resolver.h`:
   - Append `kCustomResolver` to `AssetResolver::AssetResolverType` enum.
   - Add forward declaration `class EmbedderAssetResolver;` and virtual method `virtual const EmbedderAssetResolver* as_embedder_asset_resolver() const { return nullptr; }`.
2. In `engine/src/flutter/shell/platform/embedder/embedder.h`:
   - Declare `FlutterAssetResolverType` enum (`kFlutterAssetResolverTypeAPK = 0`, `kFlutterAssetResolverTypeDirectory = 1`, `kFlutterAssetResolverTypeCustom = 2`).
   - Declare `FlutterMapping` struct (`struct_size`, `mapping`, `size`, `user_data`, `release_callback`).
   - Declare `FlutterAssetResolverGetAssetCallback` typedef (`bool (*)(const char*, FlutterMapping*, void*)`).
   - Declare `FlutterAssetResolver` struct (`struct_size`, `user_data`, `type`, `get_asset_callback`, `is_valid_after_asset_manager_change`).
   - Append `asset_resolvers_count` and `asset_resolvers` to `FlutterProjectArgs`.
   - Declare `FlutterEngineResult FlutterEngineUpdateAssetResolver(FlutterEngine, const FlutterAssetResolver*);`.
   - Declare `FlutterEngineUpdateAssetResolverFnPtr` typedef and append `UpdateAssetResolver` to `FlutterEngineProcTable`.
3. In `engine/src/flutter/shell/platform/embedder/embedder_asset_resolver.h` and `.cc`:
   - Implement `EmbedderAssetResolver` inheriting from `flutter::AssetResolver`.
   - Translate `FlutterAssetResolverType` to `AssetResolver::AssetResolverType`.
   - Implement `IsValid()`, `IsValidAfterAssetManagerChange()`, `GetType()`, `GetAsMapping()`, and `operator==`.
   - In `GetAsMapping()`, call `get_asset_callback`, and if successful, return `std::unique_ptr<fml::Mapping>` wrapping the buffer and forwarding release notification to `release_callback`. If mapping pointer is null, call `release_callback` immediately and return `nullptr`.
4. In `engine/src/flutter/shell/platform/embedder/embedder_engine.h` and `.cc`:
   - Implement `bool UpdateAssetResolver(std::unique_ptr<AssetResolver> updated_asset_resolver, AssetResolver::AssetResolverType type);` which invokes `shell_->UpdateAssetResolverByType(std::move(updated_asset_resolver), type);`.
5. In `engine/src/flutter/shell/platform/embedder/embedder.cc`:
   - In `FlutterEngineInitialize` and `FlutterEngineRun`, inspect `SAFE_ACCESS(args, asset_resolvers, nullptr)` and `SAFE_ACCESS(args, asset_resolvers_count, 0)`. Validate each resolver pointer and its struct size (`SAFE_ACCESS(resolver, struct_size, 0)`), ensuring non-null `get_asset_callback`. Register each with `run_configuration.AddAssetResolver(std::make_unique<EmbedderAssetResolver>(*resolver));`.
   - Implement `FlutterEngineUpdateAssetResolver`, validating engine and resolver parameters, instantiating `EmbedderAssetResolver`, and delegating to `EmbedderEngine::UpdateAssetResolver`.
   - In `FlutterEngineGetProcAddresses`, add `SET_PROC(UpdateAssetResolver, FlutterEngineUpdateAssetResolver)`.
6. In `engine/src/flutter/shell/platform/embedder/BUILD.gn`:
   - Add `embedder_asset_resolver.cc` and `embedder_asset_resolver.h` to `embedder_source_set`.
   - Add `embedder_asset_resolver_unittests.cc` to `embedder_unittests`.
7. Tests:
   - In `embedder_asset_resolver_unittests.cc`: Add standalone unit tests for `EmbedderAssetResolver` verifying mapping, release callback execution, empty payload handling, null buffer release, and equality comparison.
   - In `tests/embedder_unittests.cc`: Add integration unit tests verifying startup configuration with custom asset resolvers in `FlutterProjectArgs`, asset lookup through `AssetManager`, release lifecycle, invalid argument rejection, and `FlutterEngineUpdateAssetResolver` dynamic updates.
8. Verify:
   - Format with `./ci/format.sh`.
   - `migration_verify.dart --task T-1.3 --gates analysis,ratchet` clean.
