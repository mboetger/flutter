# Context: T-3.T6 — HC Composition Mode Migration behind Flag

## Problem Statement
The Flutter Android embedder supports multiple platform view composition modes: Texture Layer Hybrid Composition (TLHC), Virtual Display (VD), Hybrid Composition (HC), and Hybrid Composition Plus Plus (HCPP).
Hybrid Composition (HC) is Flutter's composition mode where native Android platform views are embedded directly into the native view hierarchy, requiring dynamic merging of the raster thread onto the platform thread during platform view rendering and managing overlay surfaces for Flutter UI rendered above or below native views.
HC mode is gated on T-1.18 (dynamic thread merging C-ABI extension), which implemented `supports_dynamic_thread_merging`, `post_preroll_callback`, `begin_frame_callback`, and `end_frame_callback` on `FlutterCompositor`.
In Stage 3 of the Android Embedder API migration, composition modes converge independently behind `--android-embedder-api`.
Task T-3.T6 migrates the HC mode lifecycle (frame initiation, completion, overlay creation, overlay destruction) to the embedder path while keeping the legacy path intact and reachable when the flag is disabled.

   - Implement `PlatformViewAndroid::BeginFrameHC()`:
     - Flag on: emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::BeginFrameHC", "mode", "HC", "path", "embedder_api")` and route to `BeginFrameHCEmbedder()`.
     - Flag off: emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::BeginFrameHC", "mode", "HC", "path", "legacy")` and route to `jni_facade_->FlutterViewBeginFrame()`.
   - Implement `PlatformViewAndroid::BeginFrameHCEmbedder()` with dispatch and status check.
   - Implement `PlatformViewAndroid::EndFrameHC()` and `EndFrameHCEmbedder()` with trace event and dispatch.
   - Implement `PlatformViewAndroid::CreateOverlaySurfaceHC()` and `CreateOverlaySurfaceHCEmbedder(...)` with trace event, validation, and dispatch.
   - Implement `PlatformViewAndroid::DestroyOverlaySurfacesHC()` and `DestroyOverlaySurfacesHCEmbedder()` with trace event and dispatch.

   - Update §B.1 Composition Mode Convergence Tracker to advance `HC — Hybrid Composition` status to `embedder-behind-flag` with last verified `T-3.T6`.
4. `engine/src/flutter/shell/platform/android/platform_view_android_unittests.cc`:
