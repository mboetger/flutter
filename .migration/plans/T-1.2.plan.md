# T-1.2 Plan: Surface and Renderer Availability Lifecycle

## Goal
Extend the Embedder API (`embedder.h`) with `FlutterGpuAvailability` enum, `FlutterEngineSetGpuAvailability`, `FlutterEngineNotifySurfaceCreated`, and `FlutterEngineNotifySurfaceDestroyed`. Wire them through `EmbedderEngine` to `Shell::SetGpuAvailability` and `PlatformView::NotifyCreated` / `NotifyDestroyed` with synchronous completion semantics on the platform task runner. Update `FlutterEngineProcTable` and add automated host unit tests.

## Files Touched
- `engine/src/flutter/shell/platform/embedder/embedder.h`
- `engine/src/flutter/shell/platform/embedder/embedder.cc`
- `engine/src/flutter/shell/platform/embedder/embedder_engine.h`
- `engine/src/flutter/shell/platform/embedder/embedder_engine.cc`
- `engine/src/flutter/shell/platform/embedder/tests/embedder_unittests.cc`

## Implementation Sequence
1. In `embedder.h`:
   - Declare `FlutterGpuAvailability` enum:
     - `kFlutterGpuAvailabilityAvailable = 0`
     - `kFlutterGpuAvailabilityFlushAndMakeUnavailable = 1`
     - `kFlutterGpuAvailabilityUnavailable = 2`
   - Declare functions:
     - `FlutterEngineResult FlutterEngineSetGpuAvailability(FlutterEngine, FlutterGpuAvailability);`
     - `FlutterEngineResult FlutterEngineNotifySurfaceCreated(FlutterEngine, FlutterViewId);`
     - `FlutterEngineResult FlutterEngineNotifySurfaceDestroyed(FlutterEngine, FlutterViewId);`
   - Add function pointer typedefs for `FlutterEngineProcTable`:
     - `FlutterEngineSetGpuAvailabilityFnPtr`
     - `FlutterEngineNotifySurfaceCreatedFnPtr`
     - `FlutterEngineNotifySurfaceDestroyedFnPtr`
   - Append `SetGpuAvailability`, `NotifySurfaceCreated`, `NotifySurfaceDestroyed` to `FlutterEngineProcTable`.
2. In `embedder_engine.h`:
   - Add `bool SetGpuAvailability(GpuAvailability availability);`
3. In `embedder_engine.cc`:
   - Implement `SetGpuAvailability` ensuring dispatch to the platform task runner with waitable latch synchronization.
   - Update `NotifyCreated` and `NotifyDestroyed` to ensure synchronous dispatch on the platform task runner if called from an off-platform thread.
4. In `embedder.cc`:
   - Implement `FlutterEngineSetGpuAvailability`, translating enum and delegating to `EmbedderEngine`.
   - Implement `FlutterEngineNotifySurfaceCreated` and `FlutterEngineNotifySurfaceDestroyed` with `kFlutterImplicitViewId` validation.
   - Update `FlutterEngineGetProcAddresses` macro mapping to populate `SetGpuAvailability`, `NotifySurfaceCreated`, and `NotifySurfaceDestroyed`.
5. In `embedder_unittests.cc`:
   - Add `TEST_F(EmbedderTest, SurfaceLifecycleAndGpuAvailability)` verifying `FlutterEngineSetGpuAvailability`, `FlutterEngineNotifySurfaceDestroyed`, and `FlutterEngineNotifySurfaceCreated` work as expected on a running engine.
6. Verify:
   - Format with `./ci/format.sh`.
   - `migration_verify.dart --task T-1.2 --gates analysis,ratchet` clean.
