# Implementation Plan: T-2.1 — PlatformView Delegate Pointer Seam

- **Task:** T-2.1
- **Target Files:**

  - `engine/src/flutter/shell/platform/android/platform_view_android.cc`

- **Dependencies:** T-0.2, T-0.6

---

## 1. Objectives
- Introduce a delegate pointer `PlatformView* platform_view_ = nullptr;` on `PlatformViewAndroid`.
- Provide `void SetPlatformView(PlatformView* platform_view)` and `PlatformView* GetPlatformViewDelegate() const`.
- Forward `NotifyDestroyed()` to `platform_view_->NotifyDestroyed()` when `platform_view_` is non-null, falling back to `PlatformView::NotifyDestroyed()` when null.
- Add unit tests in `platform_view_android_unittests.cc` exercising the delegate registration, accessor, and forwarding.
- Verify characterization tests in `platform_view_android_surface_lifecycle_unittests.cc` pass unmodified.

3. **Unit Tests (`platform_view_android_unittests.cc`):**

     - Clears delegate via `SetPlatformView(nullptr)`.
   - Add test `NotifyDestroyedDefaultFallback`:
