## Adversarial Scrutiny & Edge Cases
1. **Delegation Transparency & Null Safety:**
   - `AndroidCompositorAdapter` safely handles null `view_embedder_` defensively, returning safe defaults (`false`, `nullptr`, `kSuccess`), but in production it is always initialized with a valid `AndroidExternalViewEmbedderWrapper`.
   - All 11 `ExternalViewEmbedder` methods forward exact arguments and propagate exact return values.
2. **Dynamic Thread Merging Alignment:**
   - In HC mode, `AndroidExternalViewEmbedder::SupportsDynamicThreadMerging()` returns `true`.
   - `AndroidCompositorAdapter::SupportsDynamicThreadMerging()` delegates directly to `view_embedder_->SupportsDynamicThreadMerging()`.
   - `AndroidCompositorAdapter::GetFlutterCompositor()` synchronizes `compositor_.supports_dynamic_thread_merging` with `view_embedder_->SupportsDynamicThreadMerging()`.
3. **Ratchet and Include Hygiene:**
   - Only includes from `ALLOWED_HEADER_PREFIXES` (`flutter/shell/platform/android/` and `flutter/shell/platform/embedder/embedder.h`) are used in headers.
   - Internal dependencies and includes ratchet remains unchanged (deps <= 63, includes <= 121, nogncheck == 0).
