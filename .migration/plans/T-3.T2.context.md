# Context: T-3.T2 — SurfaceTexture External Texture Mode Migration behind Flag

## Problem Statement
The Flutter Android embedder supports external texture rendering through two primary abstractions: `SurfaceTexture` and `SurfaceProducer` / `ImageReader`.
In Stage 3 of the Android Embedder API migration, composition modes converge independently behind `--android-embedder-api`.
Task T-3.T2 migrates the `SurfaceTexture` mode to the embedder path while keeping the legacy path intact and reachable when the flag is disabled.

## Scope of Changes
1. `engine/src/flutter/shell/platform/android/platform_view_android.h`:
   - Declare:
     ```cpp
     FlutterEngineResult RegisterSurfaceExternalTexture(
         int64_t texture_id,
         const fml::jni::ScopedJavaGlobalRef<jobject>& surface_texture);
     ```
2. `engine/src/flutter/shell/platform/android/platform_view_android.cc`:
   - Update `PlatformViewAndroid::RegisterExternalTexture(...)`:
     - Flag on: emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::RegisterExternalTexture", "mode", "SurfaceTexture", "path", "embedder_api")` and route to `RegisterSurfaceExternalTexture(...)`.
     - Flag off: emit `TRACE_EVENT2("flutter", "PlatformViewAndroid::RegisterExternalTexture", "mode", "SurfaceTexture", "path", "legacy")` and route to legacy `external_texture_adapter_->RegisterSurfaceTexture(...)`.
   - Implement `PlatformViewAndroid::RegisterSurfaceExternalTexture(...)` with validation and dispatch.
3. `docs/platforms/android/embedder-api-migration/MIGRATION_LEDGER.md`:
   - Update §B.1 Composition Mode Convergence Tracker to advance `SurfaceTexture ext. texture` status to `embedder-behind-flag` with last verified `T-3.T2`.
4. `engine/src/flutter/shell/platform/android/platform_view_android_unittests.cc`:
   - Add unit tests verifying legacy path, embedder API path, direct seam invocation, and argument validation.

## Non-goals
- TLHC composition mode migration (scheduled for T-3.T3).
- VD composition mode migration (scheduled for T-3.T4).
- HCPP composition mode migration (scheduled for T-3.T5).
- HC composition mode migration (scheduled for T-3.T6).
