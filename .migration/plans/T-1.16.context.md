## 1. Problem Statement & Motivation
Android 14 (API 34) introduced non-linear font scaling for accessibility. In Flutter, text widgets and rendering pipelines query scaled font dimensions via `PlatformDispatcher.instance._getScaledFontSize(unscaledFontSize, configurationId)` in `dart:ui`. This triggers `PlatformConfigurationNativeApi::GetScaledFontSize`, which forwards to `PlatformView::GetScaledFontSize`.

On the Embedder API (`embedder.h`):
1. `embedder.h` has no callback in `FlutterProjectArgs` for an embedder to provide font scaling calculations.
2. `PlatformViewEmbedder` inherits the base `PlatformView::GetScaledFontSize` implementation, which executes `FML_UNREACHABLE()` and terminates the process with an unhandled assertion failure.
3. Android cannot migrate its embedder initialization to the Embedder API without this hook, because Android applications with text scaling would crash upon query.

## 2. Technical Solution
1. **Public C-ABI Callback Definition (`embedder.h`):**
   ```c
   typedef double (*FlutterGetScaledFontSizeCallback)(
       double unscaled_font_size,
       int configuration_id,
       void* user_data);
   ```
2. **`FlutterProjectArgs` Extension:**
   Append `FlutterGetScaledFontSizeCallback get_scaled_font_size_callback;` at the end of `FlutterProjectArgs`.
3. **`PlatformViewEmbedder` Implementation:**
   - Extend `PlatformDispatchTable` with `get_scaled_font_size_callback`.
   - Override `PlatformViewEmbedder::GetScaledFontSize`:
     - If callback is set, execute it with `unscaled_font_size` and `configuration_id`.
     - If callback is not set, safely return `unscaled_font_size` (1:1 scaling) rather than aborting via `FML_UNREACHABLE()`.
4. **Engine Wiring (`embedder.cc`):**
   Extract `get_scaled_font_size_callback` from `args` using `SAFE_ACCESS` and bind into `PlatformDispatchTable`.
5. **Testing:**
   - Host unit tests in `platform_view_embedder_unittests.cc` verifying that:
     a. Provided callback is invoked and returns the scaled value.
     b. Missing callback safely returns unscaled font size.
   - Host unit tests in `embedder_unittests.cc` verifying end-to-end configuration through `FlutterProjectArgs`.
