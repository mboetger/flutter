# T-0.6 Context Pack: Graphics Context Ownership and Deferred Decision Spike (Blocker B-1)

## 1. Ground Truth Verification (§G Re-verification)
- `shell/platform/android/android_context_dynamic_impeller.cc:182` (`SetupImpellerContext`):
  - Defers Vulkan vs OpenGLES selection until `SetupImpellerContext()` is invoked on the raster thread during `Shell::Create` (`shell/common/shell.cc:323`).
  - Calls `GetActualRenderingAPIForImpeller(android_get_device_api_level(), settings_)`.
- `shell/platform/android/android_context_dynamic_impeller.cc:80` (`GetActualRenderingAPIForImpeller`):
  - Queries `IsDeviceEmulator()` via `ro.hardware`, `ro.product.model`, `/dev/qemu_pipe`.
  - Queries Huawei client ID `ro.com.google.clientidbase == "android-huawei"` to avoid broken AHB imports.
  - Queries MediaTek platform `ro.vendor.mediatek.platform` with vendor API level < 32.
  - Queries `IsKnownBadSOC(property)` against SoC board blacklist (`exynos7870`..`exynos9825`, `rk30sdk`).
  - Attempts `vulkan_backend = std::make_shared<AndroidContextVKImpeller>(...)`. If `!vulkan_backend->IsValid()`, falls back to OpenGLES (`AndroidContextGLImpeller`).
- `shell/platform/android/android_context_vk_impeller.cc:74`:
  - Loads `libvulkan.so`, resolves `vkGetInstanceProcAddr`, and invokes `impeller::ContextVK::Create(settings)` to create `VkInstance`, `VkPhysicalDevice`, `VkDevice`, and `VkQueue`.
- `shell/platform/embedder/embedder.h:971, 1048`:
  - `FlutterRendererConfig` requires choosing renderer type (`kVulkan`, `kOpenGL`, `kSoftware`, `kMetal`) at `FlutterEngineInitialize`.
  - `FlutterVulkanRendererConfig` expects `instance`, `physical_device`, `device`, `queue`, and proc resolver callback.
- `shell/platform/embedder/embedder_surface_vulkan_impeller.cc:60-76`:
  - Takes `FlutterVulkanRendererConfig` fields into `impeller::ContextVK::EmbedderData` and passes to `impeller::ContextVK::Create(settings)`.

## 2. The Core Blocker (B-1)
Two fundamental mismatches exist:
1. **Timing mismatch:** `AndroidContextDynamicImpeller` decides Vulkan vs GL asynchronously on the raster thread after initialization, whereas the Embedder API requires static renderer selection at `FlutterEngineInitialize`.
2. **Ownership mismatch:** `FlutterVulkanRendererConfig` assumes the embedder creates and owns the Vulkan instance and device, whereas on Android `ContextVK` (part of Impeller) encapsulates instance and device creation with platform driver bug workarounds.

## 4. What v7 Did
- v7 avoided the problem by forcing OpenGLES/Software rendering unconditionally in `FlutterEmbedderNative`, never creating Vulkan renderer configs. This completely broke HCPP (which requires `kImpellerVulkan`), violated Invariant I-11, and measured benchmarks on a non-production backend. T-0.6 explicitly rejects this shortcut.
