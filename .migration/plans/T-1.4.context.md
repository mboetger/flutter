# T-1.4 Context Pack: Dart Deferred Components

## Objective
Extend the Embedder API (`embedder.h`) to support Dart deferred component (loading unit) resolution and loading. When a Dart program invokes `loadLibrary()`, the Dart runtime signals the engine to resolve the corresponding loading unit ID. The engine dispatches this request to the embedder via `dart_deferred_library_request_callback` in `FlutterProjectArgs`. Once the embedder resolves or downloads the loading unit snapshot artifacts (e.g. from an Android dynamic feature split / APK module or network cache), it notifies the engine via `FlutterEngineLoadDartDeferredLibrary` or `FlutterEngineLoadDartDeferredLibraryError`.
