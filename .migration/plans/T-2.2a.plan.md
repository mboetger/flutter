# Implementation Plan: T-2.2a — Delegate Forwarding for Semantics, Locale, and Font Scaling Overrides

- **Task:** T-2.2a
- **Target Files:**
  - `engine/src/flutter/shell/platform/android/platform_view_android.cc`
  - `engine/src/flutter/shell/platform/android/platform_view_android_unittests.cc`
- **Dependencies:** T-2.1

---

## 1. Objectives
- Route 5 `PlatformViewAndroid` overrides through the `platform_view_` delegate seam when a delegate is registered:
  1. `UpdateSemantics`
  2. `SetSemanticsTreeEnabled`
  3. `SetApplicationLocale`
  4. `ComputePlatformResolvedLocales`
  5. `GetScaledFontSize`
- Preserve existing fallbacks when `platform_view_ == nullptr`.
- Add unit tests in `platform_view_android_unittests.cc` verifying that each method delegates to `platform_view_` when set and falls back when null.
- Verify characterization tests pass unmodified.

---
