# T-1.3 Context Pack: Custom Asset Resolver and Dynamic Asset Updates

## Objective
Add `FlutterMapping`, `FlutterAssetResolver`, and custom asset resolver support to `FlutterProjectArgs` in the public C Embedder API (`embedder.h`). This allows embedders to provide custom asset loaders (such as Android APK `AAssetManager`, in-memory bundles, or virtual filesystems) directly without requiring disk extraction. Additionally, add `FlutterEngineUpdateAssetResolver` to enable dynamic asset updates and hot-restart resolver synchronization via `Shell::UpdateAssetResolverByType`.
