# T-1.12 Plan: Custom Task Runners & Thread Priority Setter

## 1. Summary of Changes
1. **Extend `embedder.h` with Callbacks and Struct Fields:**
   - Define callback types:
     ```c
     typedef void (*FlutterThreadPrioritySetter)(
         FlutterThreadPriority priority);

     typedef void (*FlutterThreadPrioritySetterWithUserData)(
         FlutterThreadPriority priority,
         void* user_data);
     ```
   - Append to `FlutterTaskRunnerDescription`:
     - `FlutterThreadPriority priority;`
     - `FlutterThreadPrioritySetter thread_priority_setter;`
     - `FlutterThreadPrioritySetterWithUserData thread_priority_setter_with_user_data;`
   - Append to `FlutterCustomTaskRunners`:
     - `FlutterThreadPrioritySetterWithUserData thread_priority_setter_with_user_data;`
     - `void* user_data;`
     - `const FlutterTaskRunnerDescription* io_task_runner;`
     - `FlutterThreadPriority io_thread_priority;`
   - Maintain `FLUTTER_ENGINE_VERSION` at `1`.
   - Ensure no preprocessor `#if` guards inside struct definitions.

2. **Update `EmbedderTaskRunner` (`embedder_task_runner.{h,cc}`):**
   - Add `std::function<void(FlutterThreadPriority priority)> thread_priority_setter;` to `DispatchTable`.
   - Store `std::atomic<FlutterThreadPriority> priority_;` in `EmbedderTaskRunner`.
   - Implement `GetThreadPriority()` and `SetThreadPriority(FlutterThreadPriority priority)`.
   - In `SetThreadPriority`: update atomic priority; if `thread_priority_setter` is provided, call immediately if `RunsTasksOnCurrentThread()`, otherwise post a task to `this` to execute on the task runner thread.

3. **Update `EmbedderThreadHost` (`embedder_thread_host.{h,cc}`):**
   - In `CreateEmbedderTaskRunner`:
     - Validate `SAFE_ACCESS(description, struct_size, 0) > 0`.
     - Extract `priority`, `thread_priority_setter`, and `thread_priority_setter_with_user_data` via `SAFE_ACCESS`.
     - Construct dispatcher forwarding to user-data or global setter.
     - If priority setter is configured, invoke immediately if on current thread, or post to runner.
   - In `CreateEmbedderManagedThreadHost`:
     - Extract `io_task_runner` via `SAFE_ACCESS(custom_task_runners, io_task_runner, nullptr)`.
     - If `io_task_runner` is specified:
       - Attempt to create `EmbedderTaskRunner`. If creation fails, abort engine initialization (`return nullptr`, no silent fallback).
       - Omit engine IO thread creation (`SetIOConfig` is not called).
       - Insert into `embedder_task_runners`.
       - Deduplicate with platform runner if identifiers match.
     - If `io_task_runner` is not specified:
       - Read `io_thread_priority` via `SAFE_ACCESS(custom_task_runners, io_thread_priority, FlutterThreadPriority::kBackground)`.
       - Map to `fml::Thread::ThreadPriority` (`kBackground` default, or `kNormal` when configured).
       - Configure engine IO thread via `thread_host_config.SetIOConfig(...)`.
     - Pass the resolved IO task runner to `flutter::TaskRunners`.

4. **Update `embedder.cc` Thread Config Callback:**
   - In `FlutterEngineInitialize`:
     - Guard all accesses to `custom_task_runners` via `SAFE_ACCESS`.
     - If `thread_priority_setter_with_user_data` is present, call with `(priority, user_data)`.
     - Otherwise, if `thread_priority_setter` is present, call with `(priority)`.

5. **Test Infrastructure & Host Unit Tests:**
   - Update `EmbedderConfigBuilder` to support `SetIOTaskRunner`, `SetThreadPrioritySetter`, `SetThreadPrioritySetterWithUserData`, and `SetIOThreadPriority`.
   - Update `EmbedderTestTaskRunner` to configure runner priority and setters.
   - Add comprehensive tests in `tests/embedder_unittests.cc`:
     - `CanSpecifyCustomIOTaskRunner`: Asserts custom IO task runner receives and executes posted tasks.
     - `CanSpecifyCustomTaskRunnerThreadPriorities`: Asserts per-runner priority setter invocation for custom runners.
     - `CanSpecifyCustomTaskRunnerThreadPriorityWithUserData`: Asserts per-runner priority setter with user data.
     - `CanSetEngineThreadPrioritiesWithGlobalSetter`: Asserts engine-managed thread priority setting via global callback.
     - `CanSetEngineThreadPrioritiesWithUserDataSetter`: Asserts engine-managed thread priority setting with user data.
     - `EngineManagedIOThreadPriorityConfig`: Asserts `io_thread_priority = kNormal` dispatches `kNormal` to the priority setter.
     - `EmbedderTaskRunnerSetThreadPriorityAtRuntime`: Asserts dynamic runtime priority changes invoke setter on runner thread.
     - `CustomTaskRunnersSafeAccessTruncatedStruct`: Asserts forward/backward compatibility when passed legacy truncated structs.
