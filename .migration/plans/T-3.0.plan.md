## 1. Objectives
1. Introduce engine command-line switch `--android-embedder-api` in `switch_defs.h`.
2. Add `bool android_embedder_api = false;` to `flutter::Settings` in `settings.h`.
3. Parse `--android-embedder-api` (both flag and `=true`/`=false`) and `--no-android-embedder-api` in `switches.cc`.
4. Cache flag state in `AndroidShellHolder` and `PlatformViewAndroid` at initialization.
5. Provide `IsAndroidEmbedderApiEnabled()` accessors on `AndroidShellHolder` and `PlatformViewAndroid`.
6. Add `TRACE_EVENT1("flutter", "AndroidEmbedderApiState", "enabled", ...)` in `PlatformViewAndroid`.
7. Add unit tests in `switches_unittests.cc` and `platform_view_android_unittests.cc`.
8. Expand the Stage 3 task table in `MIGRATION_LEDGER.md` detailing all Stage 3 call replacement tasks (T-3.0 to T-3.8) and composition mode tasks (T-3.T1 to T-3.T6).

## 2. Implementation Steps

### 2.1 Switch Definition (`shell/common/switch_defs.h`)
Add:
```cpp
DEF_SWITCH(kAndroidEmbedderApi,
           "android-embedder-api",
           "Whether to enable the Android Embedder API adherence path "
           "(Stage 3 migration). Defaults to false.")
```

### 2.2 Settings Struct (`common/settings.h`)
Add:
```cpp
  // Whether to enable the Android Embedder API adherence path (Stage 3 migration).
  // Defaults to false.
  bool android_embedder_api = false;
```

### 2.3 Switch Parsing (`shell/common/switches.cc`)
In `SettingsFromCommandLine`:
```cpp
  {
    std::string android_embedder_api_value;
    if (command_line.GetOptionValue(
            FlagForSwitch(Switch::kAndroidEmbedderApi),
            &android_embedder_api_value)) {
      settings.android_embedder_api =
          android_embedder_api_value.empty() ||
          "true" == android_embedder_api_value;
    } else if (command_line.HasOption("no-android-embedder-api")) {
      settings.android_embedder_api = false;
    }
  }
```

### 2.4 Android Embedder Plumbing
1. **`android_shell_holder.h` & `android_shell_holder.cc`:**
   Add:
   ```cpp
   bool IsAndroidEmbedderApiEnabled() const;
   ```
   implemented as `return settings_.android_embedder_api;`.
2. **`platform_view_android.h` & `platform_view_android.cc`:**
   Add member:
   ```cpp
   const bool android_embedder_api_;
   ```
   initialized from `settings.android_embedder_api` in both constructors.
   Add accessor:
   ```cpp
   bool IsAndroidEmbedderApiEnabled() const { return android_embedder_api_; }
   ```
   Add trace/log:
   ```cpp
   TRACE_EVENT1("flutter", "AndroidEmbedderApiState", "enabled",
                android_embedder_api_ ? "true" : "false");
   ```

### 2.5 Unit Tests
1. **`switches_unittests.cc`:**
   Add `TEST(SwitchesTest, AndroidEmbedderApiFlag)` verifying:
   - Default is `false`.
   - `--android-embedder-api` parses to `true`.
   - `--android-embedder-api=true` parses to `true`.
   - `--android-embedder-api=false` parses to `false`.
   - `--no-android-embedder-api` parses to `false`.
2. **`platform_view_android_unittests.cc`:**
   Add `TEST(PlatformViewAndroidTest, AndroidEmbedderApiFlagState)` verifying:
   - `IsAndroidEmbedderApiEnabled()` returns `false` with default settings.
   - `IsAndroidEmbedderApiEnabled()` returns `true` when `settings.android_embedder_api = true`.

### 2.6 Ledger Expansion (`MIGRATION_LEDGER.md`)
Expand the Stage 3 table with:
