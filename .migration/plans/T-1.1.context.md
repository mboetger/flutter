# T-1.1 Context Pack: Renderer Config Setup Callback

## Objective
Add `setup_callback` to renderer configurations in the Flutter Embedder API (`embedder.h`). This enables embedders (such as the Android embedder in Stage 3) to execute custom graphics context preparation on the engine's raster thread during surface creation prior to rendering the first frame, replacing the legacy `SetupImpellerContext` coupling.
