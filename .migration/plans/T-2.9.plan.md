# Plan: T-2.9 — Introduce a Compositor Seam Shaped like FlutterCompositor

## 1. Overview
Introduce a compositor seam (`AndroidCompositorAdapter`) as an indirection in front of `AndroidExternalViewEmbedderWrapper`. The adapter implements the `ExternalViewEmbedder` interface, forwards all virtual calls directly to the wrapped embedder, and constructs and exposes the `FlutterCompositor` struct matching the Embedder API shape. `PlatformViewAndroid::CreateExternalViewEmbedder()` is updated to instantiate `AndroidExternalViewEmbedderWrapper` wrapped inside `AndroidCompositorAdapter`, guaranteeing that `grep -c FlutterCompositor` in `shell/platform/android` is non-zero and actively wired while preserving 100% behavioral equivalence across all existing Android composition modes (HC, HCPP, VD, TLHC).

## 3. Detailed Steps
1. **Create `AndroidCompositorAdapter` (`android_compositor_adapter.h` and `android_compositor_adapter.cc`):**
   - Header: `engine/src/flutter/shell/platform/android/android_compositor_adapter.h`
   - Source: `engine/src/flutter/shell/platform/android/android_compositor_adapter.cc`
   - Inherits from `ExternalViewEmbedder`.
   - Holds `std::shared_ptr<ExternalViewEmbedder> view_embedder_`.
   - Delegates all 11 `ExternalViewEmbedder` methods:
     - `PrerollCompositeEmbeddedView`
     - `CompositeEmbeddedView`
     - `SubmitFlutterView`
     - `PostPrerollAction`
     - `GetRootCanvas`
     - `BeginFrame`
     - `PrepareFlutterView`
     - `CancelFrame`
     - `EndFrame`
     - `SupportsDynamicThreadMerging`
     - `Teardown`
   - Forwards auxiliary methods: `CollectView`, `PushVisitedPlatformView`, `PushFilterToVisitedPlatformViews`, `PushClipRectToVisitedPlatformViews`, `PushClipRRectToVisitedPlatformViews`, `PushClipRSuperellipseToVisitedPlatformViews`, `PushClipPathToVisitedPlatformViews`.
   - Maintains and exposes `const FlutterCompositor* GetFlutterCompositor()`.
   - Defines static callback trampolines:
     - `create_backing_store_callback`
     - `collect_backing_store_callback`
     - `present_view_callback`
     - `post_preroll_callback`
     - `begin_frame_callback`
     - `end_frame_callback`

2. **Integrate into `PlatformViewAndroid`:**
   - In `platform_view_android.h`:
     - Add forward declaration `class AndroidCompositorAdapter;`.
     - Add `AndroidCompositorAdapter* GetCompositorAdapterForTesting() const;`.
     - Add member `std::shared_ptr<AndroidCompositorAdapter> compositor_adapter_;`.
   - In `platform_view_android.cc`:
     - Include `"flutter/shell/platform/android/android_compositor_adapter.h"`.
     - In `CreateExternalViewEmbedder()`:
       ```cpp
       auto view_embedder = std::make_shared<AndroidExternalViewEmbedderWrapper>(
           android_meets_hcpp_criteria_, *android_context_, jni_facade_,
           surface_factory_, task_runners_);
       compositor_adapter_ =
           std::make_shared<AndroidCompositorAdapter>(std::move(view_embedder));
       return compositor_adapter_;
       ```
     - Implement `GetCompositorAdapterForTesting()`.

3. **Update GN Build Configuration:**
   - In `shell/platform/android/BUILD.gn`:
     - Add `"android_compositor_adapter.cc"` and `"android_compositor_adapter.h"` to `flutter_shell_native_src`.
     - Add `"android_compositor_adapter_unittests.cc"` to `flutter_shell_native_unittests`.

4. **Add Unit Tests in `android_compositor_adapter_unittests.cc`:**
   - Test `CompositorStructShape`: verifies `sizeof(FlutterCompositor)`, callbacks populated, `user_data` set, `supports_dynamic_thread_merging` matched.
   - Test `ExternalViewEmbedderForwarding`: verifies that each method on `AndroidCompositorAdapter` delegates directly to the underlying `ExternalViewEmbedder`.
   - Test `PlatformViewAndroidWiresAdapter`: verifies `PlatformViewAndroid::CreateExternalViewEmbedder()` returns `AndroidCompositorAdapter` and `GetCompositorAdapterForTesting()` is populated.

5. **Format & Verify:**
