## Background & Objectives
Following T-2.1 which established the `platform_view_` delegate pointer on `PlatformViewAndroid` and proved delegation with `NotifyDestroyed`, T-2.2 migrates the remaining overrides of `PlatformView` to forward across the delegate seam when a delegate is registered.

Per `MIGRATION_LEDGER.md` §Stage 2 and §A.2, migrations are batched in ~3–5 methods per task to ensure small diffs, strict reviews, and high verification fidelity.

T-2.2a addresses the first batch of 5 overrides:
1. `UpdateSemantics(int64_t view_id, flutter::SemanticsNodeUpdates update, flutter::CustomAccessibilityActionUpdates actions)`
2. `SetSemanticsTreeEnabled(bool enabled)`
3. `SetApplicationLocale(std::string locale)`
4. `ComputePlatformResolvedLocales(const std::vector<std::string>& supported_locale_data)`
5. `GetScaledFontSize(double unscaled_font_size, int configuration_id) const`

When `platform_view_` is set, each method delegates to `platform_view_->Method(...)`.
When `platform_view_` is null, each method maintains its existing behavior.
Unit tests in `platform_view_android_unittests.cc` exercise both paths, and Stage 0 characterization tests pass unmodified.
