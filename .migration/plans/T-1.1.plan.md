# T-1.1 Plan: Renderer Config Setup Callback

## Goal
Extend `FlutterOpenGLRendererConfig`, `FlutterVulkanRendererConfig`, and `FlutterMetalRendererConfig` in `embedder.h` with an optional `setup_callback` invoked on the raster thread during surface creation. Implement the dispatch in `embedder.cc` and `PlatformViewEmbedder`, and add an automated non-Android host test in `embedder_unittests.cc`.

## Files Touched
- `engine/src/flutter/shell/platform/embedder/embedder.h`
- `engine/src/flutter/shell/platform/embedder/platform_view_embedder.h`
- `engine/src/flutter/shell/platform/embedder/platform_view_embedder.cc`
- `engine/src/flutter/shell/platform/embedder/embedder.cc`
- `engine/src/flutter/shell/platform/embedder/tests/embedder_unittests.cc`
- `engine/src/flutter/shell/platform/embedder/tests/embedder_gl_unittests.cc`

## Implementation Sequence
1. In `embedder.h`:
   - Declare:
     ```c
     typedef bool (*FlutterRendererSetupCallback)(void* user_data);
     ```
   - Append `FlutterRendererSetupCallback setup_callback;` to `FlutterOpenGLRendererConfig`.
   - Append `FlutterRendererSetupCallback setup_callback;` to `FlutterVulkanRendererConfig`.
   - Append `FlutterRendererSetupCallback setup_callback;` to `FlutterMetalRendererConfig`.
   - Document thread affinity (raster thread) and user_data lifetime.
2. In `platform_view_embedder.h`:
   - Add `std::function<bool()> renderer_setup_callback;` to `PlatformViewEmbedder::PlatformDispatchTable`.
   - Add `bool renderer_setup_called_ = false;` and override `void SetupImpellerContext() override;`.
3. In `platform_view_embedder.cc`:
   - Implement `SetupImpellerContext()` to invoke `renderer_setup_callback` if present and not yet called.
   - In `CreateRenderingSurface()`, invoke `renderer_setup_callback` if not yet called to guarantee execution before GPU surface acquisition.
4. In `embedder.cc`:
   - In `InferGLPlatformViewCreationCallback`: read `SAFE_ACCESS(open_gl_config, setup_callback, nullptr)` and bind to `platform_dispatch_table.renderer_setup_callback`.
   - In `InferVulkanPlatformViewCreationCallback`: read `SAFE_ACCESS(vulkan_config, setup_callback, nullptr)` and bind to `platform_dispatch_table.renderer_setup_callback`.
   - In `InferMetalPlatformViewCreationCallback`: read `SAFE_ACCESS(metal_config, setup_callback, nullptr)` and bind to `platform_dispatch_table.renderer_setup_callback`.
5. In `embedder_unittests.cc`:
   - Add `TEST_F(EmbedderTest, RendererConfigSetupCallback)` verifying that setting `setup_callback` triggers on engine initialization and correctly passes `user_data`.
6. Verify:
   - Analysis and Ratchet gates clean.
   - Clean formatting via `./ci/format.sh`.
