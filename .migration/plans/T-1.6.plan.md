# T-1.6 Plan: Pointer Data Gaps

## Goal
Extend `FlutterPointerEvent` in the Embedder API (`embedder.h`) and its dispatch handling in `embedder.cc` to bridge the pointer data gaps between platform input subsystems (Android `AndroidTouchProcessor`, iOS `FlutterViewController`) and `flutter::PointerData`:
1. `tilt`: Tilt angle in radians (0 <= tilt <= pi/2) relative to perpendicular axis
2. `orientation`: Orientation angle in radians (-pi < orientation <= pi) relative to positive y-axis
3. `radius_major`: Major axis radius of touch contact ellipse in physical pixels
4. `radius_minor`: Minor axis radius of touch contact ellipse in physical pixels
5. `radius_min`: Minimum bound of contact ellipse radius in physical pixels
6. `radius_max`: Maximum bound of contact ellipse radius in physical pixels
7. `distance`: Distance from contact surface in physical pixels (for hovering styluses)
8. `distance_max`: Maximum distance from contact surface in physical pixels
9. `size`: Normalized touch contact area in [0.0, 1.0]
10. `embedder_id`: Embedder-provided identifier for event tracking across platform boundaries

## Complete Field Mapping (§A.1)

## Implementation Sequence
1. In `embedder.h`:
   - Append the 10 fields to `FlutterPointerEvent` with comprehensive doc comments describing units, coordinate systems, ranges, and backwards-compatibility notes.
   - Note: Do NOT bump `FLUTTER_ENGINE_VERSION` (§G.5, §G.9 Item 2). Forward compatibility is managed exclusively via `struct_size` and `SAFE_ACCESS`.
2. In `embedder.cc`:
   - In `FlutterEngineSendPointerEvent`:
     - Read each new field using `SAFE_ACCESS(current, field, 0.0)` (or `0` for `embedder_id`).
     - Populate `pointer_data` fields accordingly.
3. In `fixtures/main.dart`:
   - Add entrypoint `pointer_data_packet_geometry` listening on `PlatformDispatcher.instance.onPointerDataPacket` and sending formatted message via `signalNativeMessage`.
4. In `tests/embedder_unittests.cc`:
   - Add unit test `CanSendPointerDataGeometry` sending `FlutterPointerEvent` with non-default values for all 10 fields and verifying that Dart receives each field exactly as specified.
   - Add test `CanSendPointerEventWithLegacyStructSize` sending a pointer event struct with an older `struct_size` (truncated before the new fields) and verifying safe fallback to 0.
5. Verify & Ratchet:
   - Run `./ci/format.sh --fix`.
   - Run `migration_verify.dart --task T-1.6 --gates analysis,ratchet`.
