## 1. Goal & Observable Behaviour Change
- **Goal:** Provide a public Embedder C-API (`FlutterEngineGetCallbackInformation`) allowing embedders to resolve Dart callback metadata (name, class name, library path) from a persistent 64-bit callback handle (produced by `dart:ui`'s `PluginUtilities.getCallbackHandle`). This removes the need for embedders to include internal engine headers (`lib/ui/plugins/callback_cache.h`) or reach into private engine classes.
- **Observable Behaviour Change:** Purely additive C-API and proc table entry point. Existing embedders are unaffected.

## 3. Implementation Sequence
1. **Cache Accessor (`callback_cache.{h,cc}`):**
   ```cpp
   const DartCallbackRepresentation* DartCallbackCache::GetCallbackInformationPtr(
       int64_t handle) {
     std::scoped_lock lock(mutex_);
     auto it = cache_.find(handle);
     if (it != cache_.end()) {
       return &it->second;
     }
     return nullptr;
   }
   ```
2. **Embedder API Header Additions (`embedder.h`):**
   - Add `FlutterCallbackInformation` struct with `struct_size`, `callback_name`, `class_name`, and `library_path`.
   - Add `FlutterEngineGetCallbackInformation` prototype.
   - Add `FlutterEngineGetCallbackInformationFnPtr` typedef.
   - Append `GetCallbackInformation` to `FlutterEngineProcTable`.
3. **Embedder API Implementation (`embedder.cc`):**
   - Implement `FlutterEngineGetCallbackInformation`:
     - Return `kInvalidArguments` if `info_out == nullptr` or `SAFE_ACCESS(info_out, struct_size, 0) != sizeof(FlutterCallbackInformation)`.
     - Query `DartCallbackCache::GetCallbackInformationPtr(handle)`. Return `kInternalInconsistency` if not found.
     - Populate fields and return `kSuccess`.
   - Wire `SET_PROC(GetCallbackInformation, FlutterEngineGetCallbackInformation)` in `FlutterEngineGetProcAddresses`.
4. **Unit Tests (`embedder_unittests.cc`):**
   - Implement tests exercising argument validation, successful lookups, and proc table resolution.
