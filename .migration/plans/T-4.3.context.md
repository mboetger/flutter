# Context: T-4.3 — Flip the Public Default; Flag Remains as Opt-Out

## Problem Statement
Task T-4.1 enabled `--android-embedder-api` by default in the tree, and task T-4.2 verified stability across 3 consecutive soak runs without regression.
Task T-4.3 transitions the public status of the Android Embedder API to the public default.
The CLI switch definitions and documentation in `switch_defs.h` must formally declare the new default and provide first-class recognition of the `--no-android-embedder-api` opt-out switch so developers and tooling can reliably request the legacy path during the stabilization window.

## Scope of Changes
1. `engine/src/flutter/shell/common/switch_defs.h`:
   - Update `kAndroidEmbedderApi` to reflect default `true`.
   - Add `kNoAndroidEmbedderApi` ("no-android-embedder-api").
2. `engine/src/flutter/shell/common/switches.cc`:
   - Use `FlagForSwitch(Switch::kNoAndroidEmbedderApi)`.
3. `engine/src/flutter/shell/common/switches_unittests.cc`:
   - Verify `kNoAndroidEmbedderApi` behaves as expected.
4. `docs/platforms/android/embedder-api-migration/MIGRATION_LEDGER.md`:
   - Document completion of T-4.3.

## Non-goals
- Deleting legacy paths (scheduled for T-4.5).
- Dissolving `PlatformViewAndroid` (scheduled for T-4.6).
