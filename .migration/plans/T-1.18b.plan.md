## 1. Goal & Observable Behaviour Change
- **Goal:** Implement dynamic raster thread merging support in `EmbedderExternalViewEmbedder` and connect it via `InferExternalViewEmbedderFromArgs` in `embedder.cc`, enabling dynamic thread merging across generic embedders.
- **Observable Behaviour Change:**
  - When `FlutterCompositor.supports_dynamic_thread_merging` is set to `true`, `Rasterizer::Setup` initializes a `RasterThreadMerger`.
  - When preroll runs, `EmbedderExternalViewEmbedder::PostPrerollAction` passes frame threading info to `FlutterPostPrerollCallback` and translates the returned `FlutterPostPrerollResult` to `PostPrerollResult`.
  - Frame lifecycle callbacks (`begin_frame_callback` and `end_frame_callback`) are dispatched with valid threading information.
  - Initializing an engine with `supports_dynamic_thread_merging = true` but null `post_preroll_callback` fails immediately with `kInvalidArguments` (Invariant I-1).
  - All existing embedders with zero-initialized compositors remain 100% unaffected.
