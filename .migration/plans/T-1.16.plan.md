## 1. Goal & Observable Behaviour Change
- **Goal:** Enable the public Embedder API (`embedder.h`) to support non-linear font scaling calculations requested by Dart (`PlatformDispatcher._getScaledFontSize`), avoiding `FML_UNREACHABLE()` aborts in `PlatformViewEmbedder` and providing an extensible callback hook for embedders.
- **Observable Behaviour Change:**
  - Embedders can configure `get_scaled_font_size_callback` in `FlutterProjectArgs`.
  - When Dart queries scaled font size via `PlatformDispatcher._getScaledFontSize`, `PlatformViewEmbedder::GetScaledFontSize` delegates to the embedder callback.
  - If no callback is provided (e.g., legacy or desktop embedders), `PlatformViewEmbedder::GetScaledFontSize` safely returns the unscaled font size (1:1 scaling) instead of terminating the process with an assertion failure.
