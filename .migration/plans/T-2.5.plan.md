## 1. Objectives
- Extract thread configuration logic from `AndroidShellHolder` into `AndroidTaskRunners`.
- Implement `AndroidPlatformThreadPrioritySetter` matching `FlutterThreadPrioritySetter` (`void (*)(FlutterThreadPriority)`).
- Implement `AndroidPlatformThreadConfigSetter` adapter for `fml::Thread::ThreadConfig`.
- Populate `FlutterCustomTaskRunners` shape on `AndroidTaskRunners` with:
  - `struct_size = sizeof(FlutterCustomTaskRunners)`
  - `thread_priority_setter = &AndroidPlatformThreadPrioritySetter`
  - `io_thread_priority = FlutterThreadPriority::kNormal`
  - Valid task runner descriptions for platform, raster, ui, and io.
- Provide `flutter::TaskRunners` to `AndroidShellHolder` and `Shell`.
- Replace `thread_host_` member in `AndroidShellHolder` with `std::shared_ptr<AndroidTaskRunners> task_runners_`.
- Remove `#include "flutter/shell/common/thread_host.h"` from `android_shell_holder.h` and `android_shell_holder.cc`.
- Maintain dependency ratchet counts: internal includes decrease from 122 to 121 (<= 123 baseline), internal deps remain 63 (<= 63 baseline), nogncheck == 0.
- Ensure all tests in `android_threading_unittests.cc` and `flutter_shell_native_unittests` pass cleanly.

## 2. Implementation Steps

1. **`android_task_runners.h` / `android_task_runners.cc`**:
   - Declare `void AndroidPlatformThreadPrioritySetter(FlutterThreadPriority priority);`.
   - Declare `void AndroidPlatformThreadConfigSetter(const fml::Thread::ThreadConfig& config);`.
   - Define `class AndroidTaskRunners`:
     - Factory: `static std::unique_ptr<AndroidTaskRunners> Create(const std::string& thread_label, const Settings& settings);`
     - Constructor taking `(const std::string& thread_label, const Settings& settings, std::shared_ptr<ThreadHost> thread_host)` for `Spawn()` reuse.
     - Getters:
       - `const flutter::TaskRunners& GetTaskRunners() const;`
       - `const FlutterCustomTaskRunners* GetCustomTaskRunners() const;`
       - `std::shared_ptr<ThreadHost> GetThreadHost() const;`
       - `bool IsValid() const;`
     - Private members:
       - `std::shared_ptr<ThreadHost> thread_host_;`
       - `flutter::TaskRunners task_runners_;`
       - `FlutterTaskRunnerDescription platform_description_;`
       - `FlutterTaskRunnerDescription raster_description_;`
       - `FlutterTaskRunnerDescription ui_description_;`
       - `FlutterTaskRunnerDescription io_description_;`
       - `FlutterCustomTaskRunners custom_task_runners_;`
       - Helper `void InitializeDescriptions();`

2. **`BUILD.gn`**:
   - Add `"android_task_runners.cc"` and `"android_task_runners.h"` to `flutter_shell_native_src`.

3. **`android_shell_holder.h` / `android_shell_holder.cc`**:
   - In `android_shell_holder.h`:
     - Replace `#include "flutter/shell/common/thread_host.h"` with `#include "flutter/shell/platform/android/android_task_runners.h"`.
     - Replace `std::shared_ptr<ThreadHost> thread_host_;` with `std::shared_ptr<AndroidTaskRunners> task_runners_;`.
     - Update testing getter / constructor to use `AndroidTaskRunners`.
   - In `android_shell_holder.cc`:
     - Remove `AndroidPlatformThreadConfigSetter` definition (now provided by `android_task_runners.h`).
