## 1. Problem Statement & Motivation
In Flutter, Hybrid Composition (HC) on Android requires dynamic thread merging between the raster thread and the platform thread. As analyzed in T-0.13 (`docs/android/embedder_migration_b4_thread_merging.md`), running HC without dynamic thread merging leads to JNI thread violations, deadlocks, and visual tearing.

Currently, `embedder.h` lacks the C-ABI definitions needed for embedders to interact with `RasterThreadMerger`. Per `MIGRATION_LEDGER.md` §T-1.18, task T-1.18 is split into three phases:
- **T-1.18a:** C-ABI definitions in `embedder.h`, `FlutterEngineProcTable` extensions, and proc table unit tests.
- **T-1.18b:** Engine implementation in `EmbedderExternalViewEmbedder` and wiring in `embedder.cc`.
- **T-1.18c:** End-to-end host integration tests in `embedder_unittests.cc`.

This task, T-1.18a, establishes the public C-ABI foundation and verifies proc-table population.

---

## 2. Technical Solution
1. **Public Types & Callbacks (`embedder.h`):**
   - `FlutterRasterThreadMergerRef`
   - `FlutterPostPrerollResult`
   - `FlutterFrameThreadingInfo`
   - `FlutterPostPrerollCallback`
   - `FlutterCompositorFrameCallback`
2. **`FlutterCompositor` Extension (`embedder.h`):**
   - Append `supports_dynamic_thread_merging`, `post_preroll_callback`, `begin_frame_callback`, `end_frame_callback` after `present_view_callback`.
3. **C-API Exports (`embedder.h`, `embedder.cc`):**
   - Declare and implement `FlutterRasterThreadMergerIsMerged`, `FlutterRasterThreadMergerIsOnPlatformThread`, `FlutterRasterThreadMergerMergeWithLease`, `FlutterRasterThreadMergerExtendLeaseTo`.
4. **`FlutterEngineProcTable` Extension:**
   - Append the four function pointer typedefs and struct fields.
   - Populate via `SET_PROC` in `FlutterEngineGetProcAddresses`.
5. **Testing:**
   - Update `embedder_unittests_proctable.cc` to verify the new proc table entries are populated, non-null, unique, and safe to invoke with nullptr.
