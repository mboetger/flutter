## Defect Note for T-0.15b (Device-Lock)
The `--device-lock` test was removed via I-7 scope ruling and deferred to T-0.15b. During Round 3 this test produced a severe deadlock under `flutter test` despite running cleanly under `dart test`.
**Root cause passed to T-0.15b to inherit**: The test spawns a child isolate that calls blocking `lockSync()`; POSIX file locks are per-process, so an isolate in the same process is testing the wrong thing regardless of runner; T-0.15b must test lock contention across separate PROCESSES and must pass under whichever runner CI uses.
